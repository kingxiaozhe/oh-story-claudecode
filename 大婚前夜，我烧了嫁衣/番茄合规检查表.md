# 番茄合规检查表（常驻，每批正文提交前逐项过）

> 依据：官方签约规则（参考资料/番茄签约规则_20260525.md）+ 工具箱番茄 rubric + 女频手册。
> 用法：每写完一批章节跑「章级检查」；每 2 万字跑「批级回扫」；申请签约前跑「提交前终检」。

## A. 内容红线（安全审核层，一票否决）

- [ ] 无「通敌/外族」表述：侯府旧案只写**吃空饷、侵吞军资、伪冒军功**
- [ ] 死亡/服毒场景一句带过，不写生理过程；重生不解释机制
- [ ] 外室子全程为无辜背景板，无虐童、无羞辱孩子桥段
- [ ] 复仇全程走「证据 → 官府/圣裁」，主角不私刑杀人
- [ ] 把柄类情节**写结果不写方法**：下毒、做假账等只写查到什么与后果，不写可操作手法
- [ ] 感情线合规（固化规则）：所有感情线角色均为成年人（女主 19、男主 23）；前世婚姻无实（大婚当日丈夫即赴北境，七年未同房），双洁；全文无越界亲密描写；关系推进平等自愿，无胁迫式感情动态
- [ ] 无校园/学生相关负面内容（本书古言，天然规避）
- [ ] 三观锚定：守活寡七年只作控诉对象，重生第一时间否定，不宣扬愚忠

## B. 评估三维度对照（编辑评估层，签约生死线）

- [ ] 题材：古言+重生+复仇+退婚（番茄女频主流标签），正文前 3 章全部兑现标签承诺
- [ ] 开篇：第 1 章前 3 段即冲突（烧嫁衣）；前 300 字主角登场；第 1 章说明目标与卖点
- [ ] 节奏：约 2200 字/章；每章至少 1 个可指认的情绪兑现点；每 1000 字有情绪起伏
- [ ] 人物/代入感：女主每次反击自己做决定自己推进（主动性铁律）；男主人设用细节立
- [ ] 主线：主情绪「扬眉吐气」一条贯穿，火葬场追悔为辅线，不中途变虐恋主导
- [ ] 故事性：每章过「目标→阻碍→行动→代价→新期待」最小剧情循环
- [ ] 言语通顺：AI 味零容忍（见 C 节）
- [ ] 侵权：桥段无成段撞车；书名发书前在番茄 App 查重（用户执行）

## C. AI 同质化防线（前几本吃亏的重点）

- [ ] 句子层：每章落盘必跑 `check-ai-patterns`（blocking 零命中）+ `check-degeneration` + `normalize-punctuation`
- [ ] 门禁层：banned-words 扫描 + deslop 七道门禁抽查（禁用词/句式/心理外化/节奏/对话/结尾/解释腔）
- [ ] 结构层：**章型轮换**——对峙章/布局章/温情章/反转章交替，相邻章节拍不同构（卷纲章节定位列机械可查）
- [ ] 记忆点：签名要素「账」第 1 章第一场戏即出现（烧嫁衣时当场报出侯府一笔具体的账）
- [ ] 人读终检：每批至少一次通读，读感像人写的才放行

## D. 格式与发布操作

- [ ] 短段落、对话独立成行、无段间空行错乱（官方点名「格式未分段」是打回项）
- [ ] 从文件粘贴到后台时保留分段
- [ ] 书名=简介=标签=正文四位一体，无货不对板
- [ ] 正文无省略号/破折号/工程词（第X章、读者等）

## E. 节点与提交策略

- [ ] 第 10 章（约 2 万字）：第一波大兑现 + 章尾强钩子 → **首次签约申请点**
- [ ] 第 23 章（约 5 万字）：卷中大爽点 → 备用申请点
- [ ] 第 36 章（约 8 万字）：卷末大高潮 + 跨卷钩子 → 签约后主动开推荐点
- [ ] 提交时机：周一至周三，避开节假日；提交时存稿 5-8 章，评估期保持日更
- [ ] 每 2 万字批级回扫：story-review（solo + 番茄 rubric 六项）跑整卷
- [ ] 失败对冲：若 3 次评估全败（未签约版权仍在作者手中），同稿转投七猫（强情绪女频，调性次优）

## F. 需要用户执行的事项

- [ ] 实名认证完成；签约手机号、银行卡归属人与实名一致
- [ ] 发书前番茄 App 搜索书名查重
- [ ] 后台确认签约规则是否有更新（本表依据 2026-05-25 版官方文章）
