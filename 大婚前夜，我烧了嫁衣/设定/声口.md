## 0. 一句话声口

> **冷而稳的谢云蘅视角，古言雅驯语气词打底；狠话短句收尾，爽点靠在场群像反应抬轿；情绪极度克制——但冷里带一分"烧嫁衣的火"。**

**主次**：**冷静克制是底色，决绝是锋刃。** 沈妙式的冷是"死水微澜"；谢云蘅比她多一分带火的决绝——她是把嫁衣亲手投进火盆的人。这一分火只在**复仇兑现的瞬间**露：一个动作、一句短话，绝不煽情、绝不解释。九分冷，一分火。

## 1. 采纳区 —— 7 样手法（注入规则 + 上限）

### 1.1 古言雅驯语气词打底（地基）
- 叙述与对话用「竟 / 便是 / 倒是 / 偏 / 罢了 / 到底 / 越发 / 很是 / 定然 / 那般 / 这般 / 大约是」替代现代白话（"竟"替"居然"、"定然"替"肯定"）
- **上限**：无硬上限，同一个词一段内不重复；现代词（居然/真的/超/绝了）反向禁入
- ✅ "侯府倒是急了。" / "他偏在这时递帖子，便是要满京城都看见。"

### 1.2 冷女主推演腔：反问蓄力 + 狠话钉死
- 谢云蘅的算计写成短促推演：反问/假设 ≤2–3 句，**必须一句短狠话收尾**；严禁整段"她赌的是……所以……"式复盘讲解（本书中期章的主病）
- **上限**：每章 ≤2 处
- ✅ "他们会去庄子。因为那对他们最省事。——也最致命。"
- ✗ "她赌的是侯府的急。总账一旦到了御史台，那只手就再无退路。他们绝不会坐等……"（讲解腔，须重写）

### 1.3 在场群像反应给爽点抬轿
- 爽点/打脸/揭露的瞬间不夸主角，切 2–3 个在场者差异化反应（僵住的、变脸的、倒抽凉气的），再回到谢云蘅
- **上限**：每章 1–2 组，每组 ≤3 个反应镜头
- ✅ 满堂道贺声停了。老夫人捻佛珠的手停在半空。二房媳妇脸上的笑，一寸一寸挂不住。

### 1.4 器物/礼法的"爽点翻译"旁白
- 高光时刻用 ≤3 句旁白讲清一件器物/礼制的分量（地契红契、诰命品级、族谱除名意味着什么），让读者知道"这一下有多大"；只翻译分量，不翻译计策
- **上限**：每章 ≤1 处

### 1.5 章尾金句钩 + 下章复读
- 章尾 1–2 行落在金句/认知反转上；每 2–3 章挑一处，下章第一行原样复读该句再展开
- **上限**：章尾钩必有；复读手法每 2–3 章一次

### 1.6 对话声线分层（固定不漂移）
- **谢云蘅（冷，带火）**：短句、少语气词、反问收刃——"哦？""你说呢。""那便试试。"复仇兑现时可露一分火："我烧的就是嫁衣。"
- **半夏（急、真）**：语气词多、句子碎——"姑娘！""这可怎么好！"
- **陆听寒（缇骑，冷幽默）**：公事腔里藏刀，偶尔一句淡淡的调侃
- **老夫人/嬷嬷型**：到底、终究、很该、我的儿、老婆子
- **反派女眷（绵里藏针）**：客气话说狠事，"妹妹这话，姐姐可担不起"
- **上限**：不写"谁说的"也认得出人；聒噪型配角每章限量调剂

### 1.7 标点克制律（冷声口的物理底盘）
- 能用句号绝不用感叹号；愤怒写成"声音更低"不是"！"
- **上限**：感叹号 ≤2/千字；省略号 ≤4/千字（对话犹豫处优先用动作/停顿替代）
