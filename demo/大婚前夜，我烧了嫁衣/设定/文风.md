# 文风（《大婚前夜，我烧了嫁衣》· 声口权威基）

> 本文件是本书**声口/笔调的权威风格基**。story-long-write「自定义文风模式」会读取它，
> 之后每章的句长带 / 标点节奏 / 对话潜台词 / 情绪交替以本文件为准；对标/拆文 `文风.md` 降为参考。
> 一句话定调：**冷、狠、克制，隐忍里藏锋；短句砸节奏，把柄落实处，前世今生对照见筋骨。**

---

## 一、笔调（整体基调）

- 贴女主谢云蘅的第三人称限知视角。叙述嗓音**冷峻、隐忍、克制**——重生复仇者压着两世的火，面上不露、心里透亮。
- 情绪靠**身体反应**落地，不靠形容词堆砌：`眼眶发烫` / `脊背发凉` / `心像被一只手狠狠攥住` / `血都凉了半分`。禁"悲痛欲绝""心如刀绞"这类空词。
- 爽点靠**具体把柄兑现**落地，不空喊："账、人、赃、花押、口供"——具体到哪本账、哪笔银、谁经手、哪一笔花押；不写"她终于赢了"，写她掀出的那本账。
- 反派声口分层：老油子油滑切割、失势者色厉内荏、贵人说客从容藏刀；女主始终冷、稳、一字一顿。

## 二、句长带（节奏，可执行）

- **以短句为主，长短交错**。叙述句常用逗号切成 3–8 字的小节奏顿挫。例：`云蘅的心，像被一只手狠狠攥住。`
- **关键情绪/爽点/转折处，用极短句独立成段**（2–6 字）制造重锤：`准了。` / `云蘅没有回头。` / `还是那只手。` / `是费三的后心。`
- **段落短**：常一到三句一段，**单空行分段**，留白多。忌大段密铺。
- 长句只在铺陈账目链、回溯往事时用，且内部仍以逗号切碎，不写从句套从句。
- 目标章长 ~2200 字（放行线 1980，上限 2420）。

## 三、标点节奏（硬门禁 + 偏好）

- **禁破折号 `——`/`—`**：一律归一为逗号或句号（硬门禁，normalize 脚本会清）。
- **禁省略号 `……` 作停顿**：改用短句或动作 beat 复原顿挫，不保留省略号。
- **逗号是主要的节奏工具**：靠逗号把长意群切成短促顿挫（`她抬起头，眼中是烧了两世的火。`）。
- **句号收束**，多用短句号断句制造铿锵。
- **感叹号极克制**：只在真正的爆发点用（公堂 `准！`、厉喝 `拿下她！`、老人泣血 `是被他们生生逼死的啊`）。平铺叙述不用。
- 对话用直角/弯引号 `""`；盐言场景另论。

## 四、对话（潜台词 + 声线）

- **女主台词冷、稳、一字一顿**，以理压人、以势迫人，常问非所答、以退为进：`"是谁逼死了我娘？"` / `"大人拦的，哪里是我认祖。大人拦的，是替某些人，续那二十年的盖子啊。"`
- **对话夹动作 beat**，不干说：`她攥紧了老人的手，一字一顿，"是谁逼死了我娘？"`
- **声线随基调收敛**：高压/生死/悲痛场景里，插科打诨的轻快声线让位；信息型配角不当科普嘴，把交底揉进情绪与动作里。
- 反派对话给"切割—威胁—色厉内荏"的层次；说客给"软台阶—软刀子"的双面。

## 五、标志手法（本书筋骨，尽量每章一处）

- **前世今生对照**：以"前世……这一世……"的对照，把复仇动机与人物转变焊进当下场景。这是本书最核心的情绪引擎，几乎每章埋一处。
  - 锚点：`前世，她走投无路的每一步，身后都是空的……这一世，她还没开口求，就有人把退路，替她铺在了脚下。`
- **章首强钩 / 章尾冷收**：章首用悬念句或反常举动开场；章尾用短句独段收束，常回扣主题、留强钩。
  - 章尾锚点：`温家没有绝后。温家的女儿，回来了。` / `下一站，漕运衙门。`
- **物象锚定情绪**：嫁衣、账册、遗帕、暗记、一盏温茶——用具体物件承载情绪与主线，不空抒情。

## 六、原文锚点范例（生成时对齐这些节奏）

1. 冷收尾 + 短句独段：
   > 云蘅没有回头。
   > 她走进伯府，把那本沉甸甸的总账，重新收进了怀里。

2. 身体反应写情绪 + 把柄落实：
   > 云蘅的心，像被一只手狠狠攥住。
   > 可从这个亲眼见过她娘、与她娘共过患难的老人口中，"逼死"两个字，才第一次，有了血有了肉，砸得她眼眶发烫。

3. 对话一字一顿 + 动作 beat：
   > "是谁？"她攥紧了老人的手，一字一顿，"是谁逼死了我娘？"

4. 反将式台词（以势压人、点破动机）：
   > "你越是急着花钱堵我的嘴，就越是说明，这块招牌，根本不是你的。"

## 七、用词质感 & 禁忌

- **古言质感**：用嫡女/中馈/诰命/宗人府/漕运司/花押/具结/缇骑等词；不出现现代词汇、网络语、拉丁字母。
- **禁忌词/句（与 banned-words.md 一致，出现即改）**：缓缓、仿佛/犹如/宛若、眼中闪过、嘴角勾起、深吸一口气、不禁、微微/轻轻/淡淡、`，带着…`、心中涌起、"不是X，是Y"对比句。
- **禁工程/元信息泄漏**：卷号（"卷一里…"）、伏笔编号（F##）、"上一章/本章/读者"等，一律改成世界内表达。
- **禁英文字母**：中文正文不得混入拉丁字母（连写手误高发，落盘必扫）。
