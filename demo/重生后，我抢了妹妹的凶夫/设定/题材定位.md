# 题材定位

## 核心设定表

### 基本信息
- 书名：重生后，我抢了妹妹的凶夫
- 题材/类型：古言（主）+ 重生 + 宅斗复仇 + 权谋感情线
- 目标平台：番茄女频
- 预计字数：80-120 万字
- 目标读者：18-35 女性，吃重生复仇、追妻/护妻、双强感情线

### 一句话梗概
被继母养女设局让婚、替人顶罪而死的嫡女沈观棠，重生回圣旨到府当日，当众抢下人人避之不及的「活阎王」婚约，抱紧前世唯一护过她的真金大腿，把欠她的人一个一个送上路。

### 核心梗三分法
- 题材圈：古言宅斗
- 流派圈：重生复仇 + 双强联姻
- 核心梗圈：**抢婚信息差**——全京城以为她跳火坑，只有她知道这是三年后权倾朝野的孤臣。所有剧情不出此圈：每个阶段的爽点都建立在「旁人看衰 / 她稳赢」的信息差兑现上。

### 主角设定
- 姓名：沈观棠，17 岁（重生回来时），永宁伯府嫡长女
- 核心特质：能忍会演、账目过目不忘、狠得下心
- 金手指：重生记忆（知未来三年朝局大事与各家起落）+ 十年主持中馈练出的「过目成账」
- 弱点/缺陷：胞弟沈观澜是她的死穴；生母旧人旧产是她必须护住的东西，容易被人拿捏
- 核心动机：拿回生母嫁妆、护住弟弟、让前世逼死她的人一个不漏地偿还

### 男主设定
- 姓名：裴衍，24 岁，北镇抚司指挥使，京中人称「活阎王」
- 出身：罪臣之后，少年抄家流落时受过沈观棠生母温氏商队救命之恩
- 前世：暗中护她生意、救她弟弟；她死后掀翻顾沈两家，因越权屠戮被赐死
- 今生：奉旨娶「永宁伯府沈氏女」，本以为是桩拴绳的差事，直到那位嫡女当众抢婚

### 世界观骨架
- 时代/背景：架空王朝「大雍」，京城，勋贵与新贵党争渐起
- 核心设定：北镇抚司直属天子，缉查百官；皇商体系与漕运利益盘根错节
- 社会结构：勋贵（永宁伯府）渐衰，清流新贵（顾云洲一系）上升，天子以孤臣制衡两边

### 核心冲突
- 主线矛盾：沈观棠复仇线（柳氏、沈月柔、顾云洲）× 裴衍查案线（漕运案，牵出温家船队旧案与温氏死因）双线缠绕
- 终极阻碍：漕运案背后的真正主使（跨卷揭示），前世借顾云洲之手毒杀政敌、也弄死了温氏的那只手

- 对话独立成行，带潜台词与身份声线：观棠对外柔、账上狠；裴衍话少、一句定调
- 正文不使用省略号与破折号；犹豫、停顿用动作与换行处理
