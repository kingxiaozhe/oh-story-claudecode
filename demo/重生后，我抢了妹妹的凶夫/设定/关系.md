# 角色关系

## 关系图谱

```
沈观棠（女主）
├─ 裴衍：婚约（第1章起）。类型：盟友→爱人。前世恩情单向透明（他知她不知→重生后她知他不知她知）
├─ 沈观澜：胞弟，12岁。类型：软肋+动机。被柳氏以「温养」名义暗中喂损药
├─ 柳氏：继母。类型：核心对手（内宅线）。把持温氏嫁妆，欲吞产、废嫡
├─ 沈月柔：柳氏胞妹之女，伯府养女。类型：镜像对照组。前世踩她上位，今生处处慢一步
├─ 顾云洲：户部主事，探花郎。类型：核心对手（外线）。伪君子，图温家商路
└─ 沈崇山：父亲，永宁伯。类型：摇摆的墙头草。自私平庸，谁强听谁的
```

## 关系演变规划（第一卷）

|------|------|------|
| 观棠 × 裴衍 | 各取所需的交易婚约 | 并肩查案的信任雏形（好感度：警惕→可托后背，不越双洁线） |
| 观棠 × 柳氏 | 表面母慈女孝 | 撕破脸，柳氏断一臂（心腹管事下狱） |
