# 卷一：聚宝斋风云（1-30 章）

## 卷任务

## 三幕
- 第 1-8 章：冤枉与觉醒。被诬偷玉 → 金手指觉醒 → 自证 + 第一次打脸 → 立足。
- 第 9-22 章：立名与暗流。连续鉴宝立名 → 林晚照冲突转合作 → 发现赝品局线索。
- 第 23-30 章：收网。赵德海反扑嫁祸 → 私下局对决 → 卷末揭穿 + F-02/F-03 回收。
