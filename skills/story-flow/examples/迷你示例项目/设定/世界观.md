# 世界观与规则锁

## 背景
当代都市，古玩行当。潘家园式的鱼龙混杂：捡漏、打眼、局中局。

## 金手指：残忆之眼
- 触碰器物，看到其残留记忆碎片（画面 + 情绪，无声音）
- **规则锁（写下即不可违反）**：
  1. 每天最多 3 次，跨天重置（以睡醒为准）
  2. 每次只见碎片（3-10 秒画面），不见全貌，需要主角自己推理拼合
  3. 单日第 3 次使用后剧烈头痛，且随机丢失一段自身近期记忆
  4. 只对"有人经手过的旧物"有效，新品/未经手物品无效
  5. 能力来源本卷不揭示（F001 长线伏笔）

## 行当规则
- 古玩行"不打假"潜规则：买定离手，打眼自认
- 鉴定书可以造假，圈内看"掌眼人"的口碑
- 典当行、拍卖行、私下局三条交易线
