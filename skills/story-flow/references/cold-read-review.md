# 冷读审查协议

模拟真实读者：**读者手里没有你的大纲**。冷读代理的输入被刻意限制，防止"知道设定所以觉得好看"的偏差。

## 轻量版（N4 每章执行）

**输入**：仅本章正文；可选附上一章末尾 300 字（模拟追更读者的记忆残留）。不给设定、大纲、控制卡、追踪文件。

**三问**（固定格式回答）：

1. 追读意愿 1-5 分 + 一句话理由（5=现在就想看下一章；1=不会再点开）
2. 你记住了什么？（人物、事件、悬念，凭印象列举，不超过 3 条）
3. 哪里想跳过？（指出具体段落位置，没有则写"无"）

**判定**（调度员执行，冷读代理只答题不判定）：

- 追读 < 3 → 记语义 blocking，计轮（修复方向从"理由"与"跳过点"推导）
- 追读 = 3 → advisory 留痕
- **对账**：冷读"记住的"是否命中控制卡的承诺情绪与钩子？记住的全是闲笔、钩子没进记忆 → 说明钩子失效，即使分数达标也记 advisory，偏差写入 METRICS 备注。

## 深版（N6 阶段审查执行）

**输入**：近 5 章正文连读（仍不给设定）。

**追加问题**：

4. 连读节奏：哪几章读起来"像同一章"？（开场方式、冲突形态、情绪节拍的重复感）
5. 期待管理：读到第 5 章时，你以为这本书接下来要讲什么？（答案偏离卷纲主线 → 卷级信号，交 N6 处置）
6. 弃书点：如果会弃书，最可能发生在哪一章哪一段？

## 纪律

- 冷读代理不可用时 solo 降级：调度员**先冷读后对卡**（先只重读正文答三问，再打开控制卡对账），汇报标注 `Fallback: agent unavailable -> solo`。
- 冷读结论是信号不是圣旨：与控制卡冲突时（如低压章故意慢），以卷纲的章节定位为准，但连续多章低分仍要如实进 METRICS——定位解释得了一章，解释不了一批。
