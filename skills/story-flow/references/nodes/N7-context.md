# N7 上下文管理

写手侧的"新鲜大脑"由每章新派子代理天然保证（这是本工作流对 cm-workflow「/clear 轮换」的等价实现），本节点管**调度员自己**的上下文卫生：

1. **批内**：每章闭环后，调度员丢弃该章正文细节与门禁往返内容，只保留：清单勾选状态、`追踪/上下文.md` 最新节、下一章的承接压力。禁止把整章正文留在工作记忆里跨章使用——衔接靠 N3 派发时重读"上一章末尾 500 字"。
2. **批间**：一批结束，重读 `.flow-status.json` + 清单 + METRICS 校准进度感，其余一律按需重读文件。判断依据：**任何"我记得"都不如"我刚读的"——正典在文件里，不在记忆里。**
3. **长会话防漂移**：调度员发现自己开始凭记忆断言设定细节（而非引用文件）→ 立即停止，重读对应正典文件再继续。
4. 写 `.flow-status.json`（node:N7，批间时 detail 如"第 2 批完成，准备第 3 批"）。
