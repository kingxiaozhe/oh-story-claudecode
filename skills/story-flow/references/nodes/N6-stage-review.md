# N6 阶段审查

**触发表**（满足任一）：每 5 章；卷末；高危章完成后（主线级伏笔回收章、主要人物首登场/退场章、卷内高潮章）；gate-policy 规定的 waive 累计触发；连续 2 章冷读 <3。未触发时本节点直接跳过。

1. **连读深审**：冷读深版（cold-read-review.md 深版三问：节奏重复感、期待偏移、弃书点）。
2. **节奏对账**：近 5 章实际张弛 vs 卷纲章节定位标注；开场方式/冲突形态重复度。
3. **文风漂移**：对照 `设定/文风.md`（或对标文风）抽查——句长分布、对话占比趋势（METRICS 已有数据）、口癖聚集（linter advisory 的累计分布）。
4. **产出** `追踪/阶段审查_第{X}批.md`：结论分三档——
   - 无系统性问题 → 留档继续；
   - 有模式性问题（如连续章开场同构）→ 生成修正指令注入后续批次的控制卡"禁止事项"栏；
   - 卷级问题（期待偏移、节奏结构性失衡）→ 暂停出决策卡（调卷纲走变更模式 / 接受并记录）。
5. 写 `.flow-status.json`（node:N6）。
