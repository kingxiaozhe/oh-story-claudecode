# N8 收尾

批量目标完成或卷完成时执行。

1. **卷末伏笔核对**（卷完成时）：`追踪/伏笔.md` 全量过账——本卷应回收未回收的列成清单，逐条定性：顺延下卷（改账）/ 已废弃（标注理由）/ 遗漏（决策卡：补章或下卷补救）。
2. **卷报告**：METRICS 汇总——平均轮次、首稿欠字率、人工介入次数与原因分布、waive 清单、冷读均分曲线；对照 architecture.md 试点验收指标给出达标结论。落盘 `追踪/卷报告_第{X}卷.md`。
3. **自然完结判定**：对照 `大纲/大纲.md`——全书主线义务是否已解决？已解决 → 提示用户进入完结流程（尾声/番外规划），**不机械续卷凑字数**；未解决 → 汇报下一卷入口状态。
4. 写 `.flow-status.json`（node:N8，state:"done"，detail 大白话总结）。
5. 向用户输出总结：本次完成章数、METRICS 要点、待人工事项（决策卡积压、waive 复核建议）。
