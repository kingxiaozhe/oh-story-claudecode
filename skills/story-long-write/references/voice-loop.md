# voice-loop.md：段落级声口优化循环

> **用途**：写正文时，**不再整章一次性输出**，改成"写一段 → 立刻按本书声口指纹优化这一段 → 再写下一段"，周而复始。
> **触发**：当 `{项目}/设定/声口.md` 存在且含实质内容时，`workflow-daily.md` Step 2 与 SKILL.md Phase 4 的"写正文"环节路由到本文件执行。缺失则退回整章写法。
> **声口从哪来**：开新书时从仓库级 `声口库/` 按赛道挑条目实例化到 `设定/声口.md`（流程见 `声口库/README.md`）；库里没有对应赛道条目时，先按 README 的「新增条目流程」拆一本该赛道母本。**实例化后全书锁定，不换声口。**
> **目的**：① 立住"一个具体作者"的声口/人味（AI 检测最难抓的东西）；② 打断整章平滑的机器腔；③ 从结构上**根除逐段/逐章滚雪球的乱码**（本书 223–278 章逗号乱码即由此产生）。

---

## 0. 一条压倒一切的红线

> **每一段的优化，只锚 `设定/声口.md` 这个固定文件。永远不把"上一段刚写完的成品"当风格样板去模仿。**

声口只能向 `设定/声口.md` **收敛**，不能向自己的上一段**漂移**。凡是"让下一段学上一段的断句/语气词密度/腔调"的做法，一律禁止——那正是滚雪球的引信。上一段只提供**剧情承接**（发生了什么、人物状态到哪了），**不提供风格**。

---

## 1. 准备（每章开始时，一次性）

1. 读 `设定/声口.md`，把三样东西加载进工作记忆：
   - **§1 采纳区**的注入手法 + 每样的**每章上限配额**；
   - **§2 禁用区**（本书不采用的母本特征）；
   - **§5 语气词库**（分叙述/对话）。
2. 读本章细纲的**目标情绪/基调**，定本章声线主色：
   - 高压/生死/复仇兑现章 → **冷色为主**（压声线，网感与贱嘴让位）；
   - 日常/过场/斗嘴章 → **暖色为主**（放网感、贱嘴、生活比喻）。
3. 起一个**本章配额计数器**（心算即可）：拟声词、网感 beat、黑色幽默、生活比喻各用了几次，逼近上限就停用该样。

---

## 2. 逐段循环（本章正文的主体）

把本章按细纲情节点切成若干段（一段 = 一个动作单元/一次对话回合/一个镜头，通常 2300–3800 字的章约 8–14 段）。**对每一段**执行 A→D：

### A. 写草稿段
只用**剧情**上下文（细纲本点 + 上一段发生了什么）写出这一段的**功能草稿**，先把"说什么"写对，不追求声口。

### B. 声口优化（核心）
对照 `设定/声口.md` 优化这一段的"怎么说"：

1. **判该不该注入**：看这一段的基调 + 是不是合适的落点。**不是每段都注入**——一段通常 0–1 样金子，硬塞必烂。
   - 拟声词 → 只在物理冲击点（打/摔/砸/门/电话）；
   - 网感情绪 beat（`人名：？`）→ 只在多人同时反应或主角"看穿/无语"的瞬间；
   - 黑色幽默旁白 → 紧张过后或主角看穿对手时，段末一句冷话；
   - 生活化比喻 → 需要打比方时，只从菜市场/牌桌/老家/饭局/修车铺取喻；
   - 双声线 → 按本章主色收敛对话与旁白。
2. **查配额**：要注入的这样，本章是否已用满上限？满了就不加，改用普通动作/短句。
3. **删禁用**：这一段若混入 `设定/声口.md` §2 的禁用特征（省略号 `……`、破折号 `——`、`眸中闪过/深吸一口气/缓缓开口` 这类描写套路），当场删或改场内动作。
4. **语气词克制**：单段语气词 ≤2 个（或按 `声口.md` 规定）；感叹号对话峰值 ≤1 个，不叠 `！！！`。

### C. 段级自检（防雪球）
优化完，对**这一段**心算一次：
- **逗号是否明显多于这一段汉字的 1/6（≈16%）？** 多了就是滚雪球前兆，立刻把碎逗号收成正常断句。
- 有没有把一句话切成一串两三字的碎片？有就并回中短句。
- 语气词/beat 是否超了单段上限？超了删到达标。

**不达标不许进入下一段。**

### D. 承接下一段
锁定本段，写下一段。下一段：**剧情**承接本段结果，**声口**仍然只锚 `设定/声口.md`（回到 A，不参考本段的风格手感）。

---

## 3. 整章收尾（写完最后一段后）

1. 拼合全章，跑本书门禁：`python3 追踪/gate.py 正文/第{N}章-*.md`
   - **逗号密度 ≤16%**（防雪球硬红线）、对话 25–50%、字数、禁用词、章末钩子必须全绿；任一 FAIL 先定位修复再放行。
2. 跑 `node scripts/normalize-punctuation.js`（清无功能省略号/破折号）与 `node scripts/check-ai-patterns.js`（残余 AI 味）。
3. 章末**一句话反转钩**是否兑现（`声口.md` §1.5）。
4. 通过后再更新 `追踪/` 各文件，进入下一章。

---

## 4. 配额速查（默认值，以 `设定/声口.md` 为准）

| 声口手法 | 每章上限 | 落点 |
|---|---|---|
| 拟声词独立成行 | ≤4 | 物理冲击点 |
| 网感情绪 beat | ≤3 | 多人反应/主角看穿 |
| 黑色幽默旁白 | 2–3（点缀非主菜，高压段让位） | 紧张后/看穿对手 |
| 生活化比喻 | 1–2 | 需打比方处 |
| 单段语气词 | ≤2 | — |
| 逗号密度 | ≤16%（段级 + 章级） | 硬红线 |

> 若 `设定/声口.md` 与本文件默认值冲突，**以 `设定/声口.md` 为准**（它是本书声口的权威锚点）。

---

## 5. 反面清单（做了就是在制造乱码）

- ✗ 让下一段模仿上一段的断句/语气词密度/腔调。
- ✗ 每段都硬塞声口手法，不看配额和落点。
- ✗ 为"显得有节奏"把句子切成一串两三字碎片 + 逗号。
- ✗ 把母本（三九音域）的省略号海/眸系描写照抄进正文。
- ✗ 段级自检不过就往下写。
