# 细纲（第 1 章）

### 第 1 章：上门收田
- 核心事件：周氏宝行限三日收走最后三亩灵田，沈砚在契书前觉醒《度支簿》
- 字数目标：3200 字
- 目标情绪：紧张压迫中透出一线翻盘的期待
- 章节定位：高压
- 章首钩子：危机开局 — 开篇第一句即"收田文书拍在田埂上"，300 字内主角登场
- 爽点：金手指首秀（1000 字内出现期待点：账簿显形，看穿契书隐性条目）

#### 内容概括（五段式）
- 起因：三年债务到期，周氏宝行要以"本息重算"收走沈家最后三亩灵田
- 发展：周奎宣文书、村邻围观议论（背景融入冲突）、沈栖霞对峙被"按契来办"压住
- 转折：沈砚细看契书时家传无字旧账发烫，觉醒估值之眼，看见"息转本·违例""风险：作伪"
- 高潮：沈砚试探性问利息总数，周奎随口报数与簿显不符——信息差建立，读者先于反派知道账有问题
- 结尾：三日之限落定；沈砚独自留田测试账簿能力边界，章尾账簿浮出小字：作伪的不是数目，是签名

#### 情节安排（多线）
- 主线推进：债务危机全面呈现 + 金手指觉醒
- 辅线推进：无
- 事件线 / 任务线：三日之约（本卷第一个倒计时）
- 任务卡点：无
- 感情线 / 关系线：无显性，但兄妹相依（檀递水/捡水车零件）与姑侄立场差已埋
- 逻辑线：债务到期（因）→ 上门收田（行动）→ 觉醒账簿发现契书疑点（结果）→ 三日内要么翻账要么失田（新问题）

#### 人物关系和出场顺序
- 出场顺序：沈砚 → 沈檀 → 周奎（带二护卫） → 围观村邻 → 沈栖霞 →（物件）收田文书、无字旧账
- 人物关系变化：无（立场呈现章）
- 视角/信息差：读者与主角同步得知"契书有诈"；周奎不知主角能看穿；围观者以为沈家必失田

#### 情节细化
- 情节点序列：
  1. 沈砚蹲在田里逐穗记谷数，审计习惯外化（数三遍、记两本）；檀送水【人物塑造·中250】
  2. 前世审计生涯+猝死的极简闪回（两句话带过，不停留）【背景·疏120】
  3. 宝行一行人进村，村道议论"沈家要绝了"（背景融入冲突）【信息揭示·中120】
  4. 周奎拍文书宣三日抵田，笑面条款【冲突开启·密250】
  5. 沈栖霞赶到拍桌对峙，被"都是规矩"压回【冲突升级·密250】
  6. 沈砚接契书细看，怀中旧账发烫，指尖发麻【转折·中150】
  7. 觉醒：视野浮现契书估值与隐性条目——"息转本·违例；风险：作伪"【金手指首秀·密550】
  8. 沈砚不动声色问三年利息总数，周奎随口报数，与簿显差五百余【信息差·密250】
  9. 周奎不耐限期三日，护卫踢翻田埂水车扬长而去【压迫+羞辱·中150】
  10. 家人反应三笔：檀默默捡零件、栖霞攥拳、砚盯契书出神【情绪落点·中150】
  11. 独自留田测账簿边界：看谷穗（估出今年产量）、看自己（浮出一栏刺眼的"负债"）【设定展示·密400】
  12. 决意外化：把"三日"刻上田头木牌，抱旧账箱回屋【决意·中150】
  13. 章尾：账簿在契书副本上再浮一行小字——数目没错，错的是签名【钩子·密250】
- 预算合计：3040 字（目标 3200，范围 3200-3520）→ 写作时第 7、11 点按上限展开补足
- 代价兑现 / 收益兑现：主角得金手指（收益），代价是初次使用后神识刺痛（限制首次露面）；家族背上三日倒计时

#### 结尾设定和钩子
- 结尾设定：三日之限悬顶；主角掌握两处疑点（复利违例+签名作伪）但尚无实证
- 章尾钩子：悬念式 —"签名作伪"直指做局，期待度：强；承接第 2 章连夜重算与家族会议
