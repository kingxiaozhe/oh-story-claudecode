# 细纲（第 21 章）

### 第 21 章：平前账
- 核心事件：下半卷开局。账库门槛验二缺一，赎票锁在当铺"待平账者取"，沈砚推演出唯一解——先把三千四百七十二的债平了，账一平，老掌柜才肯给赎票，赎票到手才能开第三重门槛。他立"平账专款"账，把家族全部进项拧成一股冲这个数；同日市易司将挂案死士结案（急病暴毙定论），合利号清尾坐实，活口线索彻底断绝，郡城方向已有生人打听三亩田
- 字数目标：3200 字
- 目标情绪：决然+暗流压境（从卷中点的震撼落回冷静谋算，压力换挡）
- 章节定位：推进（下半卷开局·目标锚定）
- 章首钩子：反差场景 — 老井上盖着一领旧草席、落着晨露，社户照常下田，只有沈砚知道草席底下三丈埋着先祖账库，而田埂外，两个面生的短打汉子正蹲着量田界
- 爽点：无显性爽点（目标锚定章）；往下看的理由：三千四百七十二这个天文数字，一个机动只有一百枚的破落户，怎么可能在对手动手前凑齐

#### 内容概括（五段式）
- 起因：账库开而未全开，赎票是唯一缺口，赎票的门槛是"平账"——沈砚必须把 3472 的债真金白银平掉
- 发展：沈砚在度支簿"账库"页下推演三条线（老掌柜守诺"账没平不给"、市易司备案是"账平"的公认凭证、平账等于把田从债里赎干净），定下"平账专款"新账，与运营机动分开记；盘点现有进项（万宝楼包销、沈记零售、温丹炉扩产、合作社），算出按现速要一年以上
- 转折：市易司差役再登门，正式将挂案死士以"急病"结案，合利号清尾坐实；同日云阔回报田埂外有郡城口音的生人量田界、打听"这三亩地卖不卖"——对手的手已经从账面伸到田边
- 高潮：沈砚意识到慢不得——账库一天不全开，田下之物一天是合利号眼里的肥肉；他把包销首月放量结算的净利一百五十枚整个拨进平账专款，专款破零
- 结尾：正盘算怎么把进项翻几十倍，当铺老掌柜遣人捎来口信：郡城总号托人问，沈记的散剂方子，肯不肯"论个大价钱"

#### 情节安排（多线）
- 主线推进：账库线转入"筹钱平账取赎票"的下半卷主任务，目标数字锚定 3472
- 辅线推进：死士灭口线收口结案（F001活口断绝，指认改走摹书人/坐堂人路线，留 38-40 章）；合利号压境从账面转向田边（生人量田）；父亲那笔并入"前账"待解
- 事件线 / 任务线：立"平账专款"账户，第一笔一百五十枚入账，冲刺计时开始
- 感情线 / 关系线：祖父自"账在人就没亡"翻篇后主动过问家计，与沈砚形成"守秘同盟"；栖霞领命加固田防
- 逻辑线：账库缺赎票（因）→ 赎票要平账、平账要巨款（推演）→ 立专款、进项拧一股（行动）→ 对手已到田边、慢不得（新压力）→ 郡城总号问方子（下一章大生意引信）

#### 人物关系和出场顺序
- 出场顺序：沈砚（度支簿账库页推演）→ 沈云阔（回报生人量田）→ 市易司差役（死士结案）→ 沈奉山（过问家计、守秘同盟）→ 沈栖霞（加固田防）→（物件）度支簿"平账专款"新页、当铺老掌柜口信
- 人物关系变化：家族从"翻身经营团队"转为"守库+冲刺平账"的紧绷战时协作；祖父由愧疚退隐转为主动参谋
- 视角/信息差：读者与沈砚同知"平账=赎票=开账库"的连锁，但合利号只知田下有物、不知为账库（内部档案）；生人量田的来路（合利号台面人物的先声）读者与沈砚均未明
