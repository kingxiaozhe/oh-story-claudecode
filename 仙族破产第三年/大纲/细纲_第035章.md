# 细纲（第 35 章）

### 第 35 章：白鹤先生
- 核心事件：三日限期，沈砚顺着"润笔银"那条线，在郡城背巷找到摹书人白仲——诨号"白鹤先生"，一个替人摹百家签押、字画代笔的落魄手艺人，早年被合利号豢养、专做见不得光的活。沈砚不硬闯，先以度支簿看穿他（代价太阳穴刺痛），验出这人"惧、悔、惜命，非死士"，是个被拿捏的可翻之人；再拿当年那纸伪契底档拍在他面前，指出摹本上一处只有本人才有的运笔习惯（末笔左勾的暗记）——白仲当场泄了气。沈砚给他一条活路（照实作证、都察院护他一命，胜过给合利号灭口），白仲松口：那道假签押是他摹的，可下令的、给润笔的，不是周奎——是万宝楼里合利号的坐堂人，一个坐在账房最里间、外人见不着面、只闻其名的人。名字，白仲吐了出来。伪契的手、下令的人，链条第一次接到了根上
- 字数目标：3300 字
- 目标情绪：悬疑追查→寒意认知（顺线找人的紧、翻人的智斗，末了顺出坐堂人名字时对手之深的彻骨寒，情绪强度 7.5）
- 章节定位：高压（找摹书人+坐实伪契+坐堂人身份浮出，F001 链条指认攻坚）
- 章首钩子：神秘独白 — "摹一辈子别人的字，到头来连自己的名字都不敢往契上落。"背巷里那个替人代笔的手，第一次听见有人来问三年前那道签押
- 爽点：连环智斗爽+认知冲击（一：度支簿看穿白仲"可翻之人"、以运笔暗记当场戳破他摹的伪契，翻人如翻账；二：给活路换口供，白仲松口"下令的不是周奎、是合利号坐堂人"，伪契链条从"周奎执行"直接接到坐堂人身上，F001 指认坐实到名字级——认知冲击压过爽）

#### 内容概括（五段式）
- 起因：三日限期紧扣，沈砚顺"润笔银"线在郡城背巷找到摹书人白仲（白鹤先生）
- 发展：白仲早年被合利号豢养、专做摹签押的暗活，如今落魄；沈砚不硬闯，以度支簿看穿他"惧、悔、惜命、非死士"，是被拿捏的可翻之人
- 转折：沈砚拿伪契底档拍在案上，指出摹本上一处只有本人才有的运笔暗记（末笔左勾，与担保存根、内账笔迹同源）——白仲当场泄气，认出这是自己的手
- 高潮：沈砚给白仲一条活路（照实作证、都察院护命，胜过等合利号像灭死士那样灭他的口）；白仲松口——假签押是他摹的，但下令、给润笔的不是周奎，是万宝楼账房最里间那位合利号坐堂人；名字吐出（岑谳），伪契链条第一次接到根上
- 结尾：沈砚把白仲的口供要点记牢、安排他次日随往都察院作证；退出背巷，坐堂人那个名字压在心口——原来这三年，云溪那盘棋从头到尾，是这个见不着面的人在拨；他抬头望万宝楼，那扇最里间的窗，正是他往后要算的账

#### 情节安排（多线）
- 主线推进：F001 链条攻坚——摹书人白仲坐实伪契出自其手、坐堂人岑谳身份/名字浮出（指认到名字级），"债脏"三证凑齐，撤令反杀的最后一证到位
- 辅线推进：F008（顾迟舟担保存根同一支笔）与白仲运笔暗记互证；F007（内账）与白仲口供互证——周氏—合利号—万宝楼—坐堂人一条链彻底串起；坐堂人岑谳作为二卷更大之手的引信浮出（F012 铺垫）
- 事件线 / 任务线：找摹书人+翻口供+坐实链条，郡城收网攻坚战
- 感情线 / 关系线：白仲（被拿捏的手艺人）从合利号弃卒转为沈家污点证人（给活路换真话，镜像吴账房、李牙人"验其可翻则收"的手法）；沈砚对"看不见的对手"第一次有了具体的名字
- 逻辑线：顺润笔线找到白仲（行动）→ 度支簿看穿+暗记戳破（翻人）→ 给活路换口供（破局）→ 坐堂人名字浮出、链条接根（认知，钩向都察落判与二卷更大之手）

#### 人物关系和出场顺序
- 出场顺序：白仲（背巷摹书人，独白登场）→ 沈砚（顺线找到、度支簿看穿）→（物件）伪契底档、运笔暗记、润笔银支出条、度支簿 →（浮出/未露面）合利号坐堂人岑谳（名字被吐出，本人不露面）→ 万宝楼里间的窗（意象）
- 人物关系变化：新增污点证人白仲（合利号弃卒→沈家证人）；对手升级——幕后"没写名字的债主"第一次有了名字（岑谳），坐堂人从纯内部档案浮到台面指认级；沈砚的对手认知从"合利号/卫敬之"直抵坐堂人本人
- 视角/信息差：读者与沈砚终于知道坐堂人的名字与位置（万宝楼里间），但本人未露面、够不着（留二卷）；白仲只知自己受岑谳指使摹签押、不知账库（他不在账库知情圈）；对手（岑谳）尚不知白仲已被翻、口供将上都察院（悬念增殖，灭口风险悬顶）
