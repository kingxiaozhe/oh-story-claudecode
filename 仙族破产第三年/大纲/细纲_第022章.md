# 细纲（第 22 章）

### 第 22 章：更大的生意
- 核心事件：郡城总号托娄清转达——要买回气散方子，一次性论个大价钱。沈砚将计就计，不卖核心，只把"乙级配方"（六成成色的可复制工序，剥离厚壤诀藏字诀+檀引药的灵根核心）拆出来分级授权，既换大额现金冲平账，又保住八成甲级的护城河；但他心里清楚，这笔钱来自合利号的躯壳万宝楼，等于拿敌人的钱去平敌人的债，还会暴露沈家急需大钱
- 字数目标：3200 字
- 目标情绪：机锋+步步为营（智斗博弈的期待感，糖里藏刀的警觉）
- 章节定位：推进（智斗·大生意提案）
- 章首钩子：悬念对话开局 — 娄清一句"沈掌柜，郡城总号这回是真金白银来的，你开个数"，把一张空白契纸推到桌心
- 爽点：小爽（沈砚把"整卖方子"反拆成"分级授权"，既拿钱又不交命脉，当场把娄清的算珠敲停半拍）；核心期待：这笔大钱能不能安全落袋、又不被反噬

#### 内容概括（五段式）
- 起因：郡城总号经娄清抛出"买断回气散方子"的大价钱意向，沈砚赴松鹤楼再谈
- 发展：沈砚用度支簿看透这笔"买断"的真意（把沈家从供货商变成一次性卖光工艺的空壳，日后郡城市场再无沈记），当场拒绝买断，反手拆出"分级授权"方案——乙级配方（六成，需高原料耗、不含灵根核心）授权万宝楼郡城量产，甲级八成沈家独留
- 转折：娄清算珠停半拍——他没料到沈砚肯把工艺往外放，更没料到放的是"教得会却学不到顶"的半套；试探压价与加独家条款，被沈砚以"要么授权、要么连乙级也没有"顶回
- 高潮：双方谈拢框架——一次性授权金两千四百枚、分签约首付与交付验收尾款两笔，另按郡城乙级产量抽成；娄清笑称"总号那边要派个人来过契"，沈砚心头一动（对手要派台面人物）
- 结尾：沈砚回程给栖霞算这笔账的两面——一面是平账专款一次能跳一大截，一面是教了对手半套工艺、还等于向合利号亮了"沈家急着凑大钱"的底牌；他在度支簿写下"这笔钱，是钓钩，也是刀"

#### 情节安排（多线）
- 主线推进：为平账专款锁定最大一笔来源（授权金两千四百枚，分两笔），冲刺路径成形
- 辅线推进：合利号台面人物预告（"总号派人来过契"，为第 23 章卫敬之登场埋线）；护城河风险（工艺外流）显性化；F011 授权契暗条款的伏笔起点（尾款附条件）
- 事件线 / 任务线：分级授权契谈判——大生意框架敲定，待签
- 感情线 / 关系线：娄清与沈砚"看得懂账的对手"镜像关系深化（亦商亦敌）；栖霞对"教对手工艺"的本能抵触与沈砚的算账权衡
- 逻辑线：总号抛买断（因）→ 沈砚拆分级授权自保护城河（反制）→ 框架谈拢、总号要派人过契（结果）→ 暴露平账意图+工艺外流+对手台面人物将至（多重新风险）

#### 人物关系和出场顺序
- 出场顺序：娄清（抛买断意向）→ 沈砚（拆分级授权反制）→ 沈栖霞（雅间旁观、回程算账）→（物件）空白授权契、度支簿浮字、玉衡算珠
- 人物关系变化：娄清（正价包销合作方→大额授权对家，博弈层级升高）；沈砚从"守成经营者"转为"敢用护城河边角换战略现金"的操盘者
- 视角/信息差：读者与沈砚知授权是"钓钩也是刀"、乙级是留了灵根后手的半套；娄清不知沈砚急需大钱的真因（平账取赎票开账库）；总号（合利号坐堂人）要派谁来、为何来，读者与沈砚均未明
