# 细纲（第 2 章）

### 第 2 章：重算这笔账
- 核心事件：连夜重算三年账目坐实多收，家族会议上路线之争，祖父交印信，定下三日翻账计划
- 字数目标：3200 字
- 目标情绪：压抑中转向决然（读者跟着把账算明白，产生"稳了"的期待）
- 章节定位：推进
- 章首钩子：承接式 — 开篇即摊开三年账册，第一笔就对不上
- 爽点：无显性爆发，但有"账目一笔笔现形"的解谜快感（期待点密集）

#### 内容概括（五段式）
- 起因：签名作伪查无实据，主角决定先打赢能打赢的仗——复利违例
- 发展：审计蒙太奇：借估值之眼+前世底稿功夫，三年流水重算，坐实多收五百七十三枚灵石；同时发现利息流向的疑点（每季利息并未全入周氏账，有一股流向不明——F007 埋设）
- 转折：家族会议爆发路线之争：栖霞主张卖田止损、送檀考宗门；砚拿出重算结果主张翻账
- 高潮：沉默三年的祖父开口："沈家的字，不下跪。"将家主印信正式交给沈砚
- 结尾：分工落定（栖霞护卫同行、二叔稳田、檀守家），砚宣布明日去处——不是宝行，是县衙市易司备案处

#### 情节安排（多线）
- 主线推进：翻账依据坐实；主角获得正式决策权
- 辅线推进：F007 利息流向疑点（暗线首针）
- 事件线 / 任务线：三日之约第二日
- 任务卡点：查旧账缺三年前原始借契副本 → 卡出"副本在市易司备案"这一信息（引出第 3 章战场）
- 感情线 / 关系线：姑侄冲突公开化（本章前隐性 → 本章后对立但同行）
- 逻辑线：疑点（因）→ 重算+开会（行动）→ 获得授权与依据（结果）→ 实证仍在官府底档（新问题）

#### 人物关系和出场顺序
- 出场顺序：沈砚 → 沈檀（陪夜研墨） → 沈栖霞 → 沈云阔 → 沈奉山 →（物件）家主印信、三年账册
- 人物关系变化：祖孙（托付）；姑侄（隐性分歧→公开对立→勉强同行）
- 视角/信息差：主角知道多收数目与利息流向疑点；家人只信一半；读者比家人多知道 F007 一层

#### 情节细化
- 情节点序列：
  1. 深夜账房，第一笔对不上：息转本的滚算起点被前移了一季【解谜开场·密250】
  2. 审计蒙太奇：三本账并排、灵石流水逐季勾稽，多收累计五百七十三枚【过程爽·密400】
  3. 估值之眼代价显形：太阳穴刺痛、鼻血，檀默默递帕（能力限制+兄妹戏）【代价+温情·中150】
  4. 疑点旁逸：每季利息有一股没入周氏总账，去向标"不可测"【F007 埋设·密250】
  5. 天亮，家族会议开场，栖霞先发：卖田、止损、送檀考宗门，条条现实【冲突·密300】
  6. 砚摊账：多收的数、违例的条、三日的打法；两案对撞【对峙·密300】
  7. 二叔和稀泥、族老观望（群像一笔）【过场·疏40】
  8. 祖父出屋。三年来第一次坐上主位，全场静【转折·中150】
  9. "沈家的字，不下跪。"交印信；一句话点破砚的软肋："账要算明白，人不能算没了。"（主题句首次落地）【高潮·密400】
  10. 分工落定；栖霞撂话"输了就听我的卖田"（关系留扣）【推进·中150】
  11. 章尾：砚收印信入怀，说明日去市易司调三年备案底档——"公账，压死私账。"【钩子·密250】
- 预算合计：2640 字（目标 3200，范围 3200-3520）→ 写作时第 2、5、6、9 点按上限展开补足
- 代价兑现 / 收益兑现：主角获印信与家族授权（收益）；接下"输了卖田"的赌约（后续账）；神识透支伏下限制

#### 结尾设定和钩子
- 结尾设定：依据在手、授权在身，缺的是官府底档实证；三日之约只剩一日
- 章尾钩子：期待式 — 战场从宝行柜台换到市易司公堂，期待度：强；直接承接第 3 章当众对账
