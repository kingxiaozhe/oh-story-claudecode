# 细纲（第 32 章）

### 第 32 章：三证
- 核心事件：沈砚要把这盘烂账捅到郡里，先得把状纸和证据凑齐、找到递上去的门路。他去市易司找司官——司官偏沈却怕事，压不住郡里朱印，却肯在暗处指一条道：郡里有个管纠劾的都察，姓韩，认程序、恶越权、不吃万宝楼这一套；查封令绕过县衙、缺关防、无勘验，本就是越权，都察那里能翻。司官私下写了一纸呈文作引荐，但把丑话说前头：要撬动都察，光有程序破绽不够，得证明"这债本身就脏"。沈砚回头清点三证——吴账房的内账（债权转卖 F007）、顾迟舟担保存根（同一支笔）、当年那纸伪契底档（F001）。翻内账时，一笔"润笔银"支出跳了出来：三年前，周氏替谁付过一笔摹书人的润笔——那纸伪契的签押，是花钱请人摹的。摹书人，有名有姓，人在郡城
- 字数目标：3300 字
- 目标情绪：谋算凝重→一线微亮（备状找门路的冷静推演，末了从一笔旧账里翻出通向伪契源头的活口线索，情绪强度 6）
- 章节定位：推进（备状三证+司官暗助+摹书人线索浮出）
- 章首钩子：悬念对话开局 — 市易司后堂，司官把那纸查封令抄件推回沈砚面前，压低声音"这文书下得太快、太脏，你要真想翻，云溪翻不了，只有一条道——郡里，都察院"
- 爽点：小爽点一处（司官暗助递呈文引荐都察，本地怕事的官第一次主动为沈家指路）+ 悬念增殖（内账里翻出"润笔银"一笔，伪契源头指向郡城一个有名有姓的摹书人，F001 活口从"断绝"重新接上）

#### 内容概括（五段式）
- 起因：沈砚定了赴郡里都察申诉的路线，先到市易司探门路、凑状纸
- 发展：司官偏沈却压不住郡里朱印，私下点破一条道——郡里都察韩宗礼认程序、恶越权、不吃万宝楼这套，查封令越权可诉；司官写呈文引荐，但把丑话说前头：撬动都察，得先证"这债本身脏"，光程序破绽不够
- 转折：沈砚回头把三证摊开清点——吴账房内账（债权三年前转卖合利号，周氏代收，F007）、顾迟舟担保存根（末笔左勾同一支笔，F008 侧）、当年伪契底档（签押摹写，F001）；三证能证债脏，却都指向一个没露过面的手——那个摹签押的人
- 高潮：核对吴账房背出的内账时，一笔三年前的"润笔银"支出跳出来——周氏替"上头"付过一笔摹书人的润笔；沈砚顺藤查出这摹书人有名有姓、诨号"白鹤先生"、人在郡城，专替人摹百家签押；伪契那道假签押，就出自他的手（F001 活口线索从"死士灭口断绝"重新接上，且这条不在死牢里、在郡城）
- 结尾：沈砚把三证与摹书人线索一并记进度支簿，定下郡城之行的双重目的——递状撤令、顺线拿下摹书人的口供；他把司官的呈文仔细收好，抬眼对栖霞说"这一趟，是去他们家门口，把他们的老底翻出来"

#### 情节安排（多线）
- 主线推进：赴郡里都察申诉的门路打通（司官呈文引荐都察韩宗礼），撤查封令的程序反杀正式立项
- 辅线推进：F007（内账坐实）+F008（担保存根同一支笔）+F001（伪契底档）三证合成状纸证据链；F001 活口线索重新接上——摹书人"白鹤先生"（白仲）浮出，人在郡城；F011（连环）作为"债脏"的收尾一环并入状纸
- 事件线 / 任务线：备状+探门路+翻出摹书人线索，收网第二步
- 感情线 / 关系线：司官从"偏沈却怕事"到"暗处主动指路"（12-31 章程序战积累的官面信任兑现）；吴账房作为人证的价值再兑现（内账背出润笔银这一笔）
- 逻辑线：本地无解、须捅郡里（前情）→ 司官指都察门路、要证债脏（门路+条件）→ 清点三证发现都指向摹书人（缺口）→ 内账翻出润笔银、摹书人浮出郡城（活口接上，钩向郡城之行）

#### 人物关系和出场顺序
- 出场顺序：市易司司官（推回抄件、暗助指路）→ 沈砚（探门路清点三证）→（当铺后院/记忆）吴账房（内账背出润笔银）→ 沈栖霞（听定郡城之行）→（物件）查封令抄件、司官呈文、吴账房内账、顾迟舟担保存根、伪契底档、"润笔银"支出条、度支簿
- 人物关系变化：司官对沈家的偏向从"堂上站台"升级为"私下递呈文、指郡里门路"（怕事官的最大让步）；吴账房内账的证据价值从"追账"升级为"撬郡都察的债脏铁证"
- 视角/信息差：读者与沈砚知三证+摹书人是撬都察的关键；司官不知账库、只当沈家在打债务官司；对手（合利号）不知沈砚已顺出摹书人这条线、要去郡城翻他们老底（账库仍保密，沈砚对官府只谈债脏不谈田下）
