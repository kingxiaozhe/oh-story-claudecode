# 《仙族破产第三年》全书大纲（卷级鸟瞰）

- 预计总字数：150 万起步（可续）
- 目标平台：起点男频 · 仙侠·修真文明
- 一句话梗概：审计师穿越成破产修仙家族的少年家主，靠一本能看穿隐性成本与收益的祖传账簿，从清点三亩灵田开始精打细算，一步步把沈家从债务泥潭里捞出来，最终清算整个修真界做了千年的假账。

## 卷级大纲

### 第一卷：三亩灵田（约 13 万字，40 章）
- 功能：铺垫+起步+第一个大爽点循环（县城层）
- 核心事件：翻旧账保祖田，还清首期债，反割周氏宝行；发现三亩田下的秘密与做局者"合利号"的线头
- 起始状态 → 结束状态：被上门收田的破落户少主 → 云溪县立住脚的"沈小掌柜"；炼气三层 → 六层；债务 4200 → 首期清偿+资产回血（一间铺面+灵植合作社）

### 第二卷：生息（约 25 万字，郡城层）
- 功能：产业起步+对手升级
- 核心事件：进青阳郡对垒万宝楼；沈檀入天衡宗测灵引出宗门线；赎回祖产、解开祖父封灵契的第一道枷锁；确认顾迟舟"死遁"存疑
- 起始状态 → 结束状态：县城小掌柜 → 郡城有字号的"沈记"；家族恢复仙族名分

### 第三卷：对冲（约 30 万字，宗门层）
- 功能：规则升级——从做买卖到做庄
- 核心事件：宗门经济战，仙缘券市场博弈；封灵契黑幕初揭（划走的修为去了哪）；父亲沈云舟的足迹浮出
- 起始状态 → 结束状态：商号 → 商盟；主角筑基

### 第四卷：挤兑（约 30 万字，州府层）
- 功能：最大危机+最大反杀
- 核心事件：对手以金融绞杀沈家（抽贷、挤兑、封盘），主角策动全州"挤兑"反杀，灵石本位动摇
- 起始状态 → 结束状态：商盟 → 州级世家；找到父亲（或其留下的最终线索）

### 第五卷：铸币（约 30 万字，仙朝层）
- 功能：世界观揭底的前奏
- 核心事件：入主/对抗仙朝度支司，重订天下灵财规则；《度支簿》来历揭开——仙庭崩塌之夜的真相
- 起始状态 → 结束状态：世家 → 执天下灵财之柄者

### 最终卷：平账（约 20 万字）
- 功能：高潮+收尾
- 核心事件：清算"平不了的账"——谁在向天下人收暗税；主角以账证道，平天下账
- 收束：家族线（沈家复兴圆满）、父亲线、账簿线三线合一

> 卷内节奏、爽点循环见各卷卷纲；细纲一章一文件。
