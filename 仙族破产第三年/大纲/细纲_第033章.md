# 细纲（第 33 章）

### 第 33 章：起灶前
- 核心事件：赴郡城前最后一次积蓄。田还封着、账还压着，可日子得往前过——沈记复业、包销续单、合作社趁保卫战后人心最齐的势头开三期扩户，几笔进项一点点把家用机动填回来。沈砚不动那口三千四百七十二的原箱（那是要平账的命根），只拿挣来的散钱给自己配了一副最省的修炼组合，趁郡城之行前把自己那口气再垫高一层——炼气六层。檀入天衡宗的行装也趁这几笔进项凑齐了最后一半。祖父守着封田不肯挪窝，说"等你从郡里回来，这封条就该揭了"。暖是暖，可查封令还贴在田头，郡城那头，卫敬之回去见的那个人，正等着沈砚自己送上门
- 字数目标：3300 字
- 目标情绪：暖+蓄势→尾凉（战后人心最齐的一次经营暖场与自我垫高，末了压回"郡城有人等着"的凉，情绪强度 6）
- 章节定位：低压蓄势（合作社三期+沈砚炼气六层+备行装，郡城之行前的喘息与积蓄）
- 章首钩子：反差场景 — 打谷场上合作社三期扩户按手印、新社户笑得合不拢嘴，二十步外的田头，那张郡里查封令的封条正被风掀着一角
- 爽点：双爽点（一：合作社三期扩户落地，护田同盟转成入社红利，人心资产扩容；二：沈砚以自有散钱配最省组合突破炼气六层，"这一层是拿挣来的钱堆的，没欠谁、没动平账的命根钱"，卷内修为目标达成）

#### 内容概括（五段式）
- 起因：郡城之行在即，沈砚趁保卫战后人心最齐、经营复苏，做行前最后一次积蓄
- 发展：合作社开三期扩户——护田出过力的几户外村丹农正式入社，社账内部启动金调度（不动沈家平账专款）；沈记复业续单、包销续供，几笔进项把家用机动填回；檀入天衡宗行装趁进项凑齐最后一半（二卷宗门线钩）
- 转折：沈砚拿挣来的散钱（不动三千四百七十二原箱）配一副最省的修炼组合（药浴自制+回气散自用库存+聚灵位余热，沿第 9、26 章"以账喻修"框架），趁行前闭一小关
- 高潮：当夜突破炼气六层，立意"这一层，是拿挣来的钱一点点堆上来的，没欠谁，也没动平账的命根钱"（卷内修为目标达成，资源配置驱动非顿悟，代价曲线自洽）
- 结尾：出关适逢三期首笔进项归拢与家中账面盘点（护田同盟、三期扩容、修为进六层、行装齐备），祖父守着封田说"等你从郡里回来，这封条该揭了"；暖场落定，沈砚收拾行装，抬眼望郡城方向——卫敬之回去见的那个人，正等着他自己送上门

#### 情节安排（多线）
- 主线推进：郡城之行前的积蓄完成（家用回血备使费、行装齐备），修为进六层，收网段蓄势收口
- 辅线推进：合作社三期扩户（护城河再扩，人心资产兑现）；檀入天衡宗行装凑齐（F005 二卷宗门线钩）；F010 尾凉（卫敬之回郡见坐堂人，等沈砚送上门的悬念增殖）
- 事件线 / 任务线：经营积蓄+闭关突破+备行装，郡城之行前的最后一站
- 感情线 / 关系线：合作社三期新社户的归属感、栖霞（伤愈）检点行装与护田交接、祖父守封田"等你回来揭封条"的托付、檀行装齐备的宗门线暖钩
- 逻辑线：郡城之行在即（前情）→ 趁人心最齐经营积蓄+自我垫高（行动）→ 三期落地、进六层、行装齐（积蓄成果）→ 郡城那头有人等着自投罗网（尾凉，钩向入郡）

#### 人物关系和出场顺序
- 出场顺序：郑老栓+赵伯+新入社丹农（三期扩户按手印）→ 沈云阔（社账启动金调度）→ 沈檀（行装凑齐+记账）→ 沈砚（配组合闭关）→ 沈栖霞（伤愈检点行装、护田交接）→ 沈奉山（守封田托付）→（物件）合作社社账、修炼组合、聚灵位、行装单、查封令封条
- 人物关系变化：合作社从"护田同盟"升级为"三期扩户的利益+情义共同体"；沈砚修为炼气五层→六层（卷内目标达成）；栖霞伤愈归位护田、与沈砚完成郡城之行的护家交接
- 视角/信息差：读者与沈砚知这是行前积蓄、修为垫高为郡城硬仗做底；社户只知扩户分红、不知账库与郡城之行的凶险；对手（坐堂人）等着沈砚送上门（悬念增殖，读者知沈砚将主动入虎穴）
