# 细纲（第 44 章）

### 第 44 章：郡城无沈记
- 核心事件：檀入宗后，沈砚回头给沈记在郡城找落脚立字号，处处碰壁——郡城牙行邢六带看的铺面接连被搅（刚被定下 / 租金翻数倍 / 房东临时变卦），字号注册在市易/商会被卡，处处是万宝楼郡城这只手（管事冯三出面、大掌柜裴衍名号压来）在封路。憋屈压抑。沈砚不与万宝楼主场硬碰，转向账库分账变现——依昨夜第一进记下的「云溪分库杂项分账」一条线（指向郡城旧账庄「广济号」库底一批被当死物压价的度支司旧制灵材），用度支簿验出真价与虚价的信息差，低价定下、布郡城字号第一桶金局，既是启动本钱也是破封路的暗手。章尾万宝楼郡城管事冯三放话立威。
- 字数目标：3400 字
- 目标情绪：压抑/憋屈→冷决（主场排挤的憋屈 → 转身布局的冷决，强度 6→7；双 W 之 W1 下压段）
- 章节定位：高压（万宝楼主场第一波摩擦 · 下压 + 账库分账捡漏布局，强度 6-7）
- 章首钩子：悬念对话开局 — 「沈记？云溪来的？」牙行邢六话一出口，眼神就飘了，「这铺面……方才刚被人定下了。」
- 爽点：无显性打脸（下压章），以「捡漏低买布局的暗爽 + 破封路暗手已落子的期待」承接（核心梗循环：主场吃亏，这封路怎么破——先捡漏拿本钱）；显性爽点释放留 45 章
- 章尾钩子：承诺/威胁 — 万宝楼郡城管事冯三撂话：「青阳郡的字号，不是谁想挂就挂得起来的。沈公子，云溪那点本事，出了云溪，就不好使了。」

#### 内容概括（五段式）
- 起因：檀入宗后，沈砚请郡城牙行邢六带看铺面，要给沈记在郡城找落脚立字号
- 发展：铺面接连被搅（刚被定下 / 租金翻数倍 / 房东临时变卦），字号注册在市易/商会被卡，处处是万宝楼的手；大掌柜裴衍名号压来，郡城台面对手轮廓浮出
- 转折：沈砚不与万宝楼主场硬碰（正面吃亏是送上门），转向账库分账——依「云溪分库杂项分账」记下的一条线（指向郡城旧账庄「广济号」库底一批被当死物压价的度支司旧制灵材），用度支簿验真价虚价的信息差
- 高潮：捡漏布局落子——度支簿验出这批旧灵材实有价（郡城识货者不识、被压成死物），低成本定下（付定金约 12 枚，30→18），是郡城字号的启动本钱，也是绕开万宝楼封路的暗手；账目吃紧但方向立住
- 结尾：憋屈未消，棋已落子；章尾万宝楼郡城管事冯三放话立威
