# 细纲（第 41 章）

### 第 41 章：交田不交账
- 核心事件：第一卷收卷后的过渡 + 新程起点。账库第一进开门次日，沈砚把云溪产业（灵植合作社 / 沈记零售 / 温丹炉 / 账库守护）一一交托分工，摊开进郡本钱账，正式定下「进青阳郡」战略——承接卫敬之「郡城，再算」、合利号索回授权金 2400 的悬顶、账库分账要在郡城才读得通、檀入学在即，四条都指向郡城，遂定「云溪守成、主攻郡城」。栖霞要同去被按住守家守账库井口，定云阔随行。全家新目标立起：郡城立「沈记」字号、恢复沈家仙族名分。章尾天衡宗春季纳新期限文书到，入郡有了死线。
- 字数目标：3400 字
- 目标情绪：沉静→决然（账库开门后三年来头一回踏实的清晨 → 定策进郡的决然，强度 5→6）
- 章节定位：低压过渡（新卷开局 · 战略定盘 + 分工交托，强度 5-6）
- 章首钩子：反差场景 — 账库开门次日破晓，沈家院里一边是三年来头一回踏实的清晨，另一边是沈砚已在度支簿上盘那本更大的、郡城的账
- 爽点：无显性打脸爽点（低压过渡章），以「格局跃升的决然感 + 进郡本钱抠算的期待点」承接读者（核心梗循环：这笔郡城的账怎么破）
- 章尾钩子：倒计时 — 天衡宗春季纳新文书送到，「月内到宗测灵注册，逾期作弃」，入郡死线落定

#### 内容概括（五段式）
- 起因：账库第一进开门次日，家里三年来头一回安生——债清、二十七亩田赎回、祖父气色回涌、栖霞丹尾款有了着落；沈砚却已在度支簿上盘郡城的账
- 发展：沈砚召集全家，把云溪产业交托分工——合作社日常交云阔 + 郑老栓，沈记零售与温丹炉留人守着，账库守护（田头老井）交祖父守、栖霞轮值；归拢本季进项作进郡本钱
- 转折：沈砚亮出「进青阳郡」战略——卫敬之「郡城，再算」不是虚话，合利号索回授权金 2400 的刀悬着，账库分账得在郡城才读得通，檀入学在即，四条都指向郡城；定「云溪守成、主攻郡城」
- 高潮：分工落定 + 账目摊开——进郡本钱缺口（机动 43 + 云溪本季结算约 25，束脩三十两灵银压顶，栖霞 205 专款不动），沈砚定「云溪产业持续供血 + 账库分账变现」两条腿走；栖霞要同去被按住守家守账库井口，定云阔随行
- 结尾：全家新目标立起（郡城立「沈记」字号、恢复沈家仙族名分）；章尾天衡宗纳新文书到，月内注册逾期作弃，入郡死线落定

#### 情节安排（多线）
- 主线推进：定「进青阳郡」战略、云溪产业交托分工、进郡本钱盘点（从「云溪守成」转「郡城主攻」的格局跃升）
- 辅线推进：账库守护留守安排（F002 账库线转入长期守护）+ 账库分账变现线索（F002 推进引信：昨夜第一进惊鸿一瞥里记下一册「云溪分库杂项分账」，是进郡第二条腿）；仙族名分作为本卷家族目标立起（F014 新埋引信）
