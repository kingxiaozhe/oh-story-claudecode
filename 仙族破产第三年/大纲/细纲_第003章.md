# 细纲（第 3 章）

### 第 3 章：公账对私账
- 核心事件：市易司当众对账，拆穿息转本复利与阴阳契书，三亩田解押、多收吐还；账簿看出田下"估值不可测"
- 字数目标：3400 字
- 目标情绪：爽（黄金三章的第一次完整释放）
- 章节定位：高压
- 章首钩子：场面式 — 市易司门前围满看沈家笑话的人
- 爽点：当众翻账三连击（复利违例 → 底档对不上 → 阴阳契书现形），铺垫两章的释放，必须一拳到位

#### 内容概括（五段式）
- 起因：三日之限最后一日，沈砚不去宝行求情，反而把周奎"请"到市易司对账
- 发展：调三年备案底档；周奎有恃无恐（底档他也"打点"过表层），第一回合各执一词
- 转折：沈砚不纠缠数目，直击计息起点——备案借契的起息日与周氏执行的滚算起点差一季，复利违例坐实；账房吴先生在司官逼问下不敢作伪证
- 高潮：周奎抛出"补充契书"翻盘，沈砚以估值之眼识破这份才是伪契（签名摹写），当场请司官验墨——阴阳契书现形，满堂哗然
- 结尾：司官判：多收吐还、三亩田解押、罚金另计；周奎失态离场前盯了一眼田契；沈砚以账簿看那三亩田——"地下·估值：不可测"（F002 埋设）；当夜有黑影翻入灵田

#### 情节安排（多线）
- 主线推进：第一战翻盘，债务战规则确立（打官账不打私账）
- 辅线推进：F001 部分揭示（伪契现形但幕后未指认）；F002 埋设
- 事件线 / 任务线：三日之约收口
- 任务卡点：验签需要司官点头 → 卡出"司官忌惮周氏"的微妙态度 → 沈砚以"罚金三成入公库"的算盘撬动（体现以利驱人，不靠热血）
- 感情线 / 关系线：栖霞全程按刀观战，眼神从戒备到发亮（无台词的转变）
- 逻辑线：对账（因）→ 三连击（行动）→ 解押+吐还（结果）→ 周氏为何非要这三亩田（新问题）

#### 人物关系和出场顺序
- 出场顺序：沈砚、沈栖霞 → 围观县人 → 市易司司官 → 周奎、吴账房 →（物件）备案底档、补充契书、田契
- 人物关系变化：吴账房（周氏账房→动摇的潜在证人）；司官（中立→微向沈家）；姑侄（对立同行→初步认可）
- 视角/信息差：主角知伪契为伪但需程序坐实；周奎不知主角凭什么笃定；读者全知，等的是"怎么当众引爆"

#### 情节细化
- 情节点序列：
  1. 市易司门前人山，议论"沈家小子疯了"（欲扬先抑）【铺垫·中150】
  2. 周奎带吴账房到场，姿态胜券在握，还带了"补充契书"【铺垫·中150】
  3. 第一回合：数目之争各执一词，司官不耐【压制·密250】
  4. 沈砚换打法：只问起息日，请调备案底档【转折·密250】
  5. 底档展开，滚算起点差一季，复利违例坐实；吴账房冷汗、司官变色【第一击·密400】
  6. 周奎抛补充契书："起息日另有约定"——局势反压【假败·密250】
  7. 估值之眼识破伪契（神识刺痛的代价再现）；沈砚请验墨："新墨作旧，三年？三个月都没有。"【第二击·密450】
  8. 验墨坐实、签名摹写现形，满堂哗然；在场三层反应：县人倒吸气/司官拍案/吴账房瘫坐【爆发+反应层·密500】
  9. 判决：吐还多收、解押三亩田、罚金三成入公库（主角事先算好的甜头）【收口·中150】
  10. 周奎离场前死死盯田契一眼——被主角捕捉【疑点·中120】
  11. 沈砚以账簿看田：地上估值平平，地下一栏"不可测"【F002 埋设·密300】
  12. 章尾：当夜，灵田黑影翻墙而入【钩子·密200】
- 预算合计：3170 字（目标 3400，范围 3400-3740）→ 写作时第 7、8 点按上限展开补足
- 代价兑现 / 收益兑现：家族收回三亩田+五百二十八枚灵石（首笔回血，账面可感知）；主角当众立威但彻底得罪周氏；神识透支加重（回家路上眼前发黑——限制递进）

#### 结尾设定和钩子
- 结尾设定：明面小胜收口，真正的问题浮出：对手要的从来不是债，是田
- 章尾钩子：危机式 — 黑影入田，期待度：强；直接承接第 4 章夜擒
