# 细纲（第 52 章）

### 第 52 章：该回去开门了
- 核心事件：对簿回合胜的第二天，沈砚定意回云溪一趟——郡城可追分账线索已尽，唯有回田头老井以算珠 + 度支簿 + 钥符共鸣开门补读第一进分账，才续得上变现引擎与父亲州城线（两条线都卡在「回云溪补读」上）。离郡布局：郡城铺面与字号注册未竟手续交云阔盯守，沈砚立三条死规矩（主场硬碰是火坑、遇卡先记账不硬顶、货先压铺不急出），赴广济号请柯掌柜庭外照拂一二、货来路的招牌先守住；索回诉 2400 换由头缠斗的应对交云阔「照实记、不接私了、有事快信云溪」。启程前把郡城字号注册走到哪一步、还差哪一卡在度支簿上列清（籍贯外郡具保、补验这一环仍悬，为第 55 章新卡埋雷）。埋对手可乘之机：万宝楼耳目探知沈砚离郡，裴衍青轿里得报只轻描淡写一句「那正好」（趁沈砚不在搅字号注册的杀机，周期 3 绞杀铺垫开端）。沈砚骡车出郡城门、回望西市空着的招牌位，暗定「等我把云溪那本账翻明白，回来就挂」。情绪冷决→暗涌收在 6，本批低压过渡章，与第 51 对簿爽承前不趋同（拉锯段落谷）。
- 字数目标：3400 字
- 目标情绪：冷决→暗涌（对簿占理的锐气收起、离这刚站住脚的郡城回乡的沉，叠对手「那正好」的隔空凉意，强度 8→6；本批低压过渡章、拉锯谷，与 51 爽不趋同）
- 章节定位：低压过渡/暗涌（离郡布局 + 补读动机落定 + 对手搅局引信，为 54 补读与 55 撞卡蓄势，强度 6）
- 章首钩子：反差场景 — 昨日堂上占理、今晨却在收拾行囊要离开这刚站住脚的郡城；云阔捧着字号注册那半沓没办完的文书不解，「东家，这节骨眼上，你要走？」
- 爽点：无显性爽点（低压过渡章）；功能爽 = 离郡布局周密、补读动机由「后续」落成「眼下」的谋算沉稳感（卷纲允许过渡章无显性爽点）
- 章尾钩子：承诺/威胁 — 沈砚骡车出郡城门、回望西市空招牌位；镜头切万宝楼那顶青轿，裴衍听得「沈砚离郡了」，指节在膝上一叩，只三个字「那正好」，青轿转向市易司方向。钩向对手趁虚搅字号 + 沈砚回云溪补读。
