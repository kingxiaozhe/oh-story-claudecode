# 细纲（第 5 章）

### 第 5 章：家底与苗子
- 核心事件：家账上墙、全家资产盘点定还款计划；沈檀测灵测出木灵根上品
- 字数目标：3000 字
- 目标情绪：温馨+期待（喘息章）
- 章节定位：低压生活
- 章首钩子：弱钩子/仅情绪钩子 — 功能是让读者和这个家一起坐下来喘口气、点点家底
- 爽点：无显性爽点，功能是数值化盘点的经营快感 + 测灵惊喜；往下看的理由：三个月两百灵石的死线怎么凑

#### 内容概括（五段式）
- 起因：首战胜利后，沈砚立新规：家账上墙，每月公示
- 发展：以估值之眼盘全家家底（人丁修为、田产、器物逐项估值——读者第一次看到完整资产负债表）；定下三个月还清首期两百灵石的计划与分工
- 转折：测灵师进村（例行春测），沈檀测出木灵根上品，满村哗然
- 高潮：喜讯背后是新账：宗门束脩、丹药、行装,一列数字压下来；檀说"我不去，我帮哥哥种田"——全家沉默
- 结尾：砚深夜翻账簿排计划，无意翻到最后一页：一行古字"此账未平"，随即被账簿自行合上（F004 惊鸿一瞥）；明日灵市开集

#### 情节安排（多线）
- 主线推进：还款计划与经营路线定盘
- 辅线推进：F005 埋设（檀的宗门线）；F004 惊鸿一瞥
- 事件线 / 任务线：三个月还款倒计时开启
- 任务卡点：无
- 感情线 / 关系线：全家从"各怀心思"到"一张账上的人"；檀的懂事刺痛主角（他不许妹妹替家族"节流"）
- 逻辑线：胜利喘息（因）→ 盘点定计划（行动）→ 测灵带来新希望与新负担（结果）→ 钱从哪来（新问题，引出灵市线）

#### 人物关系和出场顺序
- 出场顺序：沈砚 → 全家（会议） → 测灵师 → 沈檀 →（物件）家账墙、测灵盘、《度支簿》最后一页
- 人物关系变化：家族凝聚力+1；砚对檀"不核算"的例外首次明写（人设柔软切口）
- 视角/信息差：读者瞥见 F004 而主角未及细看；村人只看到沈家出了好苗子

#### 情节细化
- 情节点序列：
  1. 家账上墙仪式，族人围观新鲜【日常·中150】
  2. 盘点蒙太奇：人丁/田产/器物逐项报数（资产负债表首次完整亮相）【经营爽·密400】
  3. 三个月两百灵石的计划拆解：田里出五十、省用三十、余下一百二"去灵市挣"【计划·密300】
  4. 栖霞质疑灵市水深，砚只答"水深才有鱼"（留期待）【互动·中150】
  5. 测灵师进村，村童排队，气氛轻快【过场·疏40】
  6. 檀上前，测灵盘绿光冲顶——木灵根上品，测灵师失态【惊喜·密400】
  7. 村人道贺与酸话齐飞（世情一笔）【反应·中150】
