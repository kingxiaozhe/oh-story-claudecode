# 力量体系

## 境界（传统阶梯，不加私货）
炼气（一至九层）→ 筑基 → 金丹 → 元婴 → 化神 → …（化神以上第一卷不展开）

## 每境成本表（把经济写进力量体系）
> 读者需要能感知"债务四千二百灵石"是什么量级。

| 境界 | 常规资源投入（下品灵石计） | 世俗对应 |
|------|---------------------------|---------|
| 炼气一层→九层 | 每层约 50-300，越往上越贵，合计约 1500 | 小康之家倾家荡产 |
| 筑基 | 一次性约 8000-15000（丹药+闭关+灵地） | 县级富户的门槛 |
| 金丹 | 十万量级 | 郡级世家底蕴 |
| 元婴 | 百万量级 | 宗门/州级资本 |

- 战斗力除境界外与**储灵量**正相关：同境界，灵力储备厚者耗得起。穷修士赢在算，不在耗。
- 灵根决定吸收效率（=修炼的"成本折扣率"）。主角土灵根驳杂中品，折扣率差，故每一灵石都要花在刀刃上。

## 功法与技能
- 功法有明码传承费；沈家仅存家传《厚壤诀》（土行，中流）与残缺杂学（账房算学、灵植栽培）。
- 土行特性：主"生"与"藏"——灵植增产、窖藏灵物不腐、地脉感应。配合账簿=经营流天赋。

## 《度支簿》（金手指）
- 形态：一本无字旧账，认沈家血脉。觉醒于沈砚（第1章）。
- **核心能力·估值之眼**：目之所及的人、物、契约，浮现"估值"与"隐性条目"（隐藏成本/收益/风险/真伪）。
- **限制**（防全知，必须严格执行）：
  1. 估值基于可得信息，信息不足只给区间或"不可测"；
  2. 看得越深耗神识越大，越境界窥探会反噬（对筑基以上前期直接过载）；
  3. 只提示，不代做——发现漏洞后如何兑现，全靠主角操作。
- **成长线**（后期逐卷解锁，前期只有估值之眼）：记账立契（所记之账具"天道背书"，立契必偿）→ 追索（顺着债务链看见上游）→ 平账（终卷能力，暂不定义细节）。
- 配套器物：**玉衡算珠**（父亲沈云舟遗物，第一卷被抵押在当铺，第8章赎回）——可分担神识消耗，后期是解锁"记账立契"的钥匙之一。

## 封灵契（世界观微创新·金融体系核心）
- 以修为作押的契约：违约则按契划扣修为年限，划走的修为化作"灵息"归债权方。
- 被封者修为冻结、不得进阶，强行突破则契约反噬。
- 债权可转卖（沈家的封灵契债权已被暗中转手——第一卷末揭示）。
- 仙缘券：对赌某修士能否筑基的凭证，州交易所流通（第二卷起启用）。
