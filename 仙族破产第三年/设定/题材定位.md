# 题材定位

## 基本信息
- 题材类型：仙侠·修真文明（家族修仙 + 种田经营）
- 目标平台：起点（男频）
- 核心梗：审计师穿越成破产仙族少家主，一本能看穿隐性成本与收益的祖传账簿，把"还债"变成一场对整个修真界金融体系的反向收割
- 微创新点（≤3）：
  1. 组合法：家族修仙种田 × 审计/金融内核（核心创新）
  2. 加料法：修为可抵押的"封灵契"金融体系（世界观创新）
  3. 反套路：主角灵根平庸且不逆天改命，靠资源配置最优解成长（人设创新）

## 核心梗三分法
- 表层卖点：破产修仙家族 + 会看账的金手指（书名《仙族破产第三年》即卖点，一眼可懂）
- 深层爽点：捡漏（低买）、避坑（识破高息陷阱）、算计反杀（把做局者反割）、家族账面与声望的双重积累感——每一笔投入看得见回报
- 长线钩子：《度支簿》最后一页记着上古仙庭崩塌之夜"平不了的账"；父亲沈云舟因借阅账簿失踪。谁欠了天下人？沈家先祖为何抱账而逃？

## 核心梗三层递进
- 一代主题：账要算明白，人不能算没了——在把修为当唯一硬通货的世界里，替被收割的人把账讨回来
- 二代题材核心：家族由衰转盛的经营积累感 + 群像传承的时间厚度（对标《玄鉴仙族》验证）
- 三代核心情绪：**精打细算翻身**的爽（期待：这笔怎么算赢 → 满足：账面/实力/声望三线增长），叠"莫欺少家穷"的打脸期待

## 每章循环检查（核心梗循环）
每章三选一：① 有"这笔账怎么破"的期待点 ② 有"算赢了"的爽点 ③ 处于两者之间的推进。
循环模式（不断循环型，变奏对象升级）：发现隐性价值/陷阱 → 低成本布局 → 兑现收益/反杀 → 家族资产与声望上台阶 → 引来更大的对手。
升级阶梯：县城宝行 → 郡城万宝楼 → 宗门经济战 → 州府灵石本位动摇 → 仙朝度支司烂账 → 天道之账。

- 八节点位置：开篇处于「日常世界·危机压顶」节点（收田危机）
- 关键转折节点：
  1. 觉醒账簿（第1章，激励事件）
  2. 市易司对账翻盘（第3章，第一门槛）
