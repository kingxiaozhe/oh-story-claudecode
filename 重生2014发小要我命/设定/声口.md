## 0. 一句话声口

> **冷峻克制的旁白，关键处一句贱兮兮的黑色幽默；画面靠拟声词和短镜头推进，情绪靠"一行一 beat"砸下去，章尾一句话反转。**

主角陈牧的叙述声线：**沉、狠、藏**。不喊，不解释，把情绪压进动作和一句冷话里。越是要爆的地方，越写得轻。

**主次（重要）**：**沉狠是底色，贱是点缀，不是主菜。** 一章里冷占九成，贱兮兮的冷幽默只在个别节点闪一下——闪对了才狠，闪多了就滑成痞贫、掉了陈牧的份量。拿不准时，宁可少一句贱，也别多一句。

## 1. 采纳区 —— 6 样金子（注入规则 + 上限）

### 1.1 拟声词独立成行

母本招牌：`轰隆——` `扑通——` `砰！！` `啪嗒——`。快、有画面、有声音。

- **规则**：动作的物理冲击点，用拟声词单独成行，替代"他重重摔在地上"这类描写。
- **本书禁用破折号**（番茄门禁）→ 拟声词后收句号或感叹号，不带 `——`。
- **上限**：每章 ≤ 4 处，只给真正的冲击点（打斗、摔、砸、门、电话）。滥用就廉价。

```
✅  账本摔在桌上。
    啪。
    邬庆山的手，停在半空。
✗   邬庆山猛地一拍桌子，账本被震得跳了起来，发出一声巨响。（描写腔、慢）
```

### 1.2 网感情绪 beat（一行一个字的镜头）

母本最强的招：
```
陈伶：？
简长生三人：！！！
```
把一个瞬间的表情/反应压成一行。番茄快节奏爽点神器。

- **规则**：多人同时反应、或主角一个"无语/看穿"的瞬间，用 `人名：？` / `人名：！` / `人名：……`（对话内可保留极短省略号做表情，见 §2 例外）压成独立行。
- **上限**：每章 ≤ 3 处。这是调味，不是主食；连用会烂。

```
✅  孙大勇的人递上来一张卡。
    陈牧：？
    “孙老板这是什么意思。”
```

### 1.3 黑色幽默 / 自嘲旁白（人味核心）

母本："他大概率是被掉下来的射灯砸死了……"、"他欠你钱了吗？"。冷峻里带一点贱。**这是 AI 检测最难抓、最像"一个具体的人"的东西。**

- **规则**：紧张过后、或主角看穿对手时，给一句**不动声色的冷幽默**。贱在心里，脸上不动。
- **落点**：段末或对话后，短，一句就走，不解释"这很好笑"。
- **上限**：每章 **2–3 句**（沉狠为主，贱是点缀）。多了掉价、滑向痞贫；宁少勿多。
- **让位**：高压/生死/复仇兑现的段落，这一样**收起来**，一句都不给——那种地方越冷越狠（见 §1.6 双声线）。

```
✅  邬庆山走的时候还挺高兴。
    高兴好。他越高兴，刀就亮得越慢。
✅  八百万。这三个字背后，是八百万的血。他记得这笔账，就是想不起当年自己是怎么把脖子伸过去的。
```

### 1.4 生活化比喻（土、准、反 AI 味）

母本："就像在老师背后偷偷作弊，老师一转身，手机滑到脚下。" 从日常里取喻，不从"文学"里取。

- **规则**：要打比方时，只从**菜市场、牌桌、老家、饭局、修车铺**这类地气场景取喻；**禁止**"如寒冰般""似利刃般"这类文学腔。
- **上限**：每章 1–2 个。比喻是奢侈品，不是耗材。

```
✅  他这价压得，跟收破烂的看见一屋子旧报纸一个眼神。
✗   他的眼神如鹰隼般锐利。（AI 味、被 banned-words 拦）
```

### 1.5 一句话反转章尾钩

母本："那我们昨晚杀的……又是谁？" 一句话把地基掀了。**这一条直接就是番茄要的。**

- **规则**：章尾最后 1–3 行，抛一个**推翻前面认知**的信息或悬念，短句砸下，不收尾、不升华。
- 接 `gate.py` 的章末钩子检测。

```
✅  二叔的声音抖得厉害：“你爸的坟……昨天夜里，被人刨了。”
    陈牧的脸色一沉。
    是孙大勇家那辆车。
```

### 1.6 双声线切换（真功夫）

母本：生死场景把声线压冷（"……看来，运气不佳啊"），日常场景放网感和贱嘴。

- **规则**：
  - **高压/生死/复仇兑现** beat → 声线**压到最冷**，短句、少形容、动作说话。§1.2 网感 beat 和 §1.3 黑色幽默**让位/收敛**。
  - **日常/过场/斗嘴** beat → 放开网感、贱嘴、生活比喻。
- 每章开头先判本章基调，定这一章"冷"多还是"贱"多。

## 4. 段落级优化循环怎么用这份文件

> 这是你要的"写一段、停下来、用作者声口优化一段"的执行契约。

对每一段（草稿写完后）：

1. **只读本文件**（§1 采纳区 + §5 语气词库）。**不读上一段的成品当风格样板。**
2. 按段落基调（冷/贱）判断：这一段该不该注入 §1 的某样金子？**不是每段都要注入**——硬塞会烂。一段通常 0–1 样。
3. 注入时**查该样的"上限"**：本章该样的配额是否已用完？用完就不加。
4. 优化完**立刻自检逗号密度**（心算：这一段逗号是不是明显多于汉字的 1/6？多了就是滚雪球前兆，收掉）。
5. 过了再写下一段；下一段的**剧情**承接上一段，**声口**仍锚本文件。

**红线**：任何"让下一段模仿上一段风格/断句/语气词密度"的做法，一律禁止。声口只能向本文件收敛，不能向自己的上一段漂移。

## 5. 语气词 / 口头禅库（分场景，带上限）

> 取自母本可迁移部分 + 本书都市语境。**是有限清单，不是越多越好。**

**叙述里（旁白冷幽默用）**：便是、也好、罢了、无非、说到底、说来、要说、偏偏、倒是
- 例：“他要的，无非是这个‘薄’字。” “说到底，孙大勇怕的不是陈牧，是那本账。”

**对话里（角色声线用）**：
- 陈牧（沉狠）：少语气词，多短句和反问。“哦？” “就这些？” “你说呢。”
- 市井配角（活）：啧、哼、得咧、你猜怎么着、可不、成、行吧
- 情绪爆发（少用）：！ 单个，不叠 `！！！`（叠感叹号是母本对话习惯，本书叙述里不用，对话峰值 ≤1 个）

**每段上限**：单段语气词 ≤2 个。超过就是在"装人味"，反而假。
