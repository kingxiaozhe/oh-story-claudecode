# 第 181 章 尘埃落定

那位先生落网后，一切，都以一种，摧枯拉朽的速度，尘埃落定。

陈牧递上去的那份，密不透风的材料，成了压垮这头庞然大物的，最后一道枷锁。

调查组顺着那些，铁证如山的线索，一路深挖。那位先生，经营了大半辈子的，那个盘根错节的黑色帝国，被一层一层地，剥开、查封。

洗钱、行贿，还有那些，深埋多年的陈年旧案，桩桩件件，都被钉死。等待着他的，将是法律，最严厉的审判。

而最让陈牧，长舒一口气的，是牧达。

那几笔，曾被那位先生，当作捆死牧达的洗钱旧账，在林敬之，原原本本的梳理下，非但没能，伤到牧达分毫——

反而，清清楚楚地，证明了牧达，自始至终，都只是被那位先生，蒙在鼓里、利用的一枚棋子。

到最后，正是这份账，成了把那位先生，送上审判台的，关键一击。

“陈总，”林敬之亲自来报这个好消息，脸上，是如释重负的轻松，“调查组那边，已经正式认定，牧达在这件事上，是完全清白的。咱们所有被牵连冻结的账户，明天就能全部解封。”

“辛苦你了。”陈牧看着这个，曾经的对手、如今的功臣，点了点头，“这一次，牧达能全身而退，你记首功。”

“陈总言重了。”林敬之苦笑着摆手，“我这，也是将功赎罪。当年被那位先生，逼着做的那些腌臜事，能亲手了结，我心底，反倒踏实了。”

“过去的，就让它过去。”陈牧淡淡道，“往后，好好替牧达，管好这摊账，我不会亏待你。”

“陈总，”沈泽拿着各方反馈的消息进来，脸上，是藏不住的与有荣焉，“现在，整个圈子，都传遍了。”

“都在说，那位连宋老都要忌惮三分的‘那只手’，是被咱们牧达，一手掀翻的。”沈泽一字一句，“以前，那些跟咱们打交道，还端着架子的人，现在，一个个，客气得不行。”

陈牧端着茶，神色平静。

“他们怕的，不是牧达。”他淡淡道，“是怕，连那位先生那样的庞然大物，都栽在了我手里。”

“可不是嘛。”沈泽咧嘴一笑，“前两天，连之前跟咱们有过过节的那几家，都主动找上门来，又是道贺，又是想合作。那副嘴脸，跟之前，简直判若两人。”

“锦上添花的人，从来不缺。”陈牧看得通透，“他们现在捧着牧达，不是因为牧达有多好，而是因为，牧达如今有了，让他们不敢得罪的分量。”

“人情冷暖，本就如此。”陈牧淡淡道，“不必理会，也不必得意。把咱们自己的事，做好，比什么都强。”

“是是是。”沈泽连连点头，“还是陈总看得透。”

没过几日，宋老，专门设了一场饭局。

席间，这位在这座城的圈子里，坐了半辈子主位的老人，看着陈牧，眼神里，多了几分，真正的平视与赞许。

“小陈啊，”宋老感慨道，“我活了这把岁数，见过的后生，不知凡几。可能在这么短的时间里，把那个人，从云端拉下来的，你是头一个。”

“往后，”宋老举起酒杯，“这座城里，该有你的一席之地了。”

“宋老过奖。”陈牧举杯回敬，姿态，不卑不亢，“若没有您几次出手相助，这局棋，我也走不到今天。”

“帮你？”宋老摆了摆手，笑道，“我那几次，不过是顺水推舟。真正难的棋，都是你自己，一步一步走出来的。”

“老头子我，活了一辈子，最佩服的，就是你这股韧劲。”宋老呷了一口酒，意味深长，“多少人，在那位先生面前，连头都不敢抬。你倒好，硬是把他，从神坛上，给拽了下来。”

“不过，”宋老话锋一转，眼神里，带着几分长辈的关切，“树大招风。你如今，名头太响，往后行事，更要稳当，别给人，留下话柄。”

“晚辈记下了。”陈牧郑重应道。

这位老人，几次在关键时刻，为他遮风挡雨，又从不求回报，陈牧对他，是打心底里的敬重。

那位先生倒下后，留下的，是一个庞大的，权力与利益的真空。

他那些，盘踞多年的产业，被查的查、被分的分。其中几块，跟牧达业务，最契合的，经过一番，光明正大的运作，最终，落进了牧达的囊中。

一时间，牧达的体量，又上了一个，新的台阶，隐隐，成了这座城里，无人能撼的地产巨头。

那位先生的倒下，像是推倒了，第一块多米诺骨牌。

那些曾经，依附在他羽翼下、作威作福的牛鬼蛇神，也跟着，一个接一个，被清算。这座城的水面之下，那股盘踞多年的污浊暗流，被狠狠地，搅动、廓清了一番。

而那些，曾被那位先生，害得家破人亡的人，也终于，等到了，迟来的公道。有几个当年的受害者，甚至，辗转找到牧达，只为当面，对陈牧，道一声谢。

陈牧没有居功。他做这一切，从来不是为了谁的一声谢。可看着那些，重新燃起希望的脸，他的胸口，也生出一丝暖意。

替天行道这种事，他本没兴趣。他要的，只是那位先生的命。只不过，在他复仇的这条路上，顺手，也为这座城，除了一害罢了。

“陈总，”沈泽看着那些，千恩万谢离去的受害者，感慨道，“您这一仗，不光是替自己出了气，也算是，为这一方，积了大德了。”

“德不德的，我不在乎。”陈牧摆了摆手，“我只知道，人在做，天在看。欠债的，就该还债；作恶的，就该偿命。这世上的道理，再多，也绕不过这一条。”

只是，无论初衷如何，结果是好的。

那位先生留下的烂摊子，被一一收拾干净；牧达的声望，达到了前所未有的顶点；而跟着他的这帮兄弟，也终于可以，睡一个安稳觉了。

可站在办公室的落地窗前，俯瞰着这座，他已然，站到了顶端的城市，陈牧，却没有多少，登顶的快意。

牧达，是做大了。可它的根，还死死扎在，这一城一地的地产上。

地产这门生意，再大，也有它的天花板。而这块天花板，他如今，几乎，已经触手可及了。

一城一地的得失，已经装不下，他的眼界了。

“沈泽，”陈牧忽然开口，“你说，牧达做到现在这个份上，下一步，该往哪走？”

沈泽愣了一下，沉吟道：“咱们在这座城的地产圈，已经是头一份了。要我说，无非是把盘子铺得更大，多拿几块地，多盖几个楼盘。”

“那也不过是，在这口井里，多扑腾几下。”陈牧摇了摇头，目光，越过窗外的楼群，望向更远的地方，“我在想，是不是，到了该跳出这口井的时候了。”

“跳出这口井？”沈泽一怔，“陈总的意思是……”

“还没想好。”陈牧收回目光，淡淡一笑，“不过，快了。”

沈泽望着自家陈总那深邃的侧脸，没再多问。他跟了陈牧这么久，早就知道，每当陈总露出这种眼神，就说明，又一盘更大的棋，要开始了。

他这两世，跌跌撞撞，走到今天。那本曾经的‘剧本’，在程邬倒台后，就成了一张废纸。

可奇怪的是，丢了剧本这根拐杖，他非但没有，寸步难行，反而，靠着自己的双腿，走得比任何时候，都要稳，都要远。

如今的他，早已不需要，任何人告诉他，下一步，该往哪走。他有自己的眼睛，能看到别人，看不到的未来。

只是，那更大的棋盘，眼下，还不急。

在谋划牧达的下一步之前，他还有一件，更重要的事，要做。

这一场，跨越了两世的鏖战，他赢了。可这场胜利，不是他一个人的。

是李锐，把后方守得密不透风；是沈泽，在谋局上，为他冲锋陷阵；是林敬之、胡彪这些‘降将’，在关键时刻，递上了最锋利的刀；更是孙建国，用自己的一身伤，替他挡下了，那位先生最卑劣的一击。

这些人的情，他都一一记在心上。而这份情，往后的日子里，他要一个一个，还回去。

那个，为他挡了一场无妄之灾的兄弟，还躺在医院里。

陈牧放下茶杯，起身，抓起了外套。

“走，”他对沈泽道，“现在就去医院。我要去看看孙建国——这笔人情，于公于私，我都得亲自还。”
