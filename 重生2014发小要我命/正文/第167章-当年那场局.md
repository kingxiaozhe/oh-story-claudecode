# 第 167 章 当年那场局

沈泽的办事效率，向来很高。

陈牧交代下去没几天，他就带着一摞，从各种渠道翻出来的、关于宏远投资的旧档，找上了门。

“陈总，宏远的事，我大致捋出来了。”沈泽把一份梳理好的脉络，放在陈牧面前，神色凝重，“这家公司当年的手段，看得我后背发凉。”

“说说看。”陈牧的声音，听不出情绪。

“宏远投资，表面上是家正经的投资公司。可它真正赚钱的路子，是‘猎杀’。”沈泽一字一句，“它专门盯着那些，有潜力、势头猛，但根基还浅、资金链脆弱的公司下手。”

“一旦盯上谁，”沈泽道，“宏远就会动用它背后那张大网的力量，从各个方向，掐断目标公司的生路——断它的融资，抢它的客户，挖它的核心人才，再放出各种流言，搅乱它的阵脚。”

“等把这家公司，逼到资金链断裂、奄奄一息的时候，”沈泽的声音，沉了下来，“宏远，再以一个低得可怜的价格，把它，整个吞下去。”

“被它盯上的公司，”沈泽摇头，“没有一个，能逃得掉。”

“我给您举个例子。”沈泽翻开一份卷宗，“当年市里有家做建材的公司，老板姓周，是个实打实的能人。短短几年，把生意做得风生水起，眼看就要上市了。”

“可就在那个节骨眼上，”沈泽的语气，沉了下来，“他的麻烦，一桩接一桩地来。银行抽贷、税务上门、合伙人反水……短短半年，一家好好的公司，就被折腾得分崩离析。”

“最后，是宏远，‘仗义’地出手，‘收购’了他濒死的公司，帮他‘解了围’。”沈泽冷笑，“那位姓周的老板，从一个准上市公司的老总，沦落成了给人打工的。没几年，就郁郁而终了。”

“这样的例子，”沈泽指了指那摞卷宗，“我手里，还有好几个。手法，如出一辙。”

陈牧静静地听着，端着茶杯，一言不发。

可只有他自己知道，沈泽口中描述的每一个字，都像一根针，扎在他最深的伤口上。

因为，沈泽所说的这一套，他太熟悉了。

前世，他一手创办的公司，蒸蒸日上，眼看就要成为行业里一匹黑马。然后，一切，急转直下。

先是合作多年的银行，毫无征兆地，抽走了贷款；紧接着，几个最大的客户，被人用更低的价格撬走；公司里几个最得力的骨干，也在一夜之间，被人高价挖走；市面上，更是流言四起，说他的公司，资金出了大问题，撑不了多久了。

那时候的他，焦头烂额，四处救火，却发现自己，像陷进了一张无形的大网，越挣扎，缠得越紧。

直到最后，资金链彻底断裂，他被迫，把整个公司，贱卖给了那家凭空冒出来的——宏远投资。

签下那份转让协议的那一天，是他这辈子，最灰暗的一天。

他清楚地记得，对面那个代表宏远来谈判的人，脸上那副，假惺惺的、悲天悯人的表情。那人拍着他的肩，说什么“市场无情，胜败乃兵家常事”，劝他“想开点”。

那时候的他，把对方当成了，趁火打劫的秃鹫，恨得牙痒，却无能为力。

他从没想过，那个秃鹫的背后，还站着一个，连秃鹫都只是他随手豢养的工具的——真正的猎人。

而他，连那个猎人的名字，都不配知道。

那时候的他，只当自己，是时运不济、棋差一着。

直到今天他才明白，他前世遭遇的那一切，从头到尾，根本就不是什么意外。那是一场，由那位先生在幕后，精心策划、亲手导演的猎杀。

他，从来不是什么失败者。他，只是一头，被猎人盯上的猎物。

“还有一件事，”沈泽的脸色，更难看了，“陈总，您听了，可能会觉得，有些瘆人。”

“讲。”

“我查到，当年被宏远吞掉的公司里，”沈泽压低声音，“有那么几个不肯善罢甘休的老板，在公司被吞之后，曾试图搜集证据，想把宏远背后的黑幕，捅出去。”

“可这几个人，”沈泽顿了顿，“后来，全都出了意外。有的，突发恶疾；有的，意外身亡；还有的，干脆人间蒸发，再也没了音讯。”

“这些事，单看，都是孤立的意外。”沈泽的声音，发着寒，“可放在一起看——那位先生这个人，对挡了他路、又不肯认命的人，下手有多狠、多绝，可见一斑。”

陈牧握着茶杯的手，骨节，因为用力，而泛白。

他前世，是怎么死的？

记忆里，那一段，始终是模糊的。他只记得，在失去一切之后，自己曾不甘心，曾想过，要查清楚，宏远究竟是什么来头。然后……然后的记忆，就断在了一片冰冷的黑暗里。

如今，听完沈泽这番话，一个，他从不敢深想的念头，第一次清晰地，浮了上来——

他前世那场，不明不白的“惨死”，会不会，也跟那几个人一样，是那位先生，亲手抹去的？

这个念头，让他遍体生寒。

可他没有证据。那段记忆，太过模糊，模糊得，连他自己，都无法确认。

但这并不妨碍，那个念头，在他胸中，疯狂地，滋生、蔓延。

他想起重生之初，自己醒来时，那种劫后余生般的恍惚；想起记忆里，那片挥之不去的、冰冷的黑暗。

如果，那场“惨死”，真是那位先生的手笔——那么，他这一次的重生，就不仅仅是上天给的一个，复仇的机会。

那更像是，一个屈死的冤魂，挣脱了那位先生以为早已处理干净的坟墓，重新杀了回来。

而这一次，他不会再，当那头任人宰割的猎物了。

但有没有证据，已经，不重要了。

不管前世，那位先生，是只夺了他的事业，还是连他的命，也一并取了——这笔账，都已经大到，不死不休的地步了。

这一夜，陈牧又一次，在书房，坐到了天明。

他那本剧本，对这一切，一无所知。

剧本，记录了程立秋的贪婪、邬庆山的阴狠，却唯独，漏掉了藏在他们身后，那个最大的黑手。它让陈牧以为，扳倒了程、邬，前世的仇，就报完了。

可真相是，他这两世所有苦难的源头，那个真正的元凶，至今，还稳稳地，活在云端，逍遥法外。

是他，靠着自己的双手，掀开了剧本刻意留下的那块遮羞布，才看清了这血淋淋的真相。

这个发现，对陈牧而言，是一把双刃剑。

一方面，它揭开了一个，让他遍体生寒的真相，把一个远比程立秋、邬庆山更可怕的对手，推到了他面前。

可另一方面——陈牧的眼中，反而燃起了一种，近乎亢奋的斗志。

前世，他是在毫不知情的情况下，被对方玩弄于股掌之间，死得窝囊。而这一世，他不但提前看清了对手，还先一步，摸到了对方的命门。

攻守之势，早已不同往日。这一回，握着猎枪的，是他陈牧。

从此刻起，扳倒那位先生，对陈牧而言，不再仅仅是为了，扫清商场上的劲敌。

这是为了，前世那个被他亲手毁掉、死得不明不白的自己，讨一个，迟到了两世的公道。

天光，一点一点，亮了起来。

陈牧站起身，走到窗前。一夜未眠的他，眼中，没有半分疲惫，只有一种，淬炼到极致的、冰冷的平静。

“沈泽。”他沉声开口，“宏远的事，到此为止，不必再查了。”

再查下去，也不过是，往他的伤口上，再撒一把盐。当年的真相，他已经知道得够多了。

剩下要做的，不是去反复回顾那段不堪回首的过往，徒增伤悲；而是，去亲手，把那个在云端导演了这一切的人，从他的神坛上，狠狠地，拉下来。

“接下来，”陈牧的目光，转向了那个，更现实的目标，“咱们的全部精力，都压到林敬之身上。”

“他，是那位先生现在的钱袋子，也是我，撬开那位先生这座坚冰的，第一锤。”陈牧一字一句，“我要让那位先生，从他最得意的钱上，开始一点一点，尝到失去的滋味。”

“等把林敬之这颗棋子，攥死在手里——”陈牧眼中，寒光如刃。

“就该我，去会一会，那位藏在云里、藏了整整两世的先生了。”
