# 第 137 章 那座山，塌了

那座山，塌得，比所有人想的，都快。

六月十三，下午。

上头派下来的人，到了。他们没有惊动太多人，直接走进了，程立秋的办公室。

没有争辩，没有反抗。

程立秋，这个在本地呼风唤雨二十多年的人，看着那几张陌生的、却带着他够不到的那个高度的气场的脸——他，什么也没说。

他只是站起身，最后望了一眼，窗外，这座，他踩着无数人爬上来、又自以为能永远俯瞰的，城。

然后，他低下了，那颗高昂了二十多年的，头。

“我跟你们，走。”他说，声音平得，听不出情绪。

走到门口，他忽然停住，回过头，问了一句：

“是邬庆山，对吧。”他盯着来人，“是那条疯狗，咬的我。”

来人，没有回答他。

程立秋，惨然，笑了一下。

到了这个时候，他居然还以为，扳倒他的，是邬庆山。他至死，也没想明白——那个真正把他推下神坛的人，他，连正眼，都没看过。

被带走的时候，程立秋，走得很慢。

街上，已经有人，认出了他。那些曾经见了他就点头哈腰的人，如今远远地看着，窃窃私语。

那座，压了整座城二十多年的山——

在六月十三这天，下午的阳光里，轰然，倒下。

山一倒，那些被它压了二十多年、不敢出声的人，一个一个，站了出来。

钱进，第一个。

这个被吓得装了二十多年缩头乌龟的老人，坐在调查组的面前，把当年那场假过户的全过程，一五一十，说了出来。

“那块地的过户手续，”钱进的声音，不再发抖，“是假的。签字那天，地的主人，苏婉清，根本不在本地。是程立秋，逼着我，在上面，盖的章。”

“这件事，”他说，“压了我，二十多年。”

调查组的人问他：“你为什么，二十多年，一直不说？”

“因为，怕。”钱进苦笑，“程立秋放过话——谁敢提那块地，谁就跟那块地原先的主人，一个下场。我，亲眼见过，不肯听话的人，是怎么没的。我，不敢赌。”

“可这二十多年，”老人的声音，哑了，“我，夜夜睡不着。那个章，是我盖的。我，对不起，苏婉清。今天能把真话说出来——我这条命，值了。”

紧接着，是郑维德。

老人把那个，他用油布裹了二十三年的小包，亲手，交到了调查组的手上。

那里面，是程立秋以为早就从这世上消失了的把柄——一份，能把他，和当年那桩假过户、那桩夺地杀人的旧案，死死钉在一起的铁证。

二十三年了。这份东西，终于，重见天日。

“这些年，”郑维德把那小包，推过去，对调查组的人说，“我一直以为，我守着它，是为了我自己那条命。今天，我才明白——”

“我守着的，是一条人命的，公道。”

而最后，站出来的，是周慧明。

他没有像钱进、郑维德那样，在屋子里。他站在当年，他姐姐告状走过的那条台阶前面。

他挺直了，那条佝偻了二十年的脊梁，当着越来越多、围过来的人，一字一句，说出了那句，他憋了二十年的话：

“我姐姐，周慧雪，不是失足落水。”

“她是，被程立秋，害死的。”

“这句话，”他的眼泪，掉了下来，可那声音，却越来越响，“我，等着对所有人说，等了，整整，二十年！”

他的声音，在那条，他姐姐二十年前一级一级走过的台阶上，回荡。

“二十年前，”周慧明，泪流满面，却一字一句，“我姐姐，就站在这里，告状。她说，那块地，是被抢的。可没有一个人，信她。没有一个人，敢替她说一句话。”

“后来，她死了。所有人都说，是意外。”

“今天，”他环视围过来的人群，声音嘶哑，却响亮，“我替她，再说一遍——我姐姐周慧雪，是被程立秋害死的！这一回，我倒要看看，还有没有人，敢说，是意外！”

人群，静了一瞬，随即，议论炸开。有人认出了他，低声说：“这不是……城南，修车的，老周吗……”“当年那个，落水的姑娘……原来，是他姐姐……”

陈牧，站在人群的最外围，看着这一幕。

他没有，再去想上一世。

那本剧本里，只记得程立秋，会倒。可它从没记下过——这个叫周慧雪的姑娘，曾经怎样带头抗争；她的弟弟，曾经怎样沉默地守了二十年；这一句，迟到了二十年的公道，听起来，是什么分量。

剧本，给不了这个。

是他，陈牧，这一世，一个一个，把这些被遗忘的人，从黑暗里请了出来——

才让这句话，今天，有人，听见。

程立秋一倒，剩下的，就快了。

他名下那些白手套公司，一个接一个，被查；他这些年靠那块地、那两条命，垒起来的所有见不得光的东西，被一层一层，揭开。

那些曾经对他俯首帖耳的人，跑的跑，撇清的撇清。那些被他踩过、压过的人，则趁着这墙倒之时，一拥而上，把自己知道的那点料，全都抖了出来。

短短几天，这座二十多年没人敢碰的庞然大物，就被扒得，只剩一个空壳。

而这场塌方，没有只埋了程立秋一个。

调查顺着程立秋这条线往下捋的时候，那些这一年，跟程立秋斗得你死我活、也因此被扯进明面上的人和事——也一个没落下。

其中，就有，宏远投资。

邬庆山，怎么也想不到，会是这么个收场。

他本想，借着跟程立秋死磕的工夫，搂草打兔子，把程立秋搞臭，自己趁机进场。可他千算万算，没算到——程立秋倒得这么快、这么彻底，把他这个，跟程立秋缠斗了一整年的人，也一起，拖下了水。

“老板，”秦经理跑进来，脸色煞白，“不好了。查程立秋的人，开始查我们，跟他那些项目上的往来了。咱们……咱们跟程立秋这一年，斗得太狠，留下的首尾，太多了！”

邬庆山，一屁股跌坐在，老板椅上。

他这才明白过来。他和程立秋斗了一整年，斗得两败俱伤。如今程立秋塌了，可这场塌方激起的尘土，正劈头盖脸，朝他埋过来。

“怎么会……”他喃喃，“怎么会，这样……”

陈牧听到这个消息的时候，正站在办公室的窗前。

“陈总，”手下来报，“查程立秋，查出了不少跟宏远牵扯的猫腻。邬庆山那边，最近也焦头烂额，听说，已经有人，找上他了。”

陈牧的目光，沉了下来。

邬庆山。

这个前世，吞掉他整个公司、把他逼上绝路的人。这个这一世，又想故技重施、把牧达啃下肚的人。

程立秋这座山塌下来，先砸到的，是他自己。可这，还不够。

陈牧望着窗外。

程立秋，倒了。当年那块地、那两条人命，二十多年无人过问的旧账，今天，总算有人，来翻了。

周慧雪，等了二十年的公道，到了。钱进、郑维德，藏了半辈子的东西，用出来了。

可在陈牧的这盘棋里，程立秋，从来不是，最后一个。

“陈总，”手下又道，“钱进、周慧明、郑维德，那三位，怎么安排？程立秋虽然倒了，可万一，他还有余党，狗急跳墙——”

“盯紧他们仨，护好。”陈牧说，“尤其是周慧明。他那一句话，等了二十年，刚说出口。我答应过他，要护他周全——这话，得算数。”

“放心。”那人说，“咱们的人，一直贴着呢。等程立秋的案子彻底定了，他们仨，才算，真正安全。”

“嗯。”陈牧说，“他们替死去的人，讨回了公道。剩下的日子，我得让他们，过得踏实。”

“对了，陈总，”手下补充，“城里现在都传遍了。多少当年被程立秋坑过、却一直忍着不敢吭声的人家，这两天，都跟着壮起了胆，一个接一个，去把当年的冤屈，报了上去。这火，是真的，烧起来了。”

“那就，让它烧。”陈牧说，“烧得越旺，程立秋那点根，刨得越干净。”

他转过身，对手下，沉声，说了一句：

“程立秋，只是开胃菜。”

“接下来，”陈牧的眼神，冷了下来，“轮到邬庆山了。”

“他前世欠我的，这一世，我要，连本带利，亲手，拿回来。”

手下听得，一凛。他从没见过，陈总的眼神，这么冷过。

窗外，那座压了这座城二十多年的山，已经塌成了一片废墟。

可对陈牧而言，这场迟到了一世的清算——

才，刚刚，掀开，序幕。

下一个，轮到谁，他，清楚得很。
