# 第 242 章 一根刺

傅野连夜出城，回到了牧达。

这一趟深入虎穴，他瘦了一圈，眼里却满是压不住的东西。老槐、鼎丰、那座藏在城郊的老宅——一样一样，他都替陈牧，看了个真切。这些是牧达在外头，砸再多钱、拼再多命，都换不来的东西。

那句老槐的话，被他一字不差，递到了陈牧面前。

“他凿的这座山，山底下埋着的东西，比他想要的仇，要深得多。”傅野一字一句，复述着，“让他别急着凿。小心，凿出一个，他自己也扛不住的，真相。”

办公室里，静了下来。

沈泽和李锐，对望一眼，脸上都有些发沉。

“陈总，”李锐斟酌着开口，“这老东西的话，怕是……话里有话。”

陈牧却没有立刻答话。他站在窗前，望着窗外那片深沉的夜色，指节，一下一下，叩着窗框。

那句话，像一根细针，扎进了这间办公室的空气里。

一个自己也扛不住的真相。

这七个字，若是砸在旁人身上，足以让人夜不能寐、寝食难安。可陈牧，只是望着夜色，眼底那点寒光，纹丝未动。

“它又来了。”良久，陈牧缓声道。

“又来了？”沈泽一愣。

“攻心。”陈牧转过身，一字一句，“上一回，它拿一沓纸，想离间我和敬之，没成。这一回，它换了个法子——拿一句话，想离间我，和我自己。”

众人一怔。

“你们看，”陈牧的声音冷得像冰，“它没告诉我那真相是什么，只丢下一句‘你扛不住’。这叫什么？这叫，把一根刺，扎进我的骨头缝里。”

“往后我每凿一锤，这根刺都会疼一下，逼我先想——我到底该不该，往下凿。”陈牧眼底寒光四射，“它要的，就是我这一犹豫。我一犹豫，它就喘上气了。”

一语,道破。

那座冰山，在明面上，已经拦不住陈牧的锤子。汇通断了，鼎丰的线也被摸到了。于是它退而求其次——既然挡不住这把锤子，就在抡锤的人骨头缝里，埋一根刺，让他自己，慢下来。

这一手，比离间林敬之，还要阴。离间人和人，好歹还有个对证的余地;离间一个人和他自己，扎的是最没处说理的地方。多少枭雄，不是败在对手的刀下，而是败在自己心底那根，被人悄悄埋下的刺。

前世的陈牧，就着过这样的道。那时，也有人在他耳边，一遍一遍地说，他信的人靠不住、他走的路是绝路。说得多了，他真就自己先乱了阵脚、自己先怕了。等他明白那些话全是敌人喂的毒，他，已经输得一败涂地。

“可它算错了一样东西。”陈牧笑了，那笑意里没有半分暖。

“它以为，我陈牧凿这座山，凿的是好奇、是想弄明白个真相。”他一字一句，“它就拿一个‘扛不住的真相’来吓我。”

“它不知道，”陈牧的声音陡然一沉，“我凿这座山，凿的从来不是真相——是仇。”

“别说山底下埋着一个我扛不住的真相，”陈牧一字一顿，眼底燃着一簇越烧越旺的火，“就是埋着刀山火海，我这把锤子，也一样，抡到底。”

“它想拿真相当刺，扎得我不敢凿。”陈牧冷笑，“那我偏要凿给它看——这座山底下的东西，不管是什么，我陈牧，都接得住。”

“一个人，连自己怎么死的、这两世从哪儿来的，都敢不去想、只管往前凿，”陈牧一字一句，“这世上，还有什么真相，能真正吓住他？”

一番话，把那根扎进来的刺，硬生生，拔了出去。

众人望着主位上那个身形挺拔的男人，翻涌的那点不安，一点一点，定了下来。

这，就是他们愿意把命，都押在这个男人身上的缘故。同样一句诛心的话，砸在别人身上，是催命的符;砸在陈牧身上，却像一拳打在铁板上，连个印子都留不下。跟着这样一个人，天塌下来，也有人替他们，先扛着。

是啊。这些年，那座冰山用尽了法子——杀手、抽贷、离间、攻心，哪一样，没砸到陈牧身上？可陈牧，哪一次，退过？

一个连死都不怕的人，又岂会，被一句捕风捉影的话，吓住脚步。

“不过，”陈牧话锋一转，眼底那点寒光，沉了几分，“这句话，我记下了。”

他没有对众人说的是——老槐这句话，虽是攻心，却未必全是空穴来风。那座冰山盘踞两世，它藏着的东西，究竟有多深，他确实，还没摸到底。

这根刺，他拔了。可拔下来的刺尖上，那一点说不清道不明的血色，他，收进了心底。

前世的迷雾，究竟还有几层？那个连老槐都讳莫如深的真相，究竟是什么？为什么先生会觉得他“像极了一个故人”？为什么老槐一听“不止一世”，那双古井无波的老眼，会翻起波澜？

这一桩桩，一件件，串起来，隐隐指向一个，他望不到底的深渊。那深渊里藏着的东西，或许，真跟他前世的死、跟他两世的来历，有着说不清的干系。

可这些，他没有答案。他也不急着要答案。

因为他清楚，那本前世的剧本，早在程邬倒台那天，就成了废纸。往后每一步，靠的不是剧本上的字，是他这两世，一刀一枪，磨出来的眼力和城府。

想通了这一层，陈牧眼底那点因老槐而起的沉郁，被一簇越烧越旺的战意，尽数压了下去。

真相也好，深渊也罢，都得等他，一锤一锤，凿到跟前，再说。眼下，他手里,攥着两样,那座冰山做梦都想不到的东西——傅野这颗钉子,和一整座鼎丰暗堡的图纸。这两样,才是他此刻,该落的子。

老槐想用一句话，让他停下锤子、坐在原地，去想那个虚无缥缈的真相。可陈牧偏不。他要用最快的速度，把这一锤，砸下去——用行动告诉那座冰山，任你千般攻心，我陈牧的锤子，一步，都不会停。

“敬之，”陈牧忽然转身，“傅野带回来的那座老宅、那座鼎丰暗堡，进出的路、明暗的岗，你连夜，给我绘成一张图。”

“沈泽，”他一字一句，“清点人手。这一回，咱们不动汇通那样的明面产业。”

“咱们要凿的，”陈牧的目光冷冽，“是它藏在暗处的那双眼睛——鼎丰。”

“陈总，”沈泽精神一振，“傅野还在里头。咱们动鼎丰，他……”

“他是我埋进去的一颗钉子。”陈牧缓声道，“这一锤砸下去的时机、怎么砸才能不伤着他，我自有分寸。”

“陈总的意思是，”李锐反应过来，“咱们端鼎丰，还得给傅野，留一条能全身而退的路？”

“不止。”陈牧一字一句，“傅野这颗钉子，眼下已经钉进了老槐身边。这么好的一步棋，我舍不得，一锤子砸没了。”

“端鼎丰这座暗堡，是明的一手，斩它的耳目。”陈牧眼底寒光四射，“可傅野这颗埋在老槐身边的钉子，是暗的一手。明的这一锤砸下去，得砸得,像是牧达从外头,自己摸进来的，跟傅野，半点干系都沾不上。”

“这样，”他缓声道，“鼎丰没了，老槐只会更倚重傅野这个,‘从牧达反水’的自己人。咱们,反倒能顺着傅野,往那座冰山,更深处,再摸一层。”

一言既出，满屋皆惊。

众人这才咂摸出味来。旁人凿冰山，凿一处，是一处;陈牧凿冰山，凿掉一处的同时，还要借着这一锤，把埋在敌人心脏的那颗钉子，钉得更深、更稳。

一锤两用，虚实相济。这份算路，众人竟没一个,跟得上。

“傅野拿命，替咱们摸清了那座暗堡。”陈牧望向窗外那片浓得化不开的夜，一字一句，“这一锤,我，必须，砸得漂亮。”

“既要斩了它的耳目，”他一字一顿，“又要,把傅野那颗钉子，护得,稳稳当当。”

“告诉弟兄们，”他转过身，眼底寒光四射，声音冷得像楼外的夜风，“三天后的今晚——”

“咱们，端了那座，能让整座冰山，睁眼变瞎子的，鼎丰。”

夜色浓重，那座城郊的老宅里，老槐还在慢条斯理地侍弄着他的兰草，只当那根刺，已经稳稳扎进了对手的骨头。他不会想到，那句自以为得意的诛心之言，非但没能拦住陈牧的锤子，反倒让这个年轻人，把锤子，抡得更狠、更急了。
