# 第 131 章 烧了二十年的那口气

找苦主，比找郑维德，更难。

郑维德，好歹，还有一份旧名册，能顺藤摸瓜。而当年那两桩案子里，因夺地而死的人，他们的家人，大多，早被程立秋，用各种法子，碾成了不敢出声的尘埃——有的，远走他乡；有的，闭口不言；有的，干脆，就在这些年里，悄无声息地，没了。

陈牧的人，找了七八天，才从一堆断了线的旧档里，拎出一个，还活着、还留在本地的人。

“查到一个。”手下把一张纸，放到桌上，“当年那两条人命里，姓周的那个——周慧雪。她还有个弟弟，叫周慧明，今年，四十五。一直，没离开过这座城。”

“他姐姐，”手下顿了顿，“当年，就是为了那块地的事，没的。具体怎么没的，档案里，语焉不详。只知道，出事那年，周慧明，才二十出头。打那以后，他们家，就垮了。父母，没扛几年，相继走了。剩他一个，这些年，在城南，开了个小修车铺，过得，紧巴巴的。”

“他成家了吗。”陈牧问。

“没有。”手下说，“四十五了，一直，单身。也没什么朋友，独来独往。街坊说，这人，脾气古怪，话少，跟谁，都不亲近。”

“跟谁都不亲近。”陈牧重复了一句。

“是。就守着那个铺子，跟守着座坟似的。”手下顿了顿，“陈总，我说句实在的——这种人，心都焊死了。咱们要撬，怕是，不好撬。”

“正相反。”陈牧说，“一个，四十五岁、不成家、不交友、把自己锁在一个小铺子里二十年的人——他不是，心死了。他是，被一件事，钉在了原地，二十年，没敢、也没法，往前走一步。”

“一个真正心死的人，早就，认了命、过自己的小日子去了。可他没有。他守在这儿，守着这条，他姐姐出事的街——”陈牧的目光，沉了下来，“他是，在等。”

“等什么。”

“他自己，也未必，说得清。”陈牧说，“也许，是等一个公道。也许，是等一个，能让他把这二十年的气，出出来的，机会。”

“而我，”陈牧把那张纸，折好，“就是，来给他这个机会的。”

陈牧看着上面那个，普通得不能再普通的名字。

周慧明。

一个，被程立秋顺手碾过、又碰巧，没碾死的人。

“这个人，我亲自去看。”

手下一愣。“陈总，您亲自去，会不会，太冒险了。您这张脸，眼下，还没在程立秋面前，露过。万一——”

“正因为要紧，才得我自己去。”陈牧说，“一个苦主，能不能用，全看，他那口气，还在不在。这种事，隔着一层人去问，问不准。我得，自己，看他的眼睛。”

“至于我这张脸——”陈牧说，“我不以陈牧的身份去。我就是个，路过的、想修车的陌生人。”

城南，那间修车铺，藏在一条老旧的巷子里。

招牌的漆，掉了大半。门口，堆着几条，沾满油污的旧轮胎。

陈牧把车，停在巷口，走了进去。

铺子里，一个中年男人，正蹲在地上，捣鼓一台半旧的摩托。他穿着一身洗得发白的工装，手上，全是油。听见动静，他头也没抬。

“修车？”

“嗯。”陈牧说，“车，在巷口。打不着火了。”

周慧明放下手里的扳手，擦了擦手，跟着陈牧，出去看车。

修车的工夫，陈牧蹲在一旁，有一搭没一搭地，跟他闲聊。

“师傅，手艺真不错。这毛病，别人未必看得出来。”

“干了二十多年，闭着眼，也摸得着。”周慧明的声音，从引擎盖底下，闷闷地传出来。

陈牧不动声色地，打量着他。这个男人，话很少，背，佝偻着，像是常年扛着什么看不见的重担。他的眼神，是那种被生活磨得没了棱角的，麻木。

“二十多年。”陈牧顺着话头，“那这铺子，开了有些年头了。我看这一片，挺老的——这种老巷子，现在不多见喽。是不是，早晚也得拆？”

周慧明的动作，几不可察地，停了一瞬。

“拆不了。”他说，声音里，听不出情绪，“早些年，倒是嚷嚷过要拆。后来，不知怎么的，又黄了。”

“黄了？”陈牧像是随口，“这地段，要真开发，值不少钱吧。怎么说黄，就黄了。”

引擎盖底下，沉默了一下。

“谁知道呢。”周慧明直起身，擦了擦手，没看陈牧，“这种事，上头一句话。轮不到我们这些修车的，操心。”

这话，说得平淡。可陈牧，捕捉到了，那平淡底下，一闪而过的，别的东西。

陈牧没有立刻接话。他点上一支烟，递过去一支。

周慧明迟疑了一下，接了。

“师傅，”陈牧给他点上火，语气，放得很随意，“我听人说，这一片，早些年，是不是，出过点事？还死过人？”

这一句，像是，戳到了什么。

周慧明捏着烟的手指，猛地，收紧了。

他抬起头，看了陈牧一眼。那一眼里，有警惕，有戒备，还有，一闪即逝的——一种，被人猝不及防，揭开旧伤疤的，剧痛。

“没有的事。”他很快垂下眼，把那点情绪，死死，按了回去，“瞎传的。这一片，太太平平，几十年，没出过事。”

这话，说得太快，也太硬。

一个，真正太平的人，不会对一句闲话，反应得这么急。

陈牧看着他重新埋下头、假装专注修车的样子，没有再追问。

他要看的，已经，看到了。

陈牧没有去想，上一世，有没有这么一个，叫周慧明的人。

那本剧本里，没有他。一个被碾进尘埃里的小人物，本就，不配在那本，只记得大人物结局的剧本里，留下一笔。

可恰恰是这些，剧本里没有的小人物，身上，烧着陈牧最需要的东西——

二十多年，没凉透的，那口气。

车，修好了。

陈牧付了钱，没有多说一个字，转身，走了。

他要的东西，已经，看到了。

这个周慧明，没有认命。他姐姐的死，那块地的事，程立秋这个名字——这些，在他心底，烧了二十多年，从没，真正，熄过。

他是，一个，可以用的人。

可陈牧也清楚，这口气，埋得太深了。深到，周慧明把它，藏在了麻木底下，藏在了一间小小的修车铺里，藏了二十多年。

一个，把恨藏得这么深的人，藏着的怕，也一定，同样深。

他怕程立秋。怕得，把自己活成了一个，只会修车的、没脾气的，中年人。

要让这样一个人，重新把那口气，提起来；要让他，敢站到程立秋面前，亲口，指认——

光，有恨，不够。

还得，让他看到，程立秋，真的，会倒。还得，让他信，这一回，有人，能替他，撑到底。

这，不是一次，就能办成的事。

陈牧开着车，离开城南。

车上，他给手下，去了个电话。

“看过了。”他说，“是个可用的人。”

“他肯帮咱们？”

“现在还不肯。他自己，都还不知道，自己肯不肯。”陈牧说，“一个把恨压了二十多年的人，你今天去捅他一下，他第一反应，不是跟你联手，是把你当成又一个，来揭他伤疤、看他笑话的人。”

“那怎么办。”

“慢慢来。”陈牧说，“从今天起，安排个人，常去他那儿修车、买烟、唠嗑。先让他，习惯有这么个人，在身边。别提那块地，别提他姐姐，更别提程立秋——一个字，都别提。”

“就这么，干养着？”

“不是干养，是等火候。”陈牧说，“等外头那两座火山，斗出个结果、等程立秋，露出真正的颓势——到那时候，我再亲自，去见他第二面。”

“到那时候，”陈牧的声音，沉静，“我才能，给他那句，他这二十多年，最想听、也最不敢信的话。”

“什么话？”

“‘那个害死你姐姐的人，要倒了。’”陈牧一字一句，“‘而你，可以亲手，推他下去。’”

电话那头，静了一下。

“陈总，”手下说，“您这是，要把一个，认了二十年命的人，重新，点着。”

“对。”陈牧说，“这世上，最锋利的刀，不是钱，也不是权。是一个，憋了二十多年、终于等到机会的，苦主。”

他找到了，那颗，他最需要的子。

可这颗子，落不落得下去，还得看，他能不能在接下来的日子里，一点一点，把周慧明心底那口，埋了二十多年的气——

重新，吹燃。

而吹燃它的，最好的、也是唯一的火种，是——

六月十三，程立秋，倒台的，那一天。

可那一天，还没到。

在那之前，他得先，让周慧明，信他。

后视镜里，那间挂着褪色招牌的修车铺，慢慢，远了。

陈牧握着方向盘，把这个名字，牢牢，记下。

周慧明。

他的第三颗子。

不，这一回，是，第四颗。

距离六月十三，还剩一百五十六天。
