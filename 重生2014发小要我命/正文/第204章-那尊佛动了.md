# 第 204 章 那尊佛，动了

华瑞跳水的第二天，陈牧就等来了远洋的回应。

这个回应，比他预想的，还要快，还要重。

“陈总，不好了。”李锐一早就冲进办公室，脸色发白，“税务和几个部门，昨晚同时给牧达下了函，说要对咱们近两年的账，做一次全面稽查。”

“不止。”沈泽紧跟着进来，声音发沉，“合作的两家银行，今早也来了电话。含含糊糊地，说什么风控收紧，之前谈好的一笔授信，要往后压一压。”

办公室里的气氛，一下子绷紧了。

税务稽查、银行抽贷——这两记闷棍，一前一后，砸得又急又准，全是冲着牧达的命根子来的。

牧达这半年，摊子铺得又大又快。吞鼎元、建海外仓、四面出击，正是最需要资金活络的当口。这时候一查账、一抽贷，就等于在牧达全力狂奔的时候，冷不丁去绊它的腿。一个不慎，就是人仰马翻。

“来得好快。”陈牧却没慌，站起身，走到窗前，缓声道，“我昨天刚咬了华瑞一口，它今天，就把这些手段全端了出来。”

“陈总，”李锐忧心忡忡，“税务那边真要认真查起来，就算咱们账干净，也够喝一壶的。银行再一抽贷，牧达的现金流，怕是要吃紧。”

“慌什么。”陈牧摆摆手，打断了他，“你们只看见远洋这两棍子狠，怎么没看见——它这一动手，自己就露了怯。”

两人一愣。

“远洋这尊佛，二十年藏在云里，靠的是什么？”陈牧转过身，目光锐利，“靠的是没人知道它在，靠的是永远不亲自下场。它躲得越深，就越安全。这份‘隐’，才是它真正的命根子。”

“可现在呢？”陈牧一字一句，“我只不过咬了华瑞一口，它就沉不住气，动税务、动银行，一口气把这么多张牌，全砸了出来。它这是在干什么？它这是在告诉我——华瑞这块肉，它疼。”

沈泽眼睛一亮：“它护得越急，就越说明，咱们戳中了它的要害。”

“对。”陈牧道，“换了从前，随便哪条无关痛痒的小鱼来惹它，它连眼皮都不抬一下。可我这一口下去，它坐不住了，宁可自己从云里探出半个身子，也要来护华瑞。”

“它动了。”陈牧望着窗外，唇角勾起一抹冷意，“这尊二十年不动如山的大佛，被我，逼得动了。”

这正是他要的。

一个永远躲在暗处的对手，才是最难对付的。你有天大的本事，也打不着一团摸不见的雾。可只要能逼它动起来、逼它出手，它每动一下，就得露一分形迹。露得多了，破绽，自然就有了。

税务和银行这两记闷棍，说到底，是远洋借着周敬堂那张官商两界的关系网，使出来的力。这张网织得有多密，恰恰暴露了远洋在国内，扎得有多深。

问题是，这股来自官面上的压力，牧达自己，未必扛得下来。

陈牧拿起电话，拨了一个号码。电话那头，是宋老。

自打先生那一战，宋老就成了陈牧在这座城里，最硬的一根靠山。当初也正是宋老，头一个警告过他，“远洋”这两个字，惹不得。

“宋老，是我。”陈牧开门见山，把税务稽查和银行抽贷的事，简明地说了一遍。

电话那头，沉默了片刻。

“我就知道，你小子迟早要跟那边碰上。”宋老的声音，带着几分无奈，又有几分赞许，“怎么样，怕了？”

“不怕。”陈牧道，“我只想问宋老一句——这压力，是官面上真有人要动我，还是,有人在背后,借着规矩,吓唬我。”

宋老笑了：“这话问到点子上了。稽查的函是真的，可动这个念头的人，级别不高，是被人递了话、卖了个人情。真要往死里办你的，还没那份分量。”

“换句话说，”陈牧眼神一凝，“是虚张声势。”

“是敲山震虎。”宋老纠正道，“他们想的，是拿这阵仗吓你退兵，不是真要把牧达连根拔了——真动手的代价，他们也掂量得清。牧达如今的体量，动它一下，满城都要跟着晃。你只要账干净、腰杆直，扛过这阵，就没事。”

“至于银行那头，”宋老顿了顿，“我替你打个招呼。牧达吞了鼎元，是块下金蛋的母鸡，不愁没人抢着借钱给你。”

“多谢宋老。”

挂了电话，陈牧眼底最后那点凝重，也散了。

宋老这几句话，等于替他把远洋这两棍子的虚实，掂了个通透——雷声大，雨点小。远洋在国内的力量再深，也不敢真把牧达这样一头庞然大物，往死里逼。它敢使的，终究只是些吓唬人的招数。

而一个只敢吓唬、不敢真下死手的对手，最怕的，就是遇上一个不吃这一套的人。

这也印证了陈牧的判断。远洋看着通天，可它真正能在国内动用的力量，是有边界的。它能借周敬堂的关系，递话、施压、吓唬人；却不敢，也不能，明目张胆地，把牧达这样一头庞然大物，一把碾碎——那样动静太大，等于把它二十年苦心经营的那个‘隐’字，亲手撕成粉碎。

它的强，强在藏。可一旦被逼着出手，这份强，反倒成了捆住它自己手脚的绳。

“税务稽查，全力配合。”陈牧转向李锐，语气笃定，“把姿态做足，查得越细，越坐实咱们的清白。银行那头，宋老会打招呼，不必理会。你只管盯着,别让底下人乱了阵脚。”

“牧达越是稳如泰山，”陈牧一字一句，“远洋就越是心慌。”

一番话，把两人翻涌的慌乱，尽数压了下去。

跟着陈牧久了，他们早摸出一个规律——越是天塌下来的时候，这位陈总，反倒越是镇定。他眼里看见的，从来不是眼前这点风浪，而是风浪底下，那条别人看不见的路。

出海这条路，前世的剧本从没走过；远洋这尊佛，剧本上更是提都没提过。陈牧能一次次在这些剧本没写过的绝境里，把死棋走活，靠的从来不是先知先觉，而是这两世拿命换来的定力和眼光。

前世的他，一遇上这种官面、银行的压力，就慌了手脚，任人拿捏。可如今，同样的招数砸下来，他一眼就看穿了背后那只手的虚实。

“慌的，不该是我们。”陈牧道，“是躲在云里那位。他护华瑞护得越用力，就越是把自己的胳膊，往我刀口上送。”

果然，当天下午，华瑞那边就传来消息。一笔来路不明的巨额资金，正火急火燎地，往华瑞的窟窿里填，硬生生把那根被陈牧抽断的资金链，又勉强给接了起来。

“看见没有。”陈牧把那份消息递给沈泽，“它急着救华瑞，连钱的路数都顾不上遮掩了。这笔救命钱从哪儿来、经了谁的手——顺着它查下去，就是又一条，通往云里那只手的线。”

沈泽接过消息，眼睛越来越亮。他这才彻底明白，陈总咬华瑞这一口，图的根本不只是华瑞。而是拿华瑞当饵，逼远洋一次次出手救场。可每一次救场，都是在替陈牧，把那张藏了二十年的网，一点一点，扯开。

正说着，沈泽的手机，震了起来。他看了眼来电，脸色微变，快步走到一旁接听。

几句过后，他挂了电话，回到陈牧面前，压低了声音。

“陈总，周敬堂那边，有动静了。”沈泽神色凝重，“他没像咱们想的那样躲起来。刚刚，他主动递了话过来——想跟您，单独见一面。”

陈牧眼底，寒光一闪。

周敬堂这一步，走得并不奇怪。

他如今，是被架在了火上烤。一头，是陈牧咬着华瑞不松口，把他替远洋看了二十年的家底，一口一口往下撕；另一头，是远洋。生意人最清楚一个理——办砸了差事的白手套，在主子眼里，一文不值。华瑞要是真丢了，远洋头一个要收拾的，就是他这个看门不力的看门狗。

两头，都是刀。周敬堂想单独见他，无非是想在这两把刀之间，替自己，寻一条活路。

而一个被架在火上、走投无路的人，往往，也是最肯松口的人。周敬堂肚子里，装着远洋二十年的秘密。这，正是陈牧求之不得的。

“他倒是识时务。”陈牧一字一句，“告诉他，今晚，我赴约。”
