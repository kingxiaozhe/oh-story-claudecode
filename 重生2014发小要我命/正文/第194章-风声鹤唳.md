# 第 194 章 风声鹤唳

陈牧的那一把火，烧得比所有人想象的，都要快。

林敬之动用他在金融圈的人脉，将那些‘看衰大型实体商业综合体’的论调，不着痕迹地，散播了出去。

他没有提鼎元一个字。可在这个节骨眼上，这些话，却像一颗颗火星，落进了本就干燥的草原。

很快，风向，就变了。

“陈总，成了！”林敬之的声音里，带着压抑不住的兴奋，“市场上的风向，彻底变了。”

“之前还在观望那个综合体的几家投资机构，现在全都缩了回去。”林敬之快速道，“不光如此，连一些原本跟鼎元关系不错的合作方，最近也开始有意无意地，跟那个项目，撇清关系。”

“大家都不是傻子。”林敬之分析道，“实体商业被电商冲击的迹象，已经越来越明显。再加上有‘业内人士’看衰，谁还敢把钱，往那个无底洞里扔？”

陈牧这一手，堪称毒辣。

他没有捏造任何谣言。他所做的，仅仅是把一个即将到来的事实，提前捅破，然后，让市场的恐慌，自己去发酵。

人都有从众的本能。起初，或许只有一两家机构动摇。可当撤资的人越来越多，那些还在观望的，便会本能地，跟着逃离。

这是一场雪崩。而陈牧，只是那个，在最恰当的时机，喊出第一声的人。

“做得漂亮。”陈牧赞许地点头，“记住，咱们自始至终，都没有出面。这只是市场自发的选择。”

“明白。”林敬之会意一笑，“咱们只是顺水推舟罢了。”

而真正致命的，是那场，陈牧等候已久的寒冬。

几乎是在同一时间，一股席卷整个实体零售行业的寒流，悄然降临。

各地的大型商场，客流，开始断崖式下跌。一家接一家的实体店，挂出了清仓转让的牌子。曾经被视为黄金资产的商业地产，一夜之间，成了人人避之不及的烫手山芋。

裴渊那座还未完工的综合体，正好撞在了这股寒流的枪口上。

这股寒流，并非凭空出现。

它是一个旧时代落幕的信号。当越来越多的人，习惯了在网上购物，那些曾经人头攒动的大型商场，就失去了存在的根基。

潮水退去的时候，才知道谁在裸泳。

无数曾经风光无限的商业地产大鳄，在这场变革中，资金链断裂，轰然倒下。而裴渊，偏偏在这个节骨眼上，用最高的杠杆，把身家性命，压在了一座巨大的商业综合体上。

这不是运气不好。这是他对这个时代，最根本的误判。

陈牧没有创造这场寒冬。他只是比所有人，都更早地，听到了它逼近的脚步声。然后，精准地把裴渊的命门，送到了寒冬的刀口之下。

“雪上加霜的是，”林敬之继续汇报，“那个项目的资金链，已经到了断裂的边缘。”

“招商彻底停摆，预售无人问津。裴渊从其他产业抽来的血，根本填不满那个越来越大的窟窿。”林敬之顿了顿，“我得到消息，已经有工程队，因为拿不到工程款，开始闹着要停工了。”

一个耗资巨大的‘地标工程’，竟然要停工了。这个消息要是传出去，对鼎元的信誉，将是致命的打击。

而此刻的鼎元内部，裴渊，第一次真正感受到了危机。

“裴董！”周总慌张地闯进办公室，“不好了！那个综合体……出大事了！”

“市场上，到处都是看衰的声音。好几家谈好的投资机构，临时撤资。工程队也在闹停工。”周总的声音发颤，“项目的资金链，眼看就要撑不住了！”

裴渊猛地从椅子上站起来，脸色，铁青。

他千算万算，怎么也没想到，自己这座寄予厚望的丰碑，会在这么短的时间里，就土崩瓦解到这个地步。

电商冲击实体零售？他不是没听过这种说法。可在他的认知里，那不过是危言耸听。商业地产这块金字招牌，怎么可能说倒就倒？

可残酷的现实，狠狠地，扇了他一记耳光。

“撤资的那几家，给我稳住！”裴渊强压着怒火，厉声下令，“告诉他们，鼎元的信誉，做担保！工程款的事，我亲自去协调银行！”

“可是裴董，”周总面露难色，“现在市场风声这么紧，银行那边……怕是不好松口啊。”

裴渊的脸色，更加阴沉。

他经营鼎元二十年，何曾遇到过这种局面？往日，他只需一个电话，多少银行抢着给他送钱。可如今，那些曾经对他毕恭毕敬的银行，却一个个，避而不见。

墙倒众人推。这四个字的分量，裴渊今天，算是真正尝到了。

更让他心惊的是，他发现，自己竟然对这场危机，束手无策。这种失控的感觉，是他二十年来，从未有过的。

“看衰的声音……”裴渊忽然想起茶室里，陈牧那句意味深长的话——‘多留意自己锅里的水，是不是快烧干了’。

一个可怕的念头，涌上他的胸口。难道，这一切，都是那个叫陈牧的年轻人，在背后搞的鬼？

可这怎么可能？一个做跨境仓储的毛头小子，怎么会知道，电商会在这个时候，冲垮实体零售？他又凭什么，能搅动整个市场的风向？

裴渊想不明白。但一股前所未有的寒意，却顺着他的脊背，爬了上来。

而另一边，陈牧这边，一切，尽在掌握。

“裴渊坐不住了。”沈泽前来汇报，“听说，他这两天焦头烂额，正四处筹钱，想给那个项目续命。”

“续不了多久的。”陈牧淡淡道，“寒冬才刚刚开始。他就算有通天的本事，也逆转不了整个时代的大势。”

“他现在所做的一切挣扎，都只是在延缓死亡的时间罢了。”陈牧走到窗前，“一个靠高杠杆堆起来的泡沫，在寒冬面前，破得只会更快。”

“何况，”陈牧的嘴角，勾起一抹弧度，“我还准备在这泡沫上，再扎上一针。”

沈泽愣了一下，随即反应过来，陈总这是，要主动出手了。

跟鼎元缠斗了这么久，一直是牧达被动挨打。如今，攻守易势，终于，轮到牧达，主动亮剑了。

这一切，都和陈牧记忆中的，分毫不差。那本‘剧本’，从未告诉他这些。可他凭着对未来的洞悉，早已看清了这盘棋的终局。

裴渊这头巨鳄，如今已经，是强弩之末。压垮它的最后一根稻草，该放上去了。

陈牧要的，从来不只是守住牧达。他要的，是趁你病，要你命，把鼎元这头挡在他出海路上的巨鳄，彻底踩在脚下。

当天晚上，陈牧的办公室里，灯火通明。

林敬之、孙建国，还有沈泽，悉数到场。陈牧把一份早已准备好的方案，放在了桌上。

“鼎元现在最缺的是什么？”陈牧开门见山，“是钱。是能让那个综合体，喘过气来的救命钱。”

“而我要做的，”陈牧的嘴角，勾起一抹冷冽的弧度，“就是断了它最后一丝，活下去的希望。”

“林敬之，你出面，以牧达的名义，放出风声——牧达有意接手几个，因资金问题而陷入困境的优质项目。”陈牧一字一句，“我要让所有人都知道，连牧达，都在等着捡鼎元的尸体。”

此言一出，办公室里的众人，无不倒吸一口凉气。

这一招，可谓是，诛心之计。它等于是，公开向整个商界宣告——鼎元，要完了。

“陈总，这会不会太狠了点？”孙建国迟疑道，“万一逼得裴渊狗急跳墙……”

“我要的，就是他狗急跳墙。”陈牧眼神平静，“一个慌了神的对手，才会自乱阵脚，露出更多的破绽。”

“更何况，”陈牧的语气转冷，“当初是他先断我的粮、挖我的人，想把牧达往死里逼。我今天做的，不过是把他加在我身上的，原样奉还。”

“他要是识趣，早在茶室那天，就该收手。”陈牧淡淡道，“可他偏要赶尽杀绝。那就别怪我，不留情面。”

众人闻言，再无异议。他们都清楚，自家这位陈总，看着温和，可真要翻起脸来，比谁都狠。

“放心吧陈总。”林敬之郑重应下，“这件事，我一定办得滴水不漏。”

陈牧望向窗外鼎元大厦的方向，一字一句：“裴渊，你不是想知道，是谁在背后点的火吗？明天，我就亲自让你，看个明白。”
