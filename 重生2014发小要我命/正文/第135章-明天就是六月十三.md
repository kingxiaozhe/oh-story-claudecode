# 第 135 章 明天，就是六月十三

冬天，过去了。

那场，由陈牧在暗处点起、又不断添柴的火，烧了整整一个春天。

程立秋和邬庆山，从你死我活的缠斗，烧到两败俱伤。可程立秋，伤得更重。

招投标的旧账，被翻了出来；几个白手套公司，被查；走得近的人，一个接一个，被带走；曾经对他俯首帖耳的那些人，嗅到了风向，开始作鸟兽散；那些被他踩过、压过的人，也趁着他自顾不暇，纷纷补刀。

到了春末，那座，曾经沉默地压着整座城二十多年的山——已经千疮百孔，摇摇欲坠。

所有人，都看得出来：姓程的，这一回，是真的，要完了。

程立秋自己，比谁都清楚，这一点。

那阵子，他像是一夜之间，老了十岁。烟，一根接一根；电话，一个接一个地，打出去——可从前那些，一呼百应的人，如今，接电话的，越来越少；接了的，也推三阻四。

他这才真切地，尝到了，什么叫树倒猢狲散。

他不是没想过，是谁，在背后捅他。可他想破了头，那个影子，始终是邬庆山——那个两年前，被他截了胡、记恨至今的老对头。

他做梦，也想不到，真正把他一步步逼到这个绝境的，是一个，他从来没正眼看过的小年轻。一个，叫陈牧的，开了家不起眼的小公司、还差点被他当成软柿子捏了的，人。

灯下黑。

这一回，轮到程立秋，自己，栽在这三个字上了。

陈牧站在窗前，望着这座，被他一手搅得天翻地覆的城。

火候，到了。

那座山，已经被外面的风浪，削得只剩最后一层，薄壳。现在，只需要有人，在它最致命的那个地方，再狠狠，捅上一刀——

它，就会，轰然倒塌。

而那一刀，他，已经磨了，整整一年多。

这几个月，陈牧，没有闲着。

他去邻县，见了郑维德，好几次。

每一次，他都不提，要东西。他只是陪那个孤独了二十多年的老人，坐一坐，说说话，把城里，程立秋一天不如一天的消息，一点一点，带给他。

他看着那个，曾经一见生人就魂飞魄散的老人，一次比一次镇定；看着他眼里，那点被恐惧压了二十多年的东西，一点一点，活，过来。

直到有一天，郑维德，主动，对他说了一句话。

“那东西，”老人的声音，不再发抖了，“到了该用的时候，我，给你。”

陈牧看着他。

“你，不怕了？”

“怕。”郑维德，惨然一笑，“怕了，一辈子了。可你说得对——他一天不倒，我就一天，做不成一个，敢见光的活人。”

“我把这条命，这样藏了二十多年，藏够了。”他说，“在死之前，我想，做一回，人。”

陈牧沉默了一下。

“老人家，”他说，“你藏了二十多年，护住的，不只是你自己的命。”

郑维德，看着他。

“你护住的那样东西，”陈牧说，“是周慧雪那样的人，用命，都没能换来的公道。这二十多年，它在你手里，没烂掉、没丢掉、没被程立秋找出来销毁——单凭这一条，你，就不是一个，只会躲的，孬种。”

郑维德浑浊的眼睛，一点一点，红了。

二十多年了。这是头一回，有人告诉他——他这藏头露尾、苟且偷生的二十年，不是白活的。他守的那样东西，是有，分量，的。

“到那天，”老人，重重地，说，“我，一定到。”

陈牧没有问，那东西，到底是什么。

他知道，到了六月十三那一天，它，自然会亮出来。而那一亮，会是压垮程立秋的，又一记，重锤。

第三颗子——不，这一回，是把一个，藏了二十年的活人，和他手里的东西，一起，请回了棋盘。

陈牧回到办公室，把负责各处的人，都叫了来，做最后一次，核对。

“钱进那边。”

“稳。”手下答，“人在外地养着，身子还撑得住。原始登记的原件，跟他分开，安全。您一声令下，他随时能启程回来。”

“周慧明。”

“守着他的铺子，照常过日子。城里程立秋的事，他天天都在听。”那人说，“他跟我说过一句——‘那一天，你们说什么时候，我什么时候到。我这把骨头，早就，备好了。’”

陈牧点了点头。

“郑维德。”

“肯了。”负责邻县那路的人说，“老爷子这阵子，跟变了个人似的。他说，到时候，他亲自来，把东西，交到您手上。”

“证据呢。”

“原始登记，在您手里。郑维德那样东西，他随身带着。”手下顿了顿，“再加上……您一直没让我们碰的、那个留到最后的引子——”

“那个，”陈牧打断他，“不用你们管。到时候，我自己，来点。”

屋里，静了下来。

所有的子，都，归位了。

陈牧没有，再去翻找上一世的记忆。

那本残缺的剧本，只告诉过他一个结局：程立秋，会倒。可怎么倒、靠谁的手倒、在哪一天倒——这些，剧本里，一个字都没有。

这一年多，他磕磕绊绊，栽过跟头，腹背受敌过，险些满盘皆输过。可走到今天，他靠的，从来不是那个缥缈的结局。

是他自己，一颗一颗，亲手落下的，子。

可就在所有的子归位的同时，一个消息，让陈牧意识到——他，不能再等了。

“陈总，”手下来报，“程立秋那边，有动静。他撑不住了，最近，在暗中，跟邬庆山，接触——像是想，跟邬庆山各退一步，把这场仗，停下来。”

陈牧的目光，沉了下来。

他等的，就是这个最坏的可能。

程立秋，不傻。他被这场，看不见底的仗，拖得快散架了。他也看出来了——再这么斗下去，他和邬庆山，会一起玩完。

所以，他想，收手。

一旦，他跟邬庆山握手言和，那两座互相撕咬的火山，就会同时平息。程立秋腾出手来，做的第一件事，会是什么？

是回过头，把这一年来，让他焦头烂额的源头，查个水落石出。

到那时候，陈牧在暗处布的所有的局，都，可能暴露。

“窗口，要关了。”陈牧，低声，说。

“那……要不要，提前？”手下问，“趁程立秋还没跟邬庆山谈拢，咱们，现在，就动手？”

“不。”陈牧摇头，“提前，太仓促。钱进要从外地赶回来，郑维德要从邻县过来，几样东西要凑齐，几个人要碰头——这些，都得，精确地卡在同一个时间、同一个地方，一起，炸响。早一步，散；晚一步，黄。”

“就六月十三。”陈牧说，“那一天，我要的，是所有人、所有的料，在程立秋最罩不住的那个明处，一起，落下。不能提前一天，也，绝不能拖到——程立秋跟邬庆山握手的，那一天，之后。”

“就这几天，”陈牧的目光，沉静，“是我们，唯一的窗口。卡死它。”

“明白。”

他不能等到，程立秋跟邬庆山谈拢。他必须赶在，那座山缓过这口气之前——把它，推倒。

他转过身，对手下，下达了，这一年多来，他等待已久的，命令：

“通知所有人。”陈牧一字一句，“按原计划。六月十三。”

“钱进，启程回来。周慧明，郑维德，到位。所有的证据，所有的人——那一天，一起，亮出来。”

“我们等的那一天，到了。”

命令，传了下去。

入夜前，最后一通电话，是手下打来的。

“陈总，”那头说，“都安排妥了。钱进的人，明天一早，护着他动身。郑维德，今晚就从邻县出发，明天上午到。周慧明那边，待命。能到场的，都会，准时到。”

“好。”

“陈总，”那人顿了一下，声音里，有点说不清的东西，“熬了一年多……明天，真就，到了。”

“嗯。”陈牧说，“你们，都辛苦了。明天——把这一年多，欠程立秋的，连本带利，一次，讨回来。”

挂了电话。

那一夜，是，六月十二。

陈牧，一个人，站在窗前。

明天这个时候，那座，压了这座城、也压了他前世今生的山，就，要塌了。

二十多年前，那块地，那两条被碾进尘土的人命。一年多来，那些被他从黑暗里，一个一个请出来的人——钱进，周慧明，郑维德。还有那个，他一直藏在最深处、要替之讨回公道的，人……

明天，他们所有人等的这一天，终于，要来了。

整整一年多。从他重生回来的那一刻起，他走的每一步、布下的每一颗子、栽过的每一个跟头，都是，为了，明天。

陈牧，望着窗外，那片初夏的夜空。

“程立秋。”他一字一句，“二十多年了。这一回，该，你，下来了。”

明天，就是，六月十三。

距离六月十三——

还剩，最后，一天。
