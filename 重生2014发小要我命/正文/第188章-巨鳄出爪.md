# 第 188 章 巨鳄出爪

沈泽的调查结果，很快，就摆在了陈牧的案头。

鼎元资本背后，真正的掌舵人，是一个叫裴渊的男人。

“裴渊？”陈牧念着这个名字。

“在资本圈里，这是一个，神一样的人物。”沈泽的语气里，带着一丝凝重，“他二十年前，白手起家，硬是靠着一次次，精准得可怕的资本运作，把鼎元，做成了如今的庞然大物。”

“这个人，最出名的，就是‘吞并’。”沈泽一字一句，“被他盯上的公司，几乎没有一个，能逃得掉。要么，被他高价收编；要么，被他用资本的手段，活活绞杀，最后贱价吃下。”

“他的人脉，通天。政商两道，都有他的人。”沈泽顿了顿，“陈总，这个对手，比那位先生，要可怕得多。”

沈泽的话，绝非危言耸听。

资料里，零星记载着，几桩裴渊的‘战绩’。某家前景大好的科技公司，因为拒绝了鼎元的收购，半年之内，就莫名陷入资金链断裂，最终，被鼎元，以一个白菜价，收入囊中。

还有一家，行业龙头，跟鼎元叫板，结果，旗下几块核心业务，接连遭到精准的狙击，元气大伤，再也没能缓过劲来。

这些案例，桩桩件件，都透着一股，令人胆寒的狠辣与精准。裴渊这个人，做起事来，从不讲什么情面，只看利益。挡他财路的，无论是谁，都只有一个下场。

这样一头，真正的庞然大物，才是陈牧跳出那口井后，要面对的第一个，真正意义上的大敌。

陈牧看着资料上，那个只有寥寥数语的介绍，沉吟着。

资料上关于裴渊的信息，少得可怜。这个男人，行事极其低调，外界对他的了解，少之又少。

但有一点，陈牧可以肯定。一个把‘吞并’，刻进骨子里的人，绝不会因为自己一句‘不卖’，就善罢甘休。

果然，没过几天，鼎元的爪牙，就伸了过来。

第一刀，砍向的，是牧达刚签下的那些跨境卖家。

“陈总，不好了！”沈泽匆匆赶来，脸色难看，“鼎元，在挖咱们的墙脚！”

“他们派人，挨个去找咱们签约的卖家，开出的条件，比咱们，好得太多了。”沈泽急道，“免费仓储、低息贷款，甚至，还愿意直接入股。已经有好几家，动摇了！”

鼎元财大气粗，这种赔本赚吆喝的买卖，它亏得起。可牧达，跟着这么拼，迟早得被拖垮。

更棘手的，还在后面。

“还有，”沈泽的声音，更沉了，“咱们几块准备用来建仓的地，本来谈得好好的，突然，就被人搅黄了。银行那边，原本说好的贷款，也卡住了。”

“是鼎元？”陈牧问。

“八九不离十。”沈泽咬牙，“除了他们，没人有这个本事，能在这么短的时间里，又断咱们的地，又卡咱们的钱。”

挖墙脚、断粮道。鼎元这头巨鳄，一出手，就是冲着牧达的命门去的。

这两招，招招致命。

牧达的跨境仓储，刚刚起步，根基未稳。卖家，是它的血肉；资金和土地，是它的筋骨。鼎元这一下，等于是，要把牧达这棵刚冒头的树苗，连根拔起。

公司里的气氛，一下子，紧张了起来。前些日子，还沉浸在开门红喜悦里的众人，此刻，都感受到了那股，从云端压下来的，泰山般的重量。

有人开始私下议论，牧达这次，是不是惹了，不该惹的人。也有人偷偷，看向陈牧的办公室，等着看，他们这位年轻的陈总，要如何接下，这雷霆一击。

陈牧却出奇地平静。

“裴渊这是在告诉我，”他淡淡道，“拒绝他的代价。”

“他想用这种方式，逼我就范。要么乖乖把牧达卖给他，要么，就看着牧达，被他一点一点，耗死。”

“那咱们怎么办？”沈泽急得团团转，“真跟他这么耗下去，咱们的家底，根本撑不了多久啊！”

“硬碰硬地耗，咱们确实耗不过他。”陈牧站起身，走到窗前。

跟鼎元这种体量的巨鳄拼资本，无异于以卵击石。这一点，陈牧比谁都清楚。

可越是这种时候，他越不能乱。

陈牧很清楚，裴渊这一套组合拳，打的就是一个‘势’字。他要的，不光是断牧达的粮，更是要在气势上，彻底压垮牧达，让牧达内部，自己先乱起来。

只要军心一散，卖家一跑，那牧达，根本不用鼎元动手，自己就会土崩瓦解。

所以眼下，稳住人心，比什么都重要。慌了阵脚，才是最致命的。

陈牧深吸一口气，强迫自己，冷静下来。他这两世，经历过的大风大浪，比这凶险的，多了去了。越是绝境，越要沉得住气。

这场仗，比他预想的，来得更快，也更猛。

那本‘剧本’，依旧，没有给他任何提示。它不会告诉他裴渊是谁，更不会告诉他，该如何对付这头，远比先生强大的巨鳄。

可陈牧知道，硬拼不行，不代表，没有别的路可走。

鼎元看着无懈可击，可再庞大的巨兽，也有它的软肋。裴渊以为，凭着雄厚的资本，就能碾死牧达。可他忘了，这条赛道的玩法，他陈牧，比他看得更透。

陈牧的眼中，寒光一闪。

跟巨鳄拼力气，是蠢。可要是，能找准它的七寸，四两，也能拨千斤。

鼎元的盘子，铺得太大了。

地产、金融、能源、科技……样样都要占，样样都要钱。这种巨无霸式的扩张，看着风光无限，实则，处处都绷着一根弦。

它的资金，看着雄厚，可一旦，某几个重仓的项目，同时出了问题，再庞大的巨鳄，也会瞬间，陷入被动。

陈牧要做的，就是找到鼎元如今，押得最重、也最容易出问题的那个‘七寸’。然后，在关键时刻，给它，狠狠的一击。

这需要精准的判断，更需要，对大势的把握。而这，恰恰是陈牧，凭着两世记忆，最擅长的事。

想通了这一层，陈牧的眼神，重新变得坚定起来。

鼎元来势汹汹，可这场仗，远没到认输的时候。

第一步，得先稳住自己的基本盘，绝不能让鼎元，把卖家挖空。第二步，再去找鼎元的破绽，伺机反击。

一守，一攻，这场仗，才有的打。

“沈泽，”陈牧忽然转身，“你马上，去做两件事。”

“第一，稳住咱们签下的卖家，尤其是钱老板。告诉他们，牧达不但不会倒，还会给他们，鼎元给不了的东西。”

“鼎元给不了的东西？”沈泽一愣，“陈总，鼎元财大气粗，咱们能给的，它都能给，而且给得更多。咱们拿什么，跟它拼？”

“拼钱，咱们拼不过。”陈牧淡淡道，“可做生意，靠的，从来不只是钱。”

“鼎元挖人，靠的是免费仓储、低息贷款。这些，都是看得见的实惠。”陈牧一字一句，“可它给不了卖家，最想要的东西——一个能跟他们长长久久、共同把生意做大的伙伴。”

“鼎元要的是吞并，是把这些卖家，当成养肥了就宰的猪。”陈牧眼神锐利，“而我陈牧，要的是共赢。这里头的区别，但凡是个聪明人，都分得清。”

沈泽愣了愣，随即，眼睛一亮。

“第二，”陈牧眼神锐利，“去帮我查一件事。我要知道，鼎元如今，把宝，押在了哪条赛道上。”

“它既然，断我的粮，挖我的人，”陈牧一字一句，“那我就得看看，它自己的身上，有没有，可以反击的破绽。”

“查它押在哪条赛道上？”沈泽有些迟疑，“陈总，鼎元的摊子那么大，咱们人手有限，从哪查起？”

“不用面面俱到。”陈牧胸有成竹，“你重点盯着，它这一两年，新砸进去、又还没见回头钱的大项目。”

“越是这种刚投进去的无底洞，越是鼎元的软肋。”陈牧目光深远，“一旦这些项目出了岔子，需要资金回笼，那它在跨境这边，就未必，还撑得住这么大的出血。”

沈泽听得连连点头。他虽然还不完全明白，陈总究竟要怎么反击，可他已经，看到了一丝希望的曙光。

“放心吧陈总！”沈泽重重抱拳，“这两件事，我一定给您，办得妥妥的！”

“想吞了我牧达？”陈牧望向窗外，嘴角，勾起一抹冷冽的弧度，“裴渊，怕是要被我这块硬骨头，硌掉几颗牙。这场仗，明天，才真正开始。”
