# 第 166 章 一个熟悉的名字

接下来的两个多月，陈牧这边，过得忙碌而充实。

明面上，牧达的盘子，越铺越大。旧城那个项目第二期顺利开盘，又是一抢而空。陈牧趁热打铁，接连拿下了好几块地，牧达的版图，肉眼可见地，在市里扩张。

“陈总，照这势头，”孙建国笑得合不拢嘴，“咱们牧达，用不了两年，就能挤进市里地产的第一梯队了。”

“第一梯队，只是个开始。”陈牧却看得更远，“咱们要做的，是把家底，越攒越厚。家底越厚，将来真到了跟那位先生掀桌子的时候，咱们能动用的牌，才越多。”

众人闻言，都是精神一振。他们虽不知道那位先生的全部底细，却都明白，自家老板，正在下一盘很大的棋。

而暗地里，沈泽对林敬之的调查，也在稳步推进。

“陈总，”这天，沈泽抱着一摞越来越厚的卷宗，沉声汇报，“林敬之经手的那些洗钱的脏事，我又坐实了好几桩。”

“证据链，一天比一天完整。”沈泽道，“照这个进度，再过个把月，咱们手里攥着的东西，就足以，让他这个‘清白’的企业家，身败名裂、锒铛入狱了。”

“好。”陈牧点头，“到那时候，就是逼他做选择的时候。火候，快到了。”

“陈总，”沈泽却有些谨慎，“话虽如此，可逼反林敬之这一步，凶险得很。万一他不肯就范，反而把咱们查他的事，捅给了那位先生，那咱们这几个月的苦功，可就暴露了。”

“所以才要把证据，做到铁。”陈牧不慌不忙，“铁到他一看，就知道自己已经是砧板上的肉，反抗只有死路一条——到那个份上，他还敢去赌那位先生会救他吗？”

“那位先生是个什么样的人，林敬之比谁都清楚。”陈牧一字一句，“他要是真栽了，那位先生第一个做的，不是救他，而是灭口。这一点，他想得明白。”

“您是说，”沈泽眼睛一亮，“到时候，咱们不光要用证据逼他，还要让他明白，他唯一的活路，就是反水？”

“正是。”陈牧点头，“给他一条生路，他才肯把刀，递到咱们手里。”

沈泽心悦诚服。

“对了，陈总。”沈泽像是想起了什么，神色有些古怪，“在查的过程中，我还顺手，挖到了一桩陈年旧事。”

“怎么？”

“我顺着林敬之的账，往早年追。”沈泽道，“想看看那位先生的钱，最早是怎么起家的。结果，我发现，那位先生早年的资金里，有很大一部分，是通过一家公司，运作起来的。”

“这家公司，”沈泽顿了顿，“叫——宏远投资。”

宏远投资。

这四个字，像一道惊雷，轰然炸开。

陈牧的瞳孔，骤然收缩。端着茶杯的手，几不可察地，紧了一下。

宏远投资……他怎么会，不认识这个名字？

前世，正是这家宏远投资，用一场精心设计的资本运作，吞并了他辛辛苦苦创下的整个公司。他被扫地出门，一无所有，最终，落得个凄惨的下场。

他重生归来，扳倒邬庆山，很大一部分原因，就是因为邬庆山，正是当年操盘宏远、亲手将他逼上绝路的人之一。

可那时候，他一直以为，邬庆山，就是宏远背后的主使。

直到此刻，沈泽这一句话，才像一道光，劈开了他记忆里，那团最浓重的迷雾——

原来，邬庆山，也不过是个台前的操盘手。真正藏在宏远背后、给邬庆山撑腰、调动那笔庞大资金的人……

竟是那位先生。

难怪。

难怪每当他面对“那位先生”这个名字，总会涌起那股说不清、道不明的异样。难怪他对这个素未谋面的人，总有一种近乎本能的熟悉与忌惮。

原来，早在前世，他就已经，败在了这个人的手里。只不过那时候的他，连对方的影子，都没能看清。

陈牧端着茶杯，久久没有说话。书房里，一时陷入了死一般的寂静。

他和那位先生之间的这笔账，从这一刻起，彻底，变了味道。

这，不再仅仅是一场商场上的新仇。这是一笔，跨越了两世的血海深仇。

前世，他被这个人，在暗中摧毁了一切，死得不明不白。这一世，他绝不会再重蹈覆辙。

“陈总？您怎么了？”沈泽察觉到陈牧的异样，关切地问。

陈牧放下茶杯。

“没事。”陈牧抬起头，眼中翻涌的情绪，已经被他强行压了下去，“只是没想到，这个林敬之的线，还能扯出宏远来。”

“陈总也听说过宏远？”沈泽有些意外。

“略有耳闻。”陈牧不动声色，“早些年市里的一桩公案罢了。这家公司，现在还在吗？”

“早没了。”沈泽道，“宏远当年，靠着一系列资本运作，吞并了好几家公司，赚得盆满钵满。可后来，不知怎么的，悄无声息地，就注销了。当时还有不少人觉得蹊跷。”

“现在看来，”沈泽压低声音，“怕是那位先生，用完了这枚棋子，就把它，连人带壳，一起处理干净了。邬庆山能在宏远的事里全身而退，多半，也是那位先生在背后，替他抹平的。”

陈牧静静地听着，端着茶杯的指节，又紧了几分。

每多听一句，他对那位先生的认知，就更深一层。这个人做事，斩草除根、不留半点首尾，狠辣、缜密，远超常人。

难怪前世，他败得那样彻底，连一点翻身的线索，都抓不住。

他没有把宏远与自己前世的恩怨，告诉沈泽。这个秘密，太过惊世骇俗，他只能，烂在自己肚子里。

但这桩意外的发现，却让他扳倒那位先生的决心，变得前所未有的坚定。

夜里，陈牧独自在书房，对着窗外的夜色，站了很久。

他那本所谓的剧本，到程立秋、邬庆山倒台，就断了。剧本，从来没有告诉过他，邬庆山的背后，还站着一个这样的人。

剧本给他的，只是前世那场悲剧的冰山一角。而真正的黑手，真正把他推进深渊的那个人，剧本里，从未提及。

是他凭着这一世的本事，一步一步查到今天，才终于触碰到了那个被剧本隐藏了的，真相的边缘。

剧本会骗人，会有疏漏。可他亲手挖出来的东西，不会。

这一刻，那股缠绕了他许久的异样感，终于有了答案。

陈牧望着窗外那片深沉的夜，眼中，是冰冷的、淬了毒的恨意。

“那位先生……”他一字一句，声音里，带着两世的寒意，“前世，你藏在暗处，要了我的命。”

“这一世，”陈牧的目光，锐利如刀，“我倒要看看，等我把你从云里揪出来的那一天，是谁，要谁的命。”

“沈泽。”陈牧转过身，沉声道，“林敬之那条线，给我加快。还有——”

陈牧顿了顿，眼中寒光一闪。

“我要你顺着宏远这条老线，再帮我查一件事。我要知道，当年，那位先生在宏远这件事上，到底还做过些什么。”

“陈总，”沈泽有些不解，“宏远都注销这么多年了，您怎么突然，对它这么上心？”

陈牧沉默了一瞬。

“直觉。”他缓声道，“一个能把宏远这枚棋子，用得这么干净的人，他在宏远身上动的手脚，绝不会只有洗钱这一桩。把这条老线挖透了，说不定，能挖出那位先生，最早的、也是最致命的把柄。”

这话半真半假。真正的原因，他没法说。

“我明白了。”沈泽郑重点头，“我这就安排人，去翻宏远的旧档。当年跟宏远打过交道的人、经手过的项目，我都给您查个底朝天。”

“好。”陈牧的目光，沉了下来，“记住，这件事，跟林敬之那条线，一样要紧。”

沈泽领命而去。

书房里，重新恢复了寂静。那段被尘封了两世的旧事，那个一直藏在迷雾里的真凶，正被陈牧，一点一点，拽向光亮之下。

陈牧走到窗前，望着窗外那片深沉的夜，声音轻得像耳语，却字字淬着冰。

“那位先生，你藏在云里、藏了整整两世的那张脸，我倒要亲手，把它揭下来。”

“等我把宏远当年的事，查个水落石出——”陈牧的眼中，寒光凛冽。

“我要让你欠我的这两世的债，连本带利，一次还清。”

夜色深沉，无边无际。可在陈牧眼里，那片云层背后藏着的人影，已经，再无处遁形。
