# 第 172 章 抽他的血

挡下了第一波反扑，陈牧没有给那位先生，任何喘息的机会。

他要反击了。而他反击的第一刀，就捅向那位先生最要命的地方——他的钱。

“沈泽，”陈牧把林敬之，请到了一处隐秘的安全屋，“接下来这段时间，你就跟着林总。他指哪儿，你打哪儿。”

林敬之，如今已是陈牧船上的人。为了自保，他不得不把那位先生的家底，竹筒倒豆子一般，全抖了出来。

“那位先生的钱，”林敬之指着一张，密密麻麻的关系图，“看着像一座金山，可这座金山，是虚的。它全靠我这套系统，在底下撑着、转着。”

“这些年，他的钱，被拆成无数份，藏在几十家空壳公司里，互相拆借、循环担保，看着固若金汤，实则——”林敬之苦笑一声，“只要有人，从里面，精准地，抽掉几块关键的砖，整座大厦，就会从内部，开始垮塌。”

“而我，”林敬之一字一句，“就是那个，唯一知道，该抽哪几块砖的人。”

陈牧的眼中，寒光一闪。

“好。”他沉声道，“那就，从最关键的那几块，开始抽。”

“陈总，”林敬之却面露难色，“话虽如此，可这些事，得做得隐蔽。那位先生，眼线遍布，一旦让他察觉，是我在背后捅刀，我，可就死无葬身之地了。”

“这个你放心。”陈牧成竹在胸，“咱们，不正面出手。”

“那几家空壳公司的问题，”陈牧一字一句，“咱们只需要，把实证，匿名送到，该送的部门。剩下的，自有人，替咱们办。”

“至于那些资金链，”陈牧的眼中，闪过一丝狡黠，“你既然能让它转起来，自然，也知道，掐断哪一环，能让它转不动。咱们要做的，不过是，让某几笔该到的钱，‘恰好’，晚到几天。”

“一切，都做得天衣无缝，不留痕迹。”陈牧淡淡道，“就算那位先生，疑心到你头上，也抓不到，半点证据。”

林敬之听完，提着的心，这才稍稍放下。他不得不承认，眼前这个年轻人，心思之缜密，手段之老辣，远在他之上。

一场无声的猎杀，就此，悄然展开。

在林敬之的精准指引下，沈泽的人，开始了行动。

先是，那位先生名下，几家看似毫不起眼的空壳公司，因为一封匿名的举报信，被有关部门，盯上了，账户，悉数被冻结。

紧接着，几条原本在暗中，循环流转的资金链，被人从中间，神不知鬼不觉地，掐断。环环相扣的担保，瞬间，崩了一环，引得后面一连串的公司，资金告急。

那位先生，那座看似巍峨的金山，就在这一记记，精准而致命的打击下，开始以肉眼可见的速度，缩水、崩塌。

这种打击，比正面的强攻，要可怕得多。

陈牧没有去碰那位先生，那些摆在明面上的产业。他专挑那些，藏在水面之下、维系着整个资金体系运转的关键节点，下手。

抽掉一根，看似无关紧要的梁，整栋看不见的大厦，便会因为失去支撑，而轰然坍塌一角。

短短半个多月，那位先生，便接连损失了数笔巨款。更要命的是，他赖以流转、洗白黑钱的那套精密系统，也被搅得七零八落，几近瘫痪。

他就像一个，被人扼住了血管的巨人。空有一身的力气，却只能眼睁睁地，看着自己的血，一点一点，流干。

云端之上，那位先生，第一次，慌了。

他眼睁睁地，看着自己经营了半辈子的财富帝国，像被白蚁蛀空的大堤，开始一处接一处地，决口。他动用所有的力量，去堵、去救，却发现，对方的每一刀，都精准地，捅在他最脆弱、最要害的地方。

这种感觉，让他遍体生寒。因为对方对他这套系统的了解，恐怕，不比他自己，少多少。

是谁？

到底是谁，能对他藏得这么深的家底，了如指掌？

一个可怕的念头，浮了上来——林敬之！

除了那个，替他打理了这么多年钱财的林敬之，没有任何人，能做到这一点！

可当他再想去联系林敬之时，却发现，那个人，早已如人间蒸发一般，再也找不到了。

那位先生，气得浑身发抖。他千防万防，没想到，自己最信任的钱袋子，竟然，被人撬了墙角、反咬了他一口。

更让他恐惧的，是这背后所折射出来的，那个对手的可怕。

能把林敬之这种，谨小慎微、又被自己牢牢捏住把柄的人，策反——这需要，何等的手段和魄力？

那位先生，第一次，对陈牧这个名字，生出了一丝，真正的忌惮。他意识到，自己面对的，绝不是一个普通的商场后辈，而是一个，心思缜密、出手狠辣，且对他，怀着刻骨仇恨的劲敌。

“你到底，是什么人……”那位先生，独自坐在昏暗的房间里，反复咀嚼着这个问题，一股，从未有过的寒意，爬上了他的后背。

而陈牧这边，对那位先生的窘境，一清二楚。

“慌了吧？”陈牧端着茶，唇角，噙着一抹冷笑，“他那点权势，是从哪儿来的？说到底，不就是一个‘钱’字，堆出来的吗？”

“他用钱，铺路、买人、织网。”陈牧一字一句，“我现在，就把他这座，钱堆起来的庙，一块砖、一块砖地，给他拆了。”

“等他没了钱，”陈牧的目光，冷峻，“他在那些‘更上面’的人眼里，还剩下几分分量？那些趋炎附势的墙头草，又会怎么对他？”

事实，正如陈牧所料。

随着那位先生，资金链频频告急、自顾不暇，那些原本，依附在他羽翼之下的人，也开始，嗅到了一丝，不寻常的气味。

有几个，与他来往密切的合作伙伴，最近，办起事来，开始变得，推三阻四、若即若离。墙倒众人推的苗头，已经，悄然显现。

那座一度，让整座城都为之忌惮的庞然大物，第一次，露出了，外强中干的疲态。

“我不急着要他的命。”陈牧淡淡道，“我要的，是让他，在这种众叛亲离、坐困愁城的滋味里，好好地，熬着。”

“前世，他就是这么一步步，把我逼上绝路的。”陈牧的声音，转冷，“这一世，我就原封不动地，还给他。”

“陈总，”沈泽有些不解，“咱们手里的证据，足够把那位先生，直接掀翻了。为何，还要这样，一点一点地，折磨他？”

“因为，掀翻他，太便宜他了。”陈牧的眼中，寒光一闪，“一刀捅死，他死前，未必能尝够，那种众叛亲离、大厦将倾的滋味。”

“我要的，”陈牧一字一句，“是让他，在这种绝望里，一寸一寸地，沉沦下去。让他，亲眼看着，自己用一辈子垒起来的东西，怎样在他眼前，土崩瓦解。”

“这份痛苦，”陈牧的声音，冷得渗人，“才配得上，他前世，欠我的那笔债。”

沈泽听得，背后一凉。他这才明白，陈总对那位先生的恨，究竟有多深。

夜色深沉，陈牧立在窗前，俯瞰着这座他已然掌控大半的城市。

这一场，攻守逆转的好戏，剧本里，从无记载。从他被那位先生反扑、到他绝地反击，把对方逼入绝境——这每一步，都是他这个‘局外人’，亲手搅动起来的风云。

那本曾让他料事如神的剧本，早已失效。可他却凭着自己，把这盘棋，下得越来越顺手。

因为他比谁都清楚，对付那位先生这样的对手，靠的不是什么先知先觉，而是这份，从尸山血海里熬出来的狠劲和耐心。

就在陈牧，稳稳占据上风，准备将这场‘抽血’，继续下去的时候——

徐先生的电话，又一次，打了过来。

只是这一次，电话那头的语气，不再有半分试探与威胁，反而，透着一股，反常的平静。

“陈总，”徐先生缓声道，“先生说，他低估你了。他想，正式跟你，见一面。”

陈牧端着茶杯的手，微微一顿。

那位先生藏了两世的真容，难道，要在这一刻，揭开了？

他放下茶杯，眼中，战意与寒意交织。

“好啊。”陈牧一字一句，“这位藏了我两世的先生，长着一副什么模样，我，也正想，亲眼看看。”

他望向窗外那片深沉的夜，声音冷得像冰。

“我要，跟他当面——做个了断。”
