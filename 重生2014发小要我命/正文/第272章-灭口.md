# 第 272 章 灭口

石楼外，浓雾里，杀机，四起。

那，藏在,雾里的,棋手，派来的,死士，比,陈牧，见过的,任何,一批，都，更,冷、更，狠。

他们，没有,喊杀，没有,叫阵。只，像，一群，从，地狱里，爬出来的,鬼影，无声无息地，从,四面八方，朝着,那座,石楼，绞杀，过来。

这，才是，那个，越过,先生的,棋手，豢养的,真正,死士。比,起,他们，先生，手底下,那些，都，成了，寻常之辈。他们，出手，没有，一丝，多余的,动作，招招，致命，杀人，就，像，割草。更，可怕的,是，那，一双双，蒙面之下的,眼睛里，没有，半点，情绪，像，一群，被，抽去了,魂魄的，杀人机器。

陈牧，一眼，就，看出——这些人，跟，先生，那批，死士，根本，不,是，一个，路数。它们，是，那，藏在,更深雾里的,东西，压箱底的,力量。

“护住,陈总!”傅野，嘶声,厉喝，带着,那，几个,精干的,弟兄，硬生生，在,楼门口，结成,一道，血墙。

“灭口的,来了。”陈牧，一步，跨出,石楼，眼底，寒光,四射，“它，果然，等,不及了。这批人,手,眼熟——是,冲,灭口,来的，不是,来,看戏的。”

“它，怕，什么？”傅野，一边，格挡，一边，嘶吼。

“它，怕，先生,那张,嘴。”陈牧，一字一句，“它，更，怕——先生，那张嘴里的,真相，落进，我，耳朵里。”

那，藏在,雾里的,东西，处心积虑，把,他，和,先生，关，进,这座岛，为的，是，让,他们，自相残杀。可，它，万万，没,料到——陈牧，非但，没,杀,先生，反倒，就，要，从,先生,嘴里，撬,出，那，最，要命的,真相。

于是，它，等,不及了。

它，宁可，撕破，脸，亲自，动手，也，绝，不能，让，那,真相，说出口。

“傅野!带,先生!往,码头,撤!”陈牧，一声,令下，“那,真相，我，非，从,他,嘴里，抠,出来,不可!”

“陈总!”傅野，一刀，逼退，一名,鬼影般的,死士，嘶声,喊道，“它，的,人，太多了!咱们,人手，本就,不多，再,拖，下去——”

“往,码头,冲!”陈牧，一字一句，“上,了,船，它，这些,死士，就，追,不上!”

“可,先生,这,老不死的——”傅野，恨声道，“咱们，为了,护,他，折了,多少,弟兄!”

“护,他，就,是，护,那,真相!”陈牧，厉声,喝道，“他,一死，我,两世的,谜，就，永远，断了!”

一场，惨烈的,突围，在,那座，孤岛的,浓雾里，轰然，展开。

陈牧,一行，护着,那个，苍老、佝偻的,先生，朝着，码头的,方向，且战，且退。

那些，死士，如,附骨之疽，一波，接,一波，扑,上来。他们，的,目标，明确，得,可怕——不是,陈牧，而是，被,陈牧，护在,当中的，先生。

它，要，先，灭，先生，这,张,嘴。

“陈牧!”奔逃间，先生，忽然，嘶声，开口，“你，护,老夫，是,为，那,真相。老夫，懂。”

“可,你，得，明白——”先生，喘着,气，“那位，今晚，不,把,老夫，灭口，绝，不,罢休。你，越,护,老夫，它，就，越，要，你，死。”

“那,又,如何?”陈牧,一掌，劈翻，一个,死士，厉声道，“你,嘴里的,真相，比,这满岛的,死士，金贵。”

“糊涂!”先生,惨然,道，“真相，是,死的;你,那条命，是,活的。为,老夫,一个,将死之人，搭上,你,自己——不值!”

“值不值，”陈牧，眼底,寒光四射，“我,自己，说,了,算!”

“它，要，先，杀，我。”先生，被,傅野，架着,狂奔，那，苍老的声音，喘,得,不成样子，却，透着,一股，惨然的,清醒，“陈牧，你，护，不住,老夫的。”

“少,废话!”陈牧,一掌，劈翻，一个,扑上来的,死士，厉声,喝道，“那,真相，你，还，没,说!”

“想,让，老夫，闭嘴，”先生，忽然，凄然，一笑，“除非，老夫，死。”

“那，就，别，死!”陈牧，嘶吼。

浓雾里，杀声,震天。牧达的,弟兄，一个，接，一个，倒下，又，一个，接，一个，用,血肉，替，陈牧，和,先生，硬,趟出，一条，血路。

眼看，码头，那盏,招魂的,灯，就，在,前方。

就，在，这时——

一支，冷箭，自,那，浓雾深处，无声，激射，而,出。

那一箭，又,快，又,准，绕过,重重,人影，直直，射向——先生的,咽喉。

“小心!”陈牧，眼角，余光，瞥见，那，一点，寒芒，几乎，是，本能地，一把，将,先生，往,身后，猛推。

可，那一箭，太,快了。

噗。

一声，闷响。

那一箭，还是，穿过,重重,阻隔，深深，钉进,了，先生的,胸口。

先生,那，佝偻的,身子，剧烈，一晃。

“先生!”

陈牧,一把，扶住，那，向后,倒去的，苍老身躯。

“先生!你,撑住!”陈牧,嘶吼，“那,真相，你,还,没,说!”

“撑,住？”先生，低头，望着，胸口，那，深入,骨血的,箭，那，浑浊的老眼里，掠过，一丝，了然，一丝，解脱，还有，一丝，连,他,自己，都，未,料到的，释然，“陈牧，你，还，不,明白吗？”

“这一箭，”他，喘着,气，一字一句，“就，是，冲，老夫，这，还，没，说，出口的,真相，来，的。”

“它，在，雾里，盯，着，咱们。”先生，惨然，一笑，“它，就，等，老夫，一开口——”

“果然……”他，喃喃，道，嘴角，溢出，一缕，鲜血，“老夫，到底，还是，没,能，活着，离,岛……”

“它，这一箭，”先生，望着,陈牧，那，苍老的脸上，竟，挣出，一个，古怪的,笑，“是,冲，老夫,那张嘴,来的。可，也，好……老夫，这，一辈子，替，它，做，尽了,脏事……临了，能，恶心，它，一回，也，值了……”

“先生!”陈牧,死死,扶住,他，“你,把,真相,说,出来!就,是,给,它，最,狠的,一巴掌!”

“来，不，及,了……”先生，嘴角，溢血，那声音，一点一点，弱下去，“可，老夫，偏，要，说……偏，要，让，它，白，费，力气……”

“陈牧,”他，死死，攥住,陈牧的,手腕，用，尽，最后，一丝，力气，一字一句，“真相……老夫，没,时间，说，全，了……”

“你，只，记住，一件事——”

“你，前世，不是，死于，一场，寻常的,谋杀……你，是，因为，你，是——”

那，最后，一个，词，先生，用，尽，了，全身,力气，才，从，牙缝里，挤,出，半个,音节。

可，就，在，那，半个，音节，即将，成,声的,刹那——

第二支，冷箭，破空，而至，狠狠，贯穿，了，先生的，咽喉。

那，最后，一个，字，连，同，先生，那，一肚子的,真相，永远，地，堵，在，了，他的，喉咙里。

先生，那，睁大的,眼里，最后，映着，陈牧,那，惊怒的,脸，一点一点，失去，了，光。

一代，翻云覆雨、藏了,几十年的,枭雄，就，这样，被，他，效忠了,一辈子的,主子，一箭，封,喉，灭,了，口。

连,那，最后，半个，字，都，没能，留下。

查无此人。

那，浓雾里，那，藏了,不知多少年的,棋手，用，最，冷酷的,方式，向，陈牧，宣告——

有些真相，它，宁可，杀,人，也，绝，不,会，让，你，知道。

陈牧，抱着，先生，那，一寸寸,冰冷的,身躯，跪，在,那,血泊里，久久，一动，不动。

那，缠了,他,两世的,谜底，明明，已经，到,了,嘴边，却，又，被，那，一箭，硬生生，夺,走。

“你，是，因为，你，是——”

先生，最后，那，半句话，像，一根，永远，拔,不,出的,刺，深深，扎，进，陈牧，胸口。

你，是，因为，你，是，什么？

是,那个，三十年前旧影的,转世？是，某个，先生，头顶,那位，忌惮,不已的人的,血脉？还是——某样，连,他,自己，都，一无所知的，惊天秘密？

陈牧，不,知道。

那,唯一，知道答案的人，此刻，正，倒，在,他,怀里，永远，闭上了,嘴。那,藏在,雾里的,棋手，用,两支,冷箭，把,那,通往,真相的,最后一扇门，彻底，焊死。

它，杀,先生，不是，因为，先生，背叛;是，因为，先生，即将，说出，那个，它，用，三十年，都，捂着的,秘密。为了，那个,秘密，它，连,自己，最，得力的,鹰犬，都，可以，毫不,犹豫地，抹掉。

这，才是，那，藏在，最深雾里的,东西，真正，令人，胆寒的,地方。

“陈总!”傅野，一刀，逼开，围上来的,死士，嘶声,狂吼，“先生,已经,没了!人,救,不活了!再,不走，咱们，都，得，交代,在,这儿!”

“弟兄们,拿命，替咱们,趟出的,这条,路，”傅野，红着,眼，“不能,白,费啊,陈总!”

这一声，才，把，陈牧，从,那，翻涌的,痛与,不甘里，硬生生，拽，了，回来。

是啊。他，不能，倒，在，这儿。他，身后，还，站着，牧达，满堂的,弟兄;他,肩上，还，扛着，两世的,血海深仇。他，若，死，在，这座岛，就，真，成，了，那，石碑上，第三十九座,坟。就，真，遂，了，那，藏在,雾里的,棋手的,愿。

先生死了，真相断了。可，那，通往,真相的,路，没，断。只要，他，活着，只要，他，手里,那把，凿山的,锤子，不,放下——他，就，能，凿到，那，藏在,最深雾里的,棋手,面前，亲手，把，那个，被,两支冷箭，堵回去的,真相，重新，撬,出来。

“陈总!”傅野,又，一声，狂吼，一把，将,他,拽起，“走啊!”

陈牧，最后,望了,一眼，先生，那，永远，闭上的,眼，一字一句，声音，冷得，像，地狱里，爬出来的,冰。

“走。”陈牧，一字一句，“把,先生，也，带,上。他，这条命，是,替,那,真相，丢的。我，不能，让,他，连,一具,尸首，都，留，在，这座，吃人的,岛上。”

他，霍然，起身，眼底，那簇火，燃烧，成，一片，择人而噬的，血红。

“今晚,这笔账，”陈牧，望向，那，浓雾，最深处，那，藏着,棋手的,方向。

“连，同,我,两世的,血债——我，陈牧，记，下,了。”
