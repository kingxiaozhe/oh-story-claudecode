# 第 215 章 两线开弓

远洋的反扑，来得比预想的还快。

顾行前脚刚走，牧达在欧洲的第二座海外仓——鹿特丹那处，就出了岔子。

“陈总，鹿特丹的地，又黄了。”沈泽神色凝重，“这一回，不是对方毁约。是当地几家有分量的公司，联手，把咱们能谈的地块，全给截了。咱们出多高的价，人家都不卖。”

“不止。”李锐也进来了，脸色发白，“安特卫普那座仓，本来运转得好好的。这两天，当地几家大物流商，忽然一起,不跟咱们合作了。货运的路子，被人,悄没声地，掐了一截。”

会议室里，一时静默。

这两记闷棍，一记截地，一记断运，招招都打在牧达出海的七寸上。

这一次，远洋没有藏着掖着。它在告诉陈牧——这片海，是它的地盘。它在欧洲盘踞了几十年，那些当地的银行、物流、地产，官面上的、商界里的关系，早被它织成了一张密不透风的网。牧达一个初来乍到的东方新客，在这张网面前，处处受制，寸步难行。它甚至不必亲自出面，只需动一动那些盘根错节的老关系，就能让牧达的出海之路，步步碰壁。

这，才是远洋真正的主场。国内那点残局，不过是它随手就能舍弃的边角；可这片经营了几十年的深海，才是它，真正的巢穴。

“它这是,想让咱们知道，”陈牧缓声道，“在海那头，谁,才是主人。”

“陈总，”李锐忧心忡忡，“远洋在欧洲的根基，太深了。咱们在那边，人生地不熟，硬拼,拼不过它。要不……出海这一步，先缓一缓？”

“缓？”陈牧却摇了摇头，眼底寒光四射，“越是这时候，越不能退。”

“咱们一退，就等于告诉它——牧达,在海那头，怕它。”陈牧一字一句，“它就会得寸进尺，把咱们出海的路，彻底,堵死。”

“出海这条路，是牧达的未来。”陈牧道，“不是我一时意气，非要跟它争这口气。是这条路，早晚要走，绕不过去。今天我怕它，退了一步，明天，它就能把我，逼退一百步。”

“更何况，”陈牧眼底寒光四射，“它把战场挪到海那头，以为是把我引进了它的深水。可它忘了——想够到它这尊大佛、够到它头顶那个‘上头’，我，本就得，亲自，下到这片海里来。”

“它这是，自己，把门，给我推开了。”

“可硬拼……”

“谁说,要硬拼了。”

陈牧站起身，走到那面世界地图前，目光落在遥远的欧洲。

“远洋在欧洲的根基深，明面上,咱们撼不动。”他一字一句，“可它有一样东西，是它最大的软肋——它藏在海外的,那些黑钱。”

众人一愣。

“周敬堂那份U盘，”陈牧缓声道，“记的不只是国内的账。海外那些黑钱怎么流、藏在哪几个窟窿里，也有迹可循。”

“它在欧洲的势力再大,那些钱,也见不得光。”陈牧的嘴角，勾起一抹冷冽的弧度，“它能在明面上,掐咱们的物流、断咱们的地。那我,就在暗地里，顺着这些钱，去捅它,最不敢让人碰的地方。”

这就是陈牧的算盘。

跟远洋在欧洲的明面上拼关系、拼根基，牧达十年都拼不过。可再深的根基，也怕暗处的一把刀。远洋的势力，建在什么上头？建在那些从国内、从各地洗过去的、见不得光的黑钱上。这些钱，是它的血。

顺着这些血，摸到它的心脏——这条路，别人走不了。可牧达有周敬堂那份账，有林敬之这个,最懂钱怎么流的人。这，恰恰是远洋，做梦都想不到的一记回马枪。

“林敬之。”陈牧看向他。

“在。”林敬之上前一步，眼睛发亮。这个搭过整套洗钱系统的人，一提到‘钱的路数’，浑身都来了劲。

“你带一队人,即刻动身,去欧洲。”陈牧一字一句，“顺着U盘里那几笔,流向海外的黑钱，给我,一寸一寸，往深里摸。我要知道，远洋的钱，最后,到底,进了谁的口袋、藏进了哪一口井。”

“它在明处打咱们，”陈牧道，“咱们，就在暗处，捅它。”

“它掐咱们的仓，咱们,就断它的钱。”

“这叫,两线开弓。”

“这一趟，凶险。”陈牧看着林敬之，一字一句，“远洋的老巢，不在国内。你到了那边，就是真正的孤军深入。查到什么，第一时间传回来；一旦觉出不对，立刻撤——命，比什么都金贵。”

“陈总放心。”林敬之郑重道，“钱藏在哪儿，我这双眼，认得。就算它埋到海底，我也替您，给它挖出来。”

一番话，把众人因远洋反扑而生的那点憷意，一扫而空。

是啊。跟着这位陈总，什么时候,吃过纯粹挨打的亏？他总能,在别人以为的绝境里，找出一条，反将对方一军的路。

前世的陈牧，遇上远洋这样的庞然大物，只会,被打得节节败退，最后连还手的地方都找不着。可这一世,不一样了。他不再是那条,只能任人宰割的鱼。剧本早废了，可他这两世练出的这双眼，总能一眼看穿——再强大的对手，也总有一处,见不得光的死穴。

“至于欧洲明面上的困局，”陈牧转向李锐，“也不必慌。远洋能拉拢当地的公司,咱们,就出更好的条件,去挖它的墙角。它在欧洲经营几十年,得罪的人,不会少。凡是被它压过、恨过它的,都是咱们能借的力。”

一个庞然大物，在一片地界上盘踞得越久，踩过的人、结下的仇，就越多。远洋在欧洲几十年，风光的背后，不知埋着多少，敢怒不敢言的旧账。这些人，平日里，是它的手下败将；可一旦有人肯挑头，跟它作对，他们，就会一个个，从暗处冒出来。

陈牧要做的，就是，做那个挑头的人。

“钱老板那边，”陈牧道，“让他动用他在欧洲的门路，先稳住现有的货运。仓,一座都不许停。”

“我倒要看看，”陈牧望着地图上那片深蓝的海，眼底一片锐利，“是它这几十年的老关系硬，还是我陈牧这把,专捅软肋的刀,快。”

众人轰然领命。

一场跨越重洋的暗战，就此拉开。国内、海外，两条战线，同时点燃。

这是陈牧两世以来，走得最远的一步。从怀塘那口枯井，到这座城，再到如今这片他从未涉足过的深海。他要面对的，不再是程立秋、韦振邦这些看得见、摸得着的对手，而是一个藏在几十年经营、藏在重重壳子与关系网背后的庞然大物。

可他没有半分退缩。那个把他两世都吞没的黑影，既然就在海那头，那他，就一定要亲自游过去，把它，从水底，一把拽出来。

而陈牧不知道的是，就在林敬之的人，动身奔赴欧洲的同时，海那头，远洋那间隔着一层雾的房间里，那个苍老的声音，也听完了关于陈牧的最新汇报。

“他要顺着钱，查到海外来。”那声音听不出喜怒，沉默了片刻。

“有点意思。”

“是该，让他，见一见真正的深水了。”那声音缓声道，“告诉那边——把‘那个人’，请出来。”

电话那头，侍立的人,身子一震。

“先生，”他声音发紧，“动用……那位？会不会,太早了？”

能让侍立在先生身边、什么大风大浪都见过的人，都变了脸色的‘那位’——绝不是等闲之辈。

在远洋这台庞大的机器里，顾行、徐先生，乃至已经倒下的韦振邦，都只是摆在明面上的棋子。而‘那位’，是远洋压箱底、轻易不动用的一张牌。一张，只在真正棘手的对手面前，才肯亮出来的牌。

“陈牧这把刀，”那苍老的声音里，掠过一丝极淡的、耐人寻味的意味，“磨得，比我想的，还要快。”

“他既然想到海那头来，”那声音缓声道，“那就，让那位，好好，招待招待他。”

“今晚，就请那位，动身。”

那侍立的人，不敢再多问，躬身，领了命。

他清楚，先生这句轻描淡写的‘招待’背后，藏着的，是何等的腥风血雨。陈牧那个在国内搅得天翻地覆的年轻人，怕是还不知道——自己即将在那片陌生的深海里，撞上一个，怎样的对手——一个，被远洋压了几十年箱底、专为收拾硬骨头而豢养着的对手。
