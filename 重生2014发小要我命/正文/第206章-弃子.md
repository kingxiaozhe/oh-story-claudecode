# 第 206 章 弃子

远洋的反应，比陈牧预料的，还要快，还要狠。

周敬堂动摇的消息，越过重洋，递进那间隔着一层雾的房间，只用了一夜。

而那位从不露面的先生做出的决断，只有冷冰冰的四个字——弃了这子。

在远洋看来，这个决断，没什么可犹豫的。周敬堂再有用，也只是一件工具。一件已经动摇、随时可能反水的工具，留着，就是隐患。既然陈牧咬着华瑞不肯松口，那便顺水推舟，把华瑞和周敬堂，一并舍了——舍一个白手套，断陈牧一条线索，还能借周敬堂这颗人头，警告所有替远洋做事的人：动摇者，死。

这笔账，那位藏在雾里的先生，算得又快，又冷。

第二天一早，周敬堂就尝到了，被主子抛弃的滋味。

头一记闷棍，砸在华瑞身上。前一天还火急火燎往华瑞窟窿里填的那笔救命钱，一夜之间，被人从半道上，硬生生抽了回去。

那根本就快接上的资金链，第二次绷断。这一回，比第一次断得更彻底。华瑞的股价，直接砸穿了地板，跌成了一堆没人敢碰的烂纸。

短短一天，这家远洋在国内的硬钉子，就彻底废了。可远洋连眼皮都没眨一下——在它眼里，华瑞也好，周敬堂也好，都不过是随时可以割掉的一块肉。壮士断腕，它断得干脆利落，连一丝犹豫都欠奉。

周敬堂慌了。

他一连打了十几个电话，往那条平日联络远洋的暗线上打。可那条线，像是凭空消失了一样，再没人接。

紧接着，第二记棍子，落了下来。

一个陌生的面孔，出现在了泓通。那人拿着远洋的授意，客客气气，却不容置疑地，接管了泓通与远洋之间，所有的资金往来和联络渠道。

“这是什么意思？”周敬堂盯着那张陌生的脸，声音发沉，“泓通和远洋这条线，我经营了二十年。”

“周老板，”那人皮笑肉不笑，“上头的意思，您歇一歇。华瑞这摊子烂事，您先料理干净。至于旁的，往后，不劳您费心了。”

“上头？”周敬堂只觉一股凉气，直往心口窜，“我要跟先生，亲自通话。”

“先生很忙。”那人淡淡道，起身理了理衣角，“周老板，好自为之。”

撂下这四个字，那人便扬长而去，留下周敬堂一个人，站在空荡荡的办公室里，浑身发冷。

那一声“好自为之”，分量，他掂得出来。这四个字，远洋不知对多少个失去价值的人，说过。而说完之后，那些人，就再没在这世上，出现过。

一夜之间，周敬堂替远洋经营了二十年的那条线，被人不声不响地，从他手里，剥了个干净。

他成了一个，被架空的空壳。

到这一步，周敬堂就算再迟钝，也彻底明白了。

远洋这是,不要他了。

华瑞保不住，那就干脆连华瑞带他，一起扔掉。而他这个知道太多秘密的弃子，接下来的下场——

周敬堂想到胡彪，想到那些替先生、替远洋卖过命，最后不明不白就消失了的人。一股寒意，顺着他的脊梁骨，直冲天灵盖。

陈牧那晚的话，一字一句，在他耳边炸响。

“等它先动了手，你，就再没得选了。”

竟全被那个年轻人，说中了。

一模一样。分毫不差。

事到如今，退路已断。

留在原地，是死。远洋绝不会容一个知道它太多秘密、又已生二心的弃子，活着。摆在他面前的，只剩一条路——那条陈牧那晚，亲手替他留下的路。

一个在商海里沉浮了大半辈子、算计过无数人的老狐狸，此刻，攥着手机的手，竟微微发抖。他清楚，接下来拨出去的这个号码，是他这辈子，下的最大的一注。赌赢了，还有一线生机；赌输了，死无葬身之地。

可他，已经没有第二条路可选。

……

牧达这头，陈牧几乎是同步，收到了消息。

“陈总，神了。”沈泽快步进来，语气里满是叹服，“远洋撤了华瑞的救命钱，还派人接管了泓通的联络线。周敬堂,被架空了。”

“跟您那晚说的，一模一样。”

“不止这些吧。”陈牧却没回头。

“陈总英明。”沈泽苦笑，“远洋还往泓通塞了个人，把周敬堂对外的联络，全接管了。这位周老板,如今在自己的公司里,连个电话都打不出去。”

“它这是,要断周敬堂的后路。”陈牧道，“先架空，再……”

后半句，他没说下去。可屋里两个人，都听懂了那没出口的杀机。

陈牧站在窗前，望着远处，唇角勾起一抹淡淡的弧度。

“不是我神。”他缓声道，“是远洋这种庞然大物，做事的路数，从来都一样。”

“对它来说，人不是人，是棋子。”陈牧一字一句，“棋子好用，就用；不好用了，就弃。周敬堂替它卖了二十年命，在它眼里，也不过是一枚,随时可以丢掉的子。”

前世的他，就是这样一枚被丢掉的棋子。

他曾把身家性命、把一腔真心，全押给了那些高高在上的人。他以为，只要自己足够有用、足够忠诚，就能换来一席之地。可到头来，他不过是别人棋盘上，一枚用完就扔的子。被人榨干最后一点价值，然后一脚踢开，任他自生自灭。

那本料事如神的剧本，算得出输赢，算不出人心的凉薄。它没能救得了前世的他。

可这两世的教训，早把这个道理，刻进了他的骨头里——在这些人眼里，从来没有情义，只有利用。

那本料事如神的剧本，写满了输赢起落，唯独没写一个字的人心。它救不了前世那个天真的陈牧，也算不出，一个走投无路之人，能爆发出多大的力量。

可这两世的血泪，替他补上了剧本最欠缺的那一课。他比谁都懂——绝境，能逼着最精于算计的人，做出最决绝的选择。周敬堂被逼到墙角，那点二十年的城府，反倒会碎得最快。

正因如此，他比谁都清楚，此刻的周敬堂，是何等的绝望，又是何等的,好用。

“一个被主子弃掉的人，”陈牧转过身，眼底寒光四射，“心底那点最后的忠，也就断干净了。这种时候的周敬堂，才是最好的一把刀。”

“他现在，是走投无路。”陈牧道，“远洋要杀他灭口，牧达这边，是他唯一能抓的一根稻草。”

“沈泽，”他吩咐道，“派人,盯紧周敬堂的安全。远洋既然弃了他，就绝不会让他，活着落到我手里。得赶在远洋动手之前，把这个人，稳稳地接过来。”

“当年藏胡彪那处安全宅子，重新启用。”陈牧道，“多派人手，明的暗的都要有。周敬堂一旦点头，第一时间，把人，连同他手里的东西，一起接到那儿去。”

“远洋的人既然盯上了他，这一趟接头，必然凶险。”陈牧眼神一沉，“宁可多费些周折，也绝不能让他，在半道上出事。他这条命，如今比金子还金贵——他脑子里装的，是我够到远洋的，唯一一把钥匙。”

“周敬堂在远洋身边二十年，”陈牧一字一句，“远洋在国内的钱怎么走、人怎么用、那只藏在云里的手，究竟从哪儿伸下来——这些，他知道的，比谁都多。把他接过来，我跟远洋这盘棋，攻守，才算真正倒了过来。”

“明白。”沈泽神情一凛，“我亲自带人去。”

“记住，”陈牧叫住他，“时间，就是周敬堂的命。远洋要动手，只会比咱们想的，更快。”

沈泽重重点头，转身大步而去。

沈泽走后，陈牧独自立在窗前。

这一步棋，走到今天，凶险与转机，只在一线之间。周敬堂若能平安接过来，他就等于从远洋身上，撬下了最要紧的一块。可只要慢上一步，让远洋抢了先手，这条好不容易露头的线，就会连人带秘密，一起埋进土里。

成败，只看这一两天了。

像是要印证他的念头，陈牧桌上的电话，急促地响了起来。

老吴在外头接了，脸色一变，快步进来。

“陈总，”他压低声音，“周敬堂,亲自打来的。他说……他愿意谈。”

“他还说，”老吴顿了顿，声音里带着几分凝重，“远洋的人，已经盯上他了。他,活不过今晚。”
