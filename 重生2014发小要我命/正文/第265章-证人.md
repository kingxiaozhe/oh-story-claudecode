# 第 265 章 证人

那家养老院，在城郊，偏得,不能再偏。

破败的,小楼，掩在,一片，荒草里。这样的地方，正合,用来，藏，一个，被人，遗忘的,活死人。

一路上，傅野，几次，欲言又止。他，怕，这一趟，扑空;更，怕，这，看似，无人看守的,养老院，底下，藏着，先生，另一道，杀机。可陈牧，却，异常，笃定。

“先生，若，真，还，盯着,这个人，”临进门，陈牧，缓声道，“就，不会，把他，弃在，这样，一个，破地方。他，把他，弃得，越,不像样，越，说明，他，早，把这个人，当成，一个，死人了。”

“而一个，被当成，死人的,活人，”陈牧，眼底，寒光四射，“往往，最，敢，说，真话。”

事实，果然，如他,所料。这养老院，冷清，得,像，一座，坟。没有，暗哨，没有，杀机，只有，一个，被，全世界，遗忘的,老人，在，等死。

陈牧,见到那个老人时，他，正,一个人，坐在,窗前，望着，窗外，那片，灰蒙蒙的,天。

他，很老了。老得，像，一段，风干的,枯木。可他，那双，浑浊的,眼里，偶尔，掠过的,一丝,精光，却，让陈牧，断定——这个人，脑子，清楚，得,很。

“您，好。”陈牧，在他，对面，坐下，语气，放得，极缓，“晚辈，姓陈。”

那老人，转过头，浑浊的,眼，在,陈牧，脸上，停了,一瞬。

然后，他，笑了。那笑，苍老，而，古怪。

“姓陈……”他，喃喃道，那声音，像，砂纸，磨过，“又，一个，姓陈的。”

陈牧的,眼底，寒光，一闪。

又一个。

这三个字，像,一记,重锤，砸在，他，胸口。

“老先生,这话，”他，压着,声，一字一句，“是,什么，意思？”

那老人，却，不答，只，望着,他，那，苍老的脸上，翻涌着，一种，说不清的,神色。

“三十年了。”良久，他，缓声道，“老夫，还，当，这辈子，再，见不着，第二个，敢，凿那座山的人了。”

“你，来,找,老夫，”他，浑浊的眼，直直，望进，陈牧,眼底，“是，想,问，三十年前，那个人，对不对？”

陈牧，迎着,那目光，重重，点头。

“他，是,谁？”陈牧，一字一句，“他，和,先生，究竟，是，什么,关系？”

那老人，望着,窗外，那片，灰蒙蒙的,天，浑浊的眼里，翻涌起，一段，尘封了,三十年的,旧梦。

“三十年前，”他，一字一顿，声音，飘忽，“先生，还，不叫,先生。那时候，他，和,那个人，是，一块儿，从,泥里，滚出来的，兄弟。”

“兄弟？”陈牧，心底，一凛。

“比,亲兄弟，还，亲。”老人，缓声道，“他们，一个，有,惊天动地的,手腕，一个，有，算无遗策的,城府。两个人，联手，才，一手，一脚，垒起了，这座,冰山，最初的,根基。”

“那时候,的,他们，”老人，那浑浊的眼里，掠过，一丝，追忆，“意气风发，睥睨天下，以为，这世上，再，没有，他们，兄弟俩，做不成的事。”

“可后来呢？”陈牧，追问。

“后来……”老人的,声音，一下子，冷了下去，“这座山，越垒，越高。高，到，容不下，两个，山主人。”

“那个人，想，把这座山，用在，正道上;先生，却，想，用它，掌控，一切。”老人，一字一句，“道，不同。不相为谋。”

“于是，先生，就，把，那个，和他，出生入死的,兄弟——”老人，浑身，猛地，一颤，那，翻涌的,追忆，霎时，化作,满脸的,惊惧。

一提，先生，那双，浑浊的老眼里，霎时，翻起，一片，三十年，都，没散尽的，惊惧。

“不能说……”他，喃喃道，枯瘦的手，死死，攥住,椅子的,扶手，“那两个字，不能，提……”

“提了，他，就，能，听见……他，无处，不在……”

陈牧，望着,那，惊惧,失态的,老人，那颗心，一点一点，沉了下去。

原来,如此。

三十年前，那个，独凿冰山的,旧影，不是，什么，凭空,冒出来的,对手。他，是，先生，曾经，最亲的,兄弟，是，这座冰山，最初的，另一位，缔造者。

后来，兄弟，反目。那个人，想，收手;先生，却，要，独吞。于是，先生，亲手，把，那个，与他，一同,打天下的，兄弟，抹成了，一句，查无此人。

难怪，先生，看着,陈牧，会，一次次，恍惚。难怪，他，会说，那个人，是，他，这辈子，唯一，看得上的,对手。

因为，那个人，从来，就，不是，寻常的,对手。他，是，先生，亲手，杀死的，另一个，自己。

三十年了。这个，被弃在，天涯海角的老人，提起,先生，竟，还，怕，成,这样。

那座冰山，那个先生，究竟，是，用，什么，把一个人，吓成,这般，模样？

“老先生，”陈牧，缓声道，语气，放得，更软，“他，听不见。您，被，弃在,这里，三十年，他，早，把您，忘了。”

“忘了？”那老人，忽然，凄然，一笑，“他，从不,忘，任何人。他，只是，懒得，动，你。”

“他，让，你，活着，”老人，一字一句，那声音里，是，一种，深入骨髓的,恐惧，“比，杀了你，还，诛心。”

“他，要，你，眼睁睁，看着，自己，被，全世界，忘掉。看着，自己，活成，一个，查无此人。”

陈牧,静静，听着，那颗心，一寸一寸，往下沉。

这，才是，那座冰山，最，可怕的地方。它，杀人，从不，只，取，性命。它，要，先，抽掉，你的,脊梁，再，抹去，你的,痕迹，最后，让,你，在，无边的,遗忘里，一点一点，烂掉。

肉体的,死，是,一了百了;可这种，被，从,天地间，彻底，抹去的,死，才，是，真正的，万劫不复。

眼前，这个，被弃了,三十年的老人，就，是，那，最，鲜活的，一具，人证。他，还，活着，可他，早，被，那座冰山，判了，一个，比死，更，惨的，刑。

查无此人。

又是，这，四个字。

陈牧，深吸，一口气，压下,那，翻涌的,一切。

“老先生，”他，一字一句，声音，沉，而，稳，“那个人，那段，旧事，晚辈，非，知道，不可。”

“因为，晚辈，如今，走的，就，是，那个人，走过的，路。晚辈，不想，也，成，那，第二个，查无此人。”

那老人，怔怔地，望着,他，望了，很久，很久。

那双，浑浊的老眼里，那片，惊惧，一点一点，褪去，取而代之的，是，一种，见了,同类的，悲悯。

“孩子，”良久，他，缓声道，那声音，苍老，而，颤抖，“你，和他，长得，不像。”

“可你，这股，明知,山有虎、偏向,虎山行的,劲儿——”

“像，得，让,老夫，害怕。”

“老先生，”陈牧，一字一句，“那个人，最后，是,怎么，输的？他，都，走到，能，跟先生，掰手腕的,地步了，怎么，会，输得，一无所有？”

那老人，长长，叹了口气，那叹息里，是，三十年，都，化不开的，苍凉。

“他，不是，输在，手腕上。”老人，缓声道，“他，是，输在，一个,‘信’字上。”

“他，太，信，那些，跟他，一起,打天下的,兄弟了。”老人，一字一顿，“他，以为，那些人，会，跟他，一条心。可先生，却，一个，一个，把他们，买了过去。”

“到，最后，那个人，才，发现——他，身边，最亲的人，全，成了，先生，插进,他,心口的，刀。”

陈牧,握着,茶盏的,手，猛地，一紧。

这话，怎么，如此，耳熟？

前世的,他，不,也，是，这样，死的？他，也，曾，把，那个，要他命的,发小，当成，最亲的人。他，也，是，到，家破人亡，才，发现——那把，捅进,他,心口的,刀，来自，他，最，信任的，掌心。

一股，寒意，顺着,陈牧的,脊梁，一寸一寸，爬了上来。

三十年前，那个人;前世，那个,他。两个，隔着,岁月的,人，竟，栽在，一个，一模一样的,坑里——被，最亲近的人，背叛,致死。

这，仅仅，是，巧合，吗？

还是……那座冰山，那个先生，那，杀人于,无形的，攻心之术，从，三十年前，到，他的,前世，一脉，相承，从，未，变过？

他，枯瘦的手，抬起来，虚虚，指了指，陈牧，又，指了指，那，遥远的，海的，方向。

“那段,旧事，老夫，可以，告诉,你。”他，一字一顿，“可老夫，得，先，问,你，一句。”

“你，可，知道，”那老人，浑浊的眼底，寒光，一闪，一字一句。

“先生，头顶，那片，比,他，还,深的，天——”

“是,谁？”

这一问，让,陈牧，那颗心，猛地，一沉。

他，凿了两世的山，一直，以为，先生，就，是，那，最后的,顶点。可这个，见过,先生，早年的,老人，却，一开口，就，问，先生，头顶，那片，更深的,天。

“先生……头顶,还,有,人？”陈牧，压着，声，一字一句。

“傻孩子。”那老人，凄然，一笑，“你，当，先生，那样，翻云覆雨的人，为什么，几十年，都，躲在，那座塔上，连,脸，都，不敢，露？”

“他，不是，在，躲，你们，这些，凿山的人。”老人，一字一顿，那，浑浊的眼里，翻涌起，一片，深不见底的,惧意。

“他，是，在，躲，他，头顶，那片，天。”

这句话，像,一道，惊雷，在,陈牧,胸中，炸开。

原来，那个，藏在,暗影里、连,老槐,都,未曾,见过一面的，先生，竟，也，是，一个，躲在，更深的,雾里、瑟瑟发抖的，惊弓之鸟。

“那片,天，”陈牧，一字一句，声音，压得，极沉，“究竟，是,什么？”

那老人，却，忽然，剧烈地，咳嗽起来，那，浑浊的眼里，惧意，翻涌，枯瘦的手，胡乱，摆着。

“不能,再,说了……”他，喘着气，嘶声道，“说,多了……要,遭,天谴的……”

“你，自己，去,凿。”老人，最后，望了,陈牧,一眼，那眼神里，是，一种，托付，也是，一种，警示，“凿到，那片，天,底下，你，就，知道了。”

“只是,那时候，”老人，一字一顿，一字，冷得，像冰。

“你，还，敢不敢，睁开,眼，看,清楚——就，难说了。”
