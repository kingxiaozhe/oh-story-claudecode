# 第 138 章 活人，得过活人的日子

程立秋的案子，一旦掀开，就再也，盖不回去了。

接下来的些日子，城里天天有新动静。当年那块地、那两条人命的旧案，正式重新立了案。程立秋这些年，靠着权势压下去的一桩桩旧账，被一件件，翻了出来。

那座山，是真的，塌干净了。

这座城，像是大病初愈。压在头顶二十多年的那片无形的阴云，散了。街头巷尾，人们议论的，都是程立秋的事。从前，这个名字，没人敢大声提；如今，它成了茶余饭后，最解气的谈资。

有老人抹着泪说，这是报应；有年轻人听着长辈讲当年的旧事，第一次知道，自己脚下这片，看似太平的土地，底下，曾经埋着，怎样的血和冤。

可对陈牧来说，山塌了之后，还有一件事，比看着程立秋伏法，更要紧。

那就是——那些被程立秋压了二十多年的活人，从今往后，得过上，活人的日子。

他先去看了，郑维德。

老人，已经从邻县那个藏身的村子，搬了出来。这一回，他没有再躲。

陈牧见到他的时候，他正坐在一处新租的、阳光很好的小院里，晒太阳。

“老人家，气色，好多了。”陈牧说。

“睡得着了。”郑维德眯着眼，笑了，那张枯槁了二十多年的脸上，头一回有了点活人的血色，“二十多年，我头一回，敢睡个囫囵觉。头一回听见有人敲门，不哆嗦。”

“这二十多年，”他望着院里的阳光，“我不是在活。我是在躲。今天，我才算，真正活过来了。”

陈牧没多说。有些话，说出来，反倒轻了。

他只是临走前，留下一句：“您后半辈子，安心。该您过的日子，一天，都不会少。”

他又去看了钱进。

钱进，已经从外地回来了。这一回，他不用再装病，不用再东躲西藏。

“陈先生。”老人见到他，挣扎着要起身。

“您坐。”陈牧按住他。

“这些天，”钱进的眼眶，红红的，“我天天往那块地跑。当年，苏婉清的地，让我盖了那个假章——这二十多年，我夜里一闭眼，就是她。”

“现在，案子重查了。”他说，“她的冤屈，要平反了。我这块，压了二十多年的石头，总算落了地。”

“我这后半辈子，”老人惨然一笑，“本来以为，要背着这个亏心事，进棺材。是你，让我把它，吐了出来。我，死也能，闭眼了。”

“别说死。”陈牧说，“您这条命，往后得好好活。您作的证，救的，不只是您自己——是二十多年前，那个屈死的人的，公道。”

接着，是周慧明。

那间城南的修车铺，还开着。可周慧明，整个人都不一样了。那条佝偻了二十年的脊梁，挺直了。

“我姐姐的案子，重新查了。”他见到陈牧，眼睛有点红，“今天有人来，跟我说，当年的卷宗，要重新做。我姐姐，她……她不再是‘失足落水’了。”

“她等了二十年，”周慧明的声音，哽住了，“终于等到，有人肯承认——她，是被害的。”

他忽然对着陈牧，深深鞠了一躬。

“我知道，这一切，是您做的。”他说，“我不问您是谁，为什么帮我。我只想跟您，说一句——”

“谢谢您。替我姐姐。”

陈牧扶起他。

“不用谢我。”陈牧说，“是你姐姐自己，二十年前就种下了因。她不肯低头、不肯签字，一级一级地去告——她把真相，护到了最后。我，只是替她，把这个真相，送到了今天。”

“她是个了不起的姑娘。”陈牧说，“你该为她，骄傲。”

周慧明重重地点头，泪，落了下来。

走出修车铺，陈牧回头看了一眼。

那本残缺的剧本里，从来没有周慧雪，没有周慧明，没有郑维德。可正是这些被剧本遗忘的小人物——他们的公道，他们的活路，才是陈牧这一世，真正想挣回来的东西。

结局，他早就知道。可结局里，这些人的脸，是他这一世，一个一个，亲手照亮的。

还有一个人，陈牧没忘。

田守业。

程立秋一倒，田守业这个程立秋的白手套，第一时间就被卷了进去。调查组顺着程立秋的账，很快就查到了他头上。

可田守业这个人，到底滑头。他这一年，被陈牧一步步逼着、又自以为聪明地脚踏两船——竟歪打正着，给自己留了一条活路。

那笔他私吞的、又被陈牧点透是程立秋把柄的保命钱；那些他在关键时刻、半推半就递出去的、对程立秋不利的东西——到了清算的时候，竟成了他主动配合、戴罪立功的筹码。

田守业，给陈牧打过一个电话。

“陈先生，”他的声音里，有劫后余生的虚弱，也有一丝说不清的怨，“您早就算到了今天，是不是。从您第一次找上我那天起，我就是您棋盘上的，一颗子。”

陈牧没有否认。

“田总，”他说，“我没害你。你今天能留下这条活路，是因为你自己，在最关键的时候，做了对的选择——你没跟程立秋，一条道走到黑。”

“可那是因为，您逼的。”

“我只是给你指了条路。”陈牧说，“走不走，是你自己迈的腿。程立秋塌了，多少人陪着他一起埋了。你没埋——田总，这已经是你这一年，提心吊胆换来的，最好的结果了。”

电话那头，沉默了很久。

“我认了。”田守业最后说，“这盘棋，我，输得不冤。”

田守业保住了一条命，可他在这座城里，那点呼风唤雨的本钱，连同他巴结的那座靠山，一起，没了。

一个靠给人当白手套过活的人，靠山倒了，他也就废了。

这，大概就是这种人，最体面的下场。

陈牧对田守业，谈不上恨，也谈不上惜。

田守业这种人，趋利避害，墙头草。当年程立秋势大，他就死心塌地，给程立秋当狗；后来风向变了，他又顺着势，给自己留后路。这种人，成不了大事，可也死不绝。

“他这种人，”陈牧后来对手下说，“你指望他讲忠义，是痴人说梦。可你只要摸透了他趋利避害的本性，就能牵着他走。”

“这一年，我没真信过他一回。”陈牧说，“可也正是因为我没信他，他才在我布的局里，一步不差，走到了今天。”

“用人如用器。”陈牧说，“知道它是什么料，就知道，该怎么使。”

而那块地——当年那场血案的源头——苏婉清那块，被假手续夺走的地，也在这场清算里，被翻了出来。

二十多年了。那个叫苏婉清的女人，那个连过户那天都不在本地，就平白丢了地、丢了命的女人——她的冤屈，终于被人，重新提起。

陈牧站在办公室的窗前，望着这座，正一天天恢复着往日平静的城。

一年多了。

从他握住那第一颗子起，到今天，程立秋这座压了无数人二十多年的山轰然倒塌——他走的每一步，都如履薄冰。

这一仗，他赢了。

赢得，不轻松。

这一年多，他栽过跟头——郑维德跑过一次，钱进差点被灭口；他腹背受敌过——程立秋和邬庆山两座火山，曾一起压向他；他也险些，满盘皆输过。

支撑他走过来的，不是那本他带回来的、缺了页的剧本。

是恨。

是前世，那个被人一步一步逼到绝路、临死时，连一个替他说话的人都没有的——自己。

那笔账，他记了，整整一世。

可陈牧知道，他真正要算的那笔账，还没算。

程立秋，是二十多年前那桩旧案的主谋。可把陈牧前世逼上绝路、吞掉他一切的，是另一个人。

邬庆山。

程立秋塌下来激起的尘土，已经埋了邬庆山半截身子。宏远被调查，邬庆山焦头烂额。

可这，远远不够。

陈牧要的，是亲手，把邬庆山前世从他身上夺走的一切——连本带利，拿回来。

他拿起电话，拨给手下。

“宏远那边，查得怎么样了。”

“查到了不少。”手下说，“邬庆山现在自顾不暇。陈总，您打算，什么时候动手？”

陈牧望着窗外，那片初夏的天。

“不急。”他沉声道，“他前世怎么一步一步把我逼死的——这一世，我就怎么一步一步，奉还。”

“这一回，”陈牧的眼神，冷得像冰，“我要他，叫天天不应，叫地地不灵——连一条退路，都没有。”

窗外，初夏的阳光，正好。

可对邬庆山而言，一场比程立秋更无路可逃的清算，才，刚刚，开始。
