# 声口库

赛道声口模板库。**每个条目 = 一本人类母本拆出的、可执行的声口指纹**，供开新书时按赛道选用。

配套引擎：`skills/story-long-write/references/voice-loop.md`（段落级声口优化循环）——引擎通用，永远只读 `{书}/设定/声口.md`；本库负责在开书时提供那份文件的来源。

---

## 目录结构

```
声口库/
  README.md                      ← 本文件
  _模板.md                       ← 空白指纹模板，拆新母本时照着填
  通用内核_三九音域我不是戏神.md   ← 跨赛道内核（第一个条目，可作任何赛道条目的基底）
  都市重生复仇.md                 ← （待建：等同赛道母本到位后拆）
  ...                            ← 按需添加，一个赛道一个条目
```

## 来源仪式：推荐 → 选定 → 炼制 → 绑定（新书/旧书均强制，v0.2.5）

> 这是"声口文件从哪来"的**权威流程**。spec-generation、N3 硬闸、voice-loop、workflow-daily 提到声口来源时，一律指到本节。
> **触发时机**：新书=整本书主题（频道/赛道/题材）定下来之后、写任何正文之前；旧书（存量书接管/续写）=继续写之前。**两种场景都必须走完整仪式，没有例外**——旧书不因"已有原文"豁免，旧稿原文不作声口主来源。

1. **推荐**：按本书频道+赛道，推荐 **1-3 本同频道同赛道参考书**（候选母本），每本给一句话说明：声口特点 + 与本书的匹配理由。
2. **选定**：作者从中选 **1 本主母本**（可另加 1 本辅助母本补个别手法）；也可以全部否掉、自己指定一本。**作者未做选择之前，不进入下一步。**
3. **炼制**：按优先级取材——
   - ① 声口库里已有该母本/该赛道的**已校准条目** → 直接取用；
   - ② 作者能提供母本文本样本（前 10-30 章 / 3-5 万字量级）→ 按下方「新增条目流程」拆成条目（条目回流入库，下本书复用）；
   - ③ 都没有 → 凭认知起草，**文件头显著标注「凭认知起草，待真实母本替换校准」**，并在作者拿到母本文本后第一时间重炼。
4. **绑定**：实例化到 `{书}/设定/声口.md`（按下方「开书实例化」5 步调分寸/选平台/自测），**文件头登记绑定信息**：绑定书名、来源母本、实例化日期、作者认可记录。作者读过认可后**全书锁定**——整本书的撰写只以这份文件为锚；中途换声口 = 走变更模式 + 作者亲自确认，不存在静默替换。

**旧书补充条款**：与新书**同一套**流程——重新推荐、重新选定、重新炼制、重新绑定；已发布原文只用于**分寸校准**（对照指纹、调 §0 主次），不作为声口的主要来源。**绑定完成前，一章新正文都不写**（铁律 8）。

## 用法：开书实例化（5 步）

1. **选条目**：按新书的赛道，从库里挑对应条目（没有就先按「新增条目流程」拆一个）。
2. **复制**：整份复制到 `{新书}/设定/声口.md`。库里的是模板，书里的是实例——以后微调只改书里那份，库条目保持干净。
3. **按主角调分寸**：改 §0 的主次（例：《重生2014》的陈牧定成"九分冷一分贱"），把例句换成本书人物语境。
4. **按平台选参数**：§平台区 里选目标平台那一列（番茄/起点），删掉另一列。
5. **自测校准**：用该声口按 voice-loop 写一章，跑本书 `追踪/gate.py`，全绿 + 作者读过认可声口，才算实例化完成。

## 铁律（防翻车，一条都不能松）

1. **一本书一份声口**：开书时选定，全书锁死不换。中途换声口 = 读者立刻感觉"换人写了"，防雪球锚点也会漂移。
2. **每段只锚 `设定/声口.md`**：写作时绝不把"上一段刚写的成品"当风格样板（乱码雪球的引信，见 voice-loop.md §0）。
3. **声口区跟母本走，平台区跟平台走**：语气词/句式/幽默类型属于作者声口；逗号密度/省略号上限/对话比/字数属于平台规则。两者在条目里分区存放，不许混写（混写的教训：曾把"番茄禁省略号"错记成声口规则，实测本书正文本来就在正常用省略号）。
4. **有真母本才建条目**：不许凭感觉编"想象中的赛道声口"。没有母本全文做量化+精读的条目是负资产。
5. **只学"怎么说"，不搬"说什么"**：条目里的母本原文只作标注来源的范例，绝不进正文——风格可学，句子/情节照搬会撞洗稿查重。

## 新增条目流程（拆一本母本）

1. **收料**：母本全文（≥3-8 章才能分辨"指纹"和"偶然"，全本最佳）+ 赛道信息（频道/大类/细分/平台）。
2. **量化**：全书跑一遍——标点指纹（逗号/句号/省略号/破折号/问叹号 每千字频次）、对话占比、语气词频率表、高频 n-gram（筛口头禅/套路描写）。
3. **精读**：前/中/后各抽 ≥1 段，确认对话声线、旁白气质、幽默类型、双声线切换习惯。
4. **切分**：把发现分进 采纳区（可迁移手法，配"规则+落点+每章上限"）和 禁用区（母本有但会害目标平台/属于套路描写的，明确标"不取"）。
5. **填模板**：照 `_模板.md` 成文。
6. **自测校准**：用它写一章过门禁 + 人读认可，标记条目状态为「已校准」，入库。

> 上限（配额）是防雪球的闸：每个采纳手法都必须带每章上限，没有上限的手法不许入库。
