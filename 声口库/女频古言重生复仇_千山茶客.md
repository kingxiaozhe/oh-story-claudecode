## 0. 一句话声口

> **冷而稳的女主视角旁白，古言雅驯的语气词打底；狠话短句收尾，爽点靠"在场群像反应"抬轿；情绪极度克制——全书感叹号只有 1.4/千字。**

**主次**：**冷静克制是底色，狠是锋刃，几乎不煽情。** 情绪不靠叹号和形容词，靠"死水微澜"式的白描和一句收尾狠话。（实例化到《大婚前夜》时按谢云蘅微调：她比沈妙更"带火"——烧嫁衣的人，冷里可以多一分决绝。）

## 1. 采纳区 —— 7 样核心手法

### 1.1 古言雅驯语气词打底（声口的地基）
- **是什么**：叙述与对话大量使用「竟 / 便是 / 倒是 / 偏 / 罢了 / 到底 / 越发 / 很是 / 定然 / 那般 / 这般 / 大约是」——全书量化：竟 11.5/万、便是 8.0/万、倒是 7.2/万、偏 4.6/万
- **规则**：这些词是"古言味"的来源，替代现代白话连接词（"竟"替"居然"、"便是"替"就是"、"定然"替"肯定"）
- **落点**：全文通用，是底色不是点缀
- **上限**：无硬上限，但**同一个词一段内不重复**；现代词（"居然/真的/超"类）反向禁入

### 1.2 冷女主推演腔：反问自答 + 狠话收尾
- **是什么**：POV 人物的算计写成短促推演，以反问蓄力、一句狠话钉死。母本范例（傅修宜段）："既然如此，那就将沈家再放在赤火上炙烤一回如何？……敢算计他傅修宜，沈家就必然要付出代价。"
- **规则**：推演最多 2–3 句反问/假设，**必须以一句短狠话收尾**；不许拖成整段计策讲解
- **落点**：布局章、看穿对手时
- **上限**：每章 ≤2 处
- ✅ "他们会去庄子。因为那对他们最省事。——也最致命。"
- ✗ 整段"她赌的是……所以……于是……"式复盘（无锋刃的讲解腔）

### 1.3 在场群像反应给爽点抬轿（爽点放大器）
- **是什么**：名场面不直接夸主角，靠周围人反应定格。母本范例（扳指名场面）："周围的人都安静下来" / "周围的人却是倒抽一口凉气"
- **规则**：爽点/打脸/揭露的瞬间，切 2–3 个在场者的差异化反应（惊呼的、僵住的、变脸的），再回到主角
- **落点**：每个爽点兑现处
- **上限**：每章 1–2 组；每组 ≤3 个反应镜头

### 1.4 器物/礼法含义的"爽点翻译"旁白
- **是什么**：用一小段旁白讲清一件器物/礼节的分量，让读者知道"这一下有多大"。母本范例："这送出去的可不仅仅只是个扳指，这意味着睿王将自己随意调动手下的权力都交给了沈妙。"
- **规则**：只翻译**爽点的分量**，不翻译计策过程；3 句内讲完
- **落点**：读者可能不懂行情的高光时刻（聘礼规制、诰命品级、店契地契的分量）
- **上限**：每章 ≤1 处

### 1.5 章尾金句钩 + 下章复读
- **是什么**：章尾落在一句有分量的短台词/短句上，**下一章第一行原样复读一遍**再展开。母本范例："来娶你了，沈娇娇。"（193 章尾 → 194 章头复读）
- **规则**：章尾 1–2 行金句收；下章开头复读该句，把跨章情绪接住
- **落点**：每章章尾（金句可以是台词、也可以是一句认知反转）
- **上限**：复读手法每 2–3 章用一次即可，不必章章复读

### 1.6 对话声线分层（群像的命）
- **是什么**：母本三层声线极分明——聒噪天真型配角（罗潭："好大好热闹……天哪，连公子哥儿都白白嫩嫩的"）/ 冷静主角（沈妙：短句、少语气词）/ 张狂苏感男主（谢景行："来娶你了，沈娇娇"——懒洋洋+视礼法如无物）
- **规则**：每个主要角色固定一种声线不漂移；对话不写"谁说的"也能认出人
- **落点**：全文
- **上限**：聒噪型配角每章戏份有限（调剂用，别抢戏）

### 1.7 标点克制律（情绪的底盘）
- **是什么**：全书感叹号 1.4/千字、省略号 2.7/千字、破折号≈0——**情绪靠内容不靠标点**
- **规则**：能用句号绝不用感叹号；愤怒写成"声音更低"而不是"！"；此律是"冷而稳"声口的物理基础
- **上限**：感叹号 ≤2/千字；省略号 ≤4/千字

## 2. 禁用区 —— 母本有，不取

| 母本特征 | 量化证据 | 处理/替代 |
|---|---|---|
| 微微系/摇头系套路 | `微微一笑` 180、`摇了摇头` 165、`微微` 高频 | AI 最爱抄的套路描写，按目标书 banned-words 删改为具体动作 |
| 长段心理复盘 | `沈妙心中` 163 次，部分段落整段推演 | 心理词女频可用但**限量**（见 §3）；推演必须按 §1.2 收成"反问+狠话"，不许整段讲解（《大婚前夜》中期章的复盘腔就是这个病） |
| 章长 ~6000 字的慢节奏 | 120万字/约190章 | 潇湘付费向章长。番茄要 2000–2500 字/章、钩子加密一倍，节奏按平台区走 |

## 4. 语气词 / 口头禅库

**叙述里（古言底色）**：竟、便是、倒是、偏、到底、越发、很是、定然、那般、这般、大约是、终究、罢了
**对话里（分声线）**：
- 冷女主型：短句，少语气词，反问收刃——"哦？""你说呢。""那便试试。"
- 长辈/嬷嬷型：到底、终究、很该、老婆子、我的儿
- 聒噪配角型：天哪、呀、啦、怎么能、可不是
- 张狂男主型：懒洋洋短句+称呼杀（专属昵称）——语气词几乎为零，靠姿态
**反向禁入**：现代白话（居然/真的假的/超/绝了/无语）
**单段上限**：语气词 ≤2
